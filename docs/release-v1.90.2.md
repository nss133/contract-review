# v1.90.2 — 문서 완결성 자동점검 제외

기존 실행기에서 contract-review-v1.90.2.crupdate를 적용합니다. 태깅자료·코퍼스·표준약정서를 지우거나 다시 적재할 필요는 없습니다.

- 조 번호·중복·인용·별첨 누락에 관한 완결성 자동 경고와 검토완료 차단을 제거했습니다.
- 문서 완결성 화면·리포트 타일·점검 범위 제한 안내를 제거했습니다.
- 계약서 추출·조항 분할·본문과 별첨 구역 및 자동판정의 원문 근거 검사는 유지했습니다.
- 기존 직접 의견·과거 완결성 판단과 메모는 보존하고 리포트에 기존 검토의견·메모로 표시합니다. 새 경고로 다시 열지 않습니다. 과거 제목 정보 없이 판단만 저장된 경우에도 메모·판정은 보존합니다.
- 통합 체크리스트 문구와 실제 자동 확인 포인트 표시(v1.90.1)를 포함합니다.
- 진행 표시에서 과거자료 연결과 항목별 태그 참고 검색을 구별합니다.

이 버전은 출처 검색의 성능 수정 버전이 아닙니다. 합성 계측에서 느린 구간은 문서 완결성보다 항목별 태깅 참고 검색이었으며, 조회 지연·인덱스 재사용·편집 재계산 분리는 별도 제안 단계입니다. 실제 폐쇄망의 3분 지연이 해결되었다고 주장하지 않습니다.
