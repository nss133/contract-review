# v1.90.1 표시 수정 검증

## 범위

- 통합 13개: 제목·질문·설명을 실제 엔진 동작과 대조함. 약정 확인 자동지원 9개와 사람 판단 4개를 구별함.
- 일반 8개: CMN-10, SP-DEL-01, SP-DEL-05, NDA-14, SETTLE-01·03·04·06의 사용자 설명을 정제함.
- 새 표시 모듈은 검색·판정 입력을 수정하지 않음. 원본 YAML, 판정 정책, 직접 자동판정·표준·판정저장 엔진의 해시가 v1.90.0과 동일함.
- 자동 확인 포인트는 저장된 자동판정 근거의 element만 중복 제거해 최대 3개 표시함. 최대 32개 근거만 살피고 원문 텍스트를 재검색하거나 복제하지 않음. 수기·재확인·과거 판단 재사용에 직접 자동 확인 표시를 붙이지 않음.
- 현재 자동판정에 없는 상세 근거는 표시하지 않음. 고정된 설명이나 지원 목록을 실제 확인 결과처럼 복사하지 않음.

- 실제 격리 Chrome: 통합 13개 렌더링, 합성 입력 자동판정 카드 9개, 실제 확인 포인트·원문 버튼 상한, 체크 원본 불변, 수기 의견 보존, 콘솔 오류 0. 삼단 화면 캡처를 직접 확인함.
- 자동판정 생명주기: 기본 자동판정, 일반 면책의 존재 확인, 구체적 전면 면책 차단, 재분석·재시작·본문 변경 시 철회, 수기 보존, 명시 중지·재개, 표준 업로드·재시작, 아카이브 활성 상태의 재분석·수기 보존 통과.
- ZIP·업데이트·직접실행 HTML의 일치와 소스·Worker 지문·코퍼스 미내장을 검증함. 패치 버전의 정확한 사용안내를 선택하도록 빌드 및 검증기를 함께 수정함.
