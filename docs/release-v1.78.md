# v1.78 — 의무 요소 비교·누적 판정 원문 연결

## 이번 변경

- 재위탁 동의, 접근권한 제한, 점검 협조, 기술적·관리적 보호조치, 식별정보 암호화 문장을 주체·행위·대상·조건으로 분해합니다. 문장 전체를 소비한 경우에만 비교하며 해석하지 못한 제한·숫자·부정을 버리지 않습니다. LLM이나 외부 통신은 사용하지 않습니다.
- 어순 변경, ‘점검하는 경우 … 협조’와 같은 정형 조건절, 명시적으로 정의된 갑·을, 병렬로 연결된 두 의무를 인식합니다. 같은 조항의 독립 의무에 붙은 ‘다만’은 무조건 차단하지 않습니다. 해당 쟁점의 예외·면제·의무 축소는 계속 확인 대상으로 남습니다.
- 요소 비교를 직접 판정뿐 아니라 등록 표준 및 과거 원문 조항 비교에도 사용합니다. 조항 구역이 명확하면 병렬 문장과 두 문장으로 분리된 표현도 비교합니다. 정의가 없는 갑·을의 역할은 추정하지 않습니다.
- 원문 평가자료에 빠진 사용자 판정을 누적 코퍼스에서 자동 연결합니다. 계약 해시 또는 검토 ID로 후보를 찾되 본문·별첨·적용 맥락·질문 지문이 모두 일치해야 합니다. 같은 ID만으로 정답을 붙이지 않습니다. 연결은 메모리에서 수행하며 원본 자료를 덮어쓰지 않습니다.
- 계약검토·법률검토 태깅자료의 검토 ID와 원문 출처를 연결해 실제 자동판정 근거에서 추적할 수 있습니다. 태그·제목·부서만 비슷한 자료는 정답으로 승격하지 않습니다. 원문 없는 의견, 첨부파일명은 검색 참고입니다.
- 최신 사용자 보완·위험수용·재확인 대기·보류·미래 자료·제외 출처는 재사용을 차단합니다. 동일 원문에 복수의 불명확한 판정 출처가 있으면 임의로 하나를 고르지 않습니다. 자동판정 결과를 새 사용자 정답으로 학습하지 않습니다.
- 전조·번호가 확인되는 전항·명시적 내부 준용은 참조 원문까지 비교합니다. 중복 번호, 누락 번호, 외부 규정 준용, 해결되지 않은 참조는 추정하지 않습니다. 본문과 별첨의 번호가 같아 대상을 확정할 수 없는 경우도 그대로 표시합니다.
- 내부 일괄 점검에 연결된 코퍼스 정답을 사용합니다. 자료 읽기와 출처 색인을 묶어 처리하고, 질문마다 같은 과거 원문을 다시 준비하던 중복 처리를 줄였습니다. 같은 계열·미래·자기 정답 검색 제외는 유지합니다.
- 자동판정 이유 화면에 원문 묶음 수, 태깅자료 연결 수, 복원한 누적 판정 수, 원문 연결 미확인 판정 수를 표시합니다. 연결된 자료가 있다는 사실과 본건 질문의 자동 충족 여부는 구분합니다.
- 기존 자동 등록 표준서식은 연결 규칙 6으로 자동 갱신됩니다. 수동 설정·사용 중지는 유지합니다. 신규 승인 절차는 추가하지 않았습니다.

## 적용

기존 실행기를 열어 v1.78.0 업데이트 파일을 적용한 뒤 계약을 재분석합니다. 데이터가 저장된 기존 실행기·브라우저 프로필을 그대로 사용하십시오. 새 실행기로 옮기면 저장영역이 달라질 수 있습니다.

표준서식은 다시 승인할 필요가 없습니다. 누적 판정 연결에는 폐쇄망 내부에 원문 평가자료와 판정 코퍼스가 함께 있어야 합니다. 지금까지 저장된 파일이 검토의견·집계·첨부파일명만 포함한다면, 이번 업데이트가 없는 계약 원문을 만들어낼 수는 없습니다. 자료를 외부로 반출할 필요는 없습니다.

자동판정되는 항목은 기존 조항별 검토의 ② 확인 완료에 표시됩니다. 자동판정 이유 화면의 ‘자료 연결’에서 연결 여부를 구분할 수 있습니다. 실제 이행 확인 기능은 추가하지 않았습니다.

## 검증 및 한계

Node 708개, Python 106개 회귀시험(합계 814개)을 통과했습니다. 격리 브라우저의 7개 흐름에서 새 요소 비교, 명시 별칭, 병렬 의무, 코퍼스 판정 복원·평가 반영, 최신 정정에 따른 철회, 표준서식 등록·복구, 자동 완료의 ② 이동, 사용자 판정 보존을 확인했습니다. 검사한 앱의 외부 요청은 0건이었습니다. 사용자 코퍼스·계약 원문은 배포본에 내장하지 않았습니다.

공개 표준자료 5개에 대한 직접 규칙의 자동충족은 여전히 0개입니다. 위 개선은 표현 변형·원문 연결 사례에서 확인한 것이며, 이 자료군이나 폐쇄망 전체의 자동판정 비율이 높아졌다고 주장하지 않습니다.

잔여 개발은 남아 있습니다. 독립적인 직접 판정은 13개 질문, 조항 선택 기반 과거 판단 재사용은 15개 주요 질문, 내장 예문과 별개의 표준 자동 연결은 손해배상·해지·비밀유지 3개 통합 질문이 중심입니다. 이번에는 이 범위 안의 해석·연결 경로를 개선했습니다. 전 206개 질문의 요건 정의 확대, 복잡한 예외·역할 정의·별첨 참조 해석, 실자료의 다양한 표현을 포함한 정확도·성능 검증까지 끝났다는 의미가 아닙니다.

원문 없는 구 코퍼스 및 법률검토 의견의 일반적 유불리를 독립 판정하는 기능은 구현하지 않았습니다. 자동 계열 추정에 따른 내부 비교는 독립 정확도 인증이 아니며, 위험수용·출처 미확인 정답은 채점에서 제외합니다.
