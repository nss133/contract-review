# v1.90.3 — 참고 검색 분리·조항 수정 부분 갱신·검색 색인 재사용

기존 실행기에 contract-review-v1.90.3.crupdate를 적용합니다. 태깅자료·코퍼스·표준약정서를 다시 적재하거나 별도 승인할 필요는 없습니다.

1. 기본 분석은 관리 화면의 태깅 참고 후보 검색을 기다리지 않습니다. 매핑에 쓰는 태그·누적 표현과 현재 원문 자동판정은 유지합니다. 자동판정 상세를 열면 별도 작업 스레드에서 참고 목록을 검색하고, 미조회·검색 중·완료·오류·입력 변경 상태를 구분합니다. 검색 취소와 재시도가 가능하며 결과 도착이 수기 판정을 변경하지 않습니다.
2. 의견 대상 조항을 이동·원위치 복귀·자동매칭 확인·계약 전반으로 바꿀 때, 분석 입력과 자료가 그대로라면 해당 체크만 다시 판정합니다. 다른 항목의 자동판정과 수기 의견은 유지합니다. 본문·별첨·범위·설정·참고자료가 바뀌면 전체 재분석 경로를 유지합니다. 전체 재분석에서도 저장된 의견 대상을 먼저 반영합니다.
3. 태깅 참고 검색은 문서별 단어 집합·벡터·태그/체크 ID 색인을 재사용하고, 기존 필터를 통과할 수 있는 후보만 유사도를 계산합니다. 동일 검색 결과를 제한된 메모리 캐시에 보관합니다. 자료 개정이나 작업 스레드 재시작 때 색인을 갱신합니다. 기존 결과·점수·순위는 유지하며 임의로 자료 수를 잘라내지 않습니다.

v1.90.2의 완결성 자동 경고·완료 차단 제외와 v1.90.1의 체크리스트 문구 정리를 포함합니다. 이 변경은 LLM 없이 작동하며 외부 검색·전송을 추가하지 않습니다. 폐쇄망 장비의 실제 처리시간과 실계약 정확도를 보장하는 것은 아닙니다.
