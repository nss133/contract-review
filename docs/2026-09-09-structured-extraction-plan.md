# 4개 형식 구조 추출·본문/별첨 번호 구역 개선계획

상태: v1.57.0 공통 구조/구역·네 형식 추출·경계 보정 구현. 형식별 복잡한 조합 및 OCR/원본 렌더링의 외부 실행 경로는 별도 범위로 남김.
Work ID: CW-20260825-EF96D7EB.

## 구현 결과

[v1.57 배포 안내](release-v1.57.md)에 실제 구현 범위와 한계를 구분했다. 구조 블록/출처 전달, 본문·별첨·부칙 구분, 별첨 존재 및 구역 간 명시 인용 검사, 1회 경계 보정·중첩 부모 선택·선택 구역 제외·내부 백업/복구·원문 변경 무효화를 연결했다. 네 형식의 합성 원본 파일을 실제 추출 경로와 브라우저에서 시험했다. Node 488건·Python 103건, 기존 안전성·계약 태그·업데이트 자료 보존 회귀를 통과했다. 외부 요청 0건이었다.

스캔 OCR, 한글/Word 자체 렌더링, 모든 번호 재시작·다단/표 읽기 순서 조합의 완전 재현은 미구현 또는 미검증이다. 실자료 정확도·구역 경계 정답·계약당 보정 횟수는 폐쇄망 내부에서 평가해야 한다. 아래 계획의 모든 세부 예외가 완료됐다고 간주하지 않는다.

## 결론과 범위

HWP·HWPX·DOCX·PDF를 모두 개선 대상으로 한다. 특정 형식이나 폐쇄망 실제 계약서의 반출을 요구하지 않는다. ‘점검 범위 제한’은 마지막 안전장치이며 일차 목표는 문서 구조 보존과 정확한 인용 주소 연결이다.

본문과 별첨의 조 번호 중복은 독립 번호 영역으로 구분하면 해결 가능한 유형이다. 다만 표제·구역·페이지 단서가 모두 유실된 입력에서는 자동 구분을 보장할 수 없다. 해당 경우에는 원본 기반 재추출과 최소 수동 경계 보정의 대안을 제공한다.

## 현재 코드 확인과 재현

- 추출 디스패처와 각 추출기는 최종 평문 문자열을 반환한다. 문단 계층·출처 위치를 후속 완결성 검사까지 전달하지 않는다.
- DOCX에는 자동번호 일부 복원이 있으나 스타일 상속·번호 정의 재정의와 문단 구조 전달을 더 점검해야 한다.
- HWP는 자동번호 제어를 문맥에 따라 복원한다. 번호 정의·문단 속성에 근거한 복원으로 대체할 필요가 있다.
- HWPX는 section XML의 텍스트 수집 중심이다. 문단 속성과 번호 정의의 연결이 필요하다.
- PDF는 좌표로 줄바꿈을 복원한 뒤 페이지·좌표·글자 속성을 후속 단계에 전달하지 않는다.
- 완결성의 구역 경계는 제한된 부칙·별표·별지·붙임 표제만 지원한다. 별첨, 대괄호를 씌운 표제, 제목이 뒤에 붙은 표제는 인식하지 못한다.
- 별첨 존재 확인도 단순 출현 횟수·파일명 문자열에 의존하므로 인용과 실제 별첨 표제를 구별하지 못한다.

합성 재현: 본문 제1·2조 뒤에 ‘별첨 1 보안관리약정서’ 또는 ‘[별첨 1] 보안관리약정서’를 두고 별첨 제1·2조를 배치하면 각각 NUM-01 두 건과 ATT-01 한 건이 발생했다. 이는 실제 폐쇄망 문서 검증이 아니라 코드 결함 재현이다.

## 공통 구조 모델

원문 표시와 추출 문자열을 보존하면서 별도 구조 레코드를 전달한다.

- 파일 ID → 논리 문서/구역 ID → 조 → 항 → 호 → 목.
- 블록마다 원문·읽기 순서·번호 원표기·번호 수준·스타일/들여쓰기·출처·구조 판단 근거를 보존한다.
- 출처는 PDF의 페이지/좌표, XML 형식의 문단·표 셀·파트 주소, HWP의 섹션·레코드 주소 등 실제로 얻은 값만 기록한다. XML 문서에 없는 페이지를 추정 확정하지 않는다.
- 기존 평문 반환 경로는 호환 어댑터로 유지하고, 완결성 검사는 구조 레코드를 우선 사용한다. 사용자 텍스트 수정 시 이전 구조와 보정의 유효성을 무효화한다.
- 매핑·사람 판정의 조항 주소가 바뀔 때 기존 판정을 다른 조문에 임의로 이식하지 않는다. 원문 지문·출처에 근거해 연결하거나 재확인한다.

## 형식별 추출 개선

| 형식 | 기본 개선 | 구조 확보가 어려울 때 |
|---|---|---|
| DOCX | 번호 정의·수준·재시작·스타일 상속, 표/텍스트상자·구역 나눔, 변경추적의 표시 정책을 분리 보존 | 내부 Word 등 승인된 원본 렌더링과 대조; 임의 번호 생성 금지 |
| HWPX | header의 번호/문단 속성과 section 문단 연결, 표 셀·구역·자동번호 보존 | 승인된 한글 프로그램의 원본 렌더링 또는 변환과 대조 |
| HWP | 문단 헤더·문단 모양·번호 정의와 자동번호 제어 연결, 섹션·표/개체 구조 보존 | 폐쇄망에 설치된 한글 프로그램을 이용한 HWPX/PDF 변환 대안; 원본 유지 및 결과 대조 |
| PDF | 페이지·좌표·글자 크기·읽기 순서 보존, 번호/표제 조각 결합, 다단·표·반복 머리말 분리 | 스캔/텍스트층 오류는 승인된 로컬 OCR 후 원본 이미지 대조 |

원본 렌더링·변환·OCR은 설치/라이선스/실행 정책 확인이 필요한 별도 경로다. 외부 API 업로드를 전제하지 않으며, 현재 단일 HTML에 이미 구현된 기능이라고 간주하지 않는다. 페이지 나눔이나 파일 형식의 section은 논리 별첨 경계와 동일하지 않다.

## 본문·별첨·부칙 구분

1. 별첨/별지/별표/붙임/부록/첨부/Annex 등의 표제 후보, 독립 문서 제목, 번호 재시작, 서명란 뒤 전환, 스타일·배치 변화를 조합한다.
2. ‘별첨 1에 따른다’ 같은 인용 문장은 구역 시작으로 삼지 않는다. 목차·반복 머리말 역시 제외한다.
3. ‘본문/제1조’, ‘별첨1/제1조’, ‘별첨2/제1조’는 별개다. 별첨 속 하위 약정서도 독립 구역 또는 자식 구역으로 표현한다. 같은 이름의 별첨이 반복되어도 ID는 이름만으로 합치지 않는다.
4. 동일 번호의 중복은 같은 독립 번호 영역 안에서만 검사한다. 반대로 제1조가 다시 나왔다는 이유만으로 무조건 구역을 나누면 실제 중복을 놓치므로 번호 재시작 단독으로 확정하지 않는다.
5. 조항 안에 인용된 서식·수정 전후 대비표·예시 문구를 별도 계약의 실제 조문과 구분한다.
6. 별첨 존재는 본문 속 실제 별첨 구역과 따로 업로드한 파일을 함께 조회한다. 별첨 표제 자체를 ‘누락된 별첨 인용’으로 만들지 않는다.
7. 인용은 먼저 명시된 대상(본 계약/별첨 번호·제목)을 적용한다. 명시가 없으면 해당 구역을 우선 탐색하되 계약 전체의 정의·문맥상 다른 구역 가능성이 있으면 후보를 표시한다. 다른 구역에서 번호가 하나 발견됐다는 이유만으로 자동 연결하지 않는다.

## 자동 인식이 불가능할 때의 대안

우선 원본 파일을 구조 보존 방식으로 재추출한다. 그래도 경계가 불명확하면 후보 위치에서 ‘여기부터 별첨/별도 문서’를 한 번 지정하게 한다. 하나의 보정이 뒤따르는 조·항·호의 주소, 중복 검사, 별첨 존재 확인에 함께 적용되도록 하며 개별 경고마다 오탐을 누르게 하지 않는다. 파일 지문과 경계 위치로 보정을 저장하고 원본 변경 시 재검증한다.

자동 후보가 없으면 문단 또는 페이지 시작 위치를 직접 지정할 수 있게 한다. 별첨 파일을 따로 업로드하거나 승인된 프로그램에서 분리하는 것은 보조 대안이며 기본 사용 절차로 강요하지 않는다.

수동 보정도 원문 부재 등으로 불가능하면 해당 구역의 번호 중복·부재 검사만 비활성화한다. 나머지 구역과 실질 계약 검토는 계속한다. 충분한 내부 시험에서 실익이 없는 세부 검사는 기본 기능에서 제외하며, 보류 안내를 늘리는 것을 성공으로 평가하지 않는다.

## 구현 순서와 완료 조건

1. 공통 구조·출처·구역 모델과 평문 호환 계층, 현재 별첨 중복 재현을 고정 회귀표본으로 만든다.
2. 네 형식 추출기를 모델에 연결한다. 형식별 완료/미완료를 구분하고 일부 형식 성공을 전체 완료로 보고하지 않는다.
3. 본문/별첨/부칙 경계와 인용 대상 연결, 별첨 존재 검사를 같은 모델로 통합한다.
4. 원본 위치 표시·경계 1회 보정·변경 무효화를 연결한다.
5. 합성 원본 파일과 폐쇄망 내부 실자료 평가 도구를 제공한다. 원본·텍스트·식별자·평가 결과 반출을 요구하지 않는다.

필수 시험: 네 형식 각각의 수동/자동번호, 번호 재시작, 표 안의 표제, 별첨 2개 이상, 중첩 별첨, 같은 이름 별첨, 표제 없는 약정서, 다단/머리말/서명란, 인용 문장과 실제 표제 구별, 본문→별첨 및 별첨→본문 인용, 실제 동일 구역 중복, 문단·페이지 경계가 유실된 경우, 원문 수정과 보정 무효화.

성공 기준은 경고 감소만이 아니다. 조·항·호 복원 정확도, 구역 경계·인용 연결 정확도, 잘못된 중복/부재 경고, 실제 구조 오류 탐지율, 자동 점검 가능 범위, 계약당 수동 경계 보정 횟수를 함께 측정한다. 고정 합성 표본의 정상 별첨 중복 오탐은 0건, 실제 같은 구역 중복 표본은 탐지 유지가 회귀 통과 조건이다. 실자료 성능 수치는 내부 시험 전 약속하지 않는다.
