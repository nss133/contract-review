# Python 3.9 전환 1차 구현 기록

2026-09-21. 브랜치: feat/python39-fastapi. 기준 커밋: 4a2e5f195ae9cd23f46bd24cf3ff034453391d80, 기존 앱 v1.90.8.

현재는 S0·S1 기반과 S2·S3 일부를 구현한 개발판이다. 전체 계약 분석 앱의 Python 이전이나 공용 서버 운영 배포를 완료한 상태는 아니다.

사용자 조건은 기존 화면 구성 유지, Python 3.9·FastAPI, 프론트와 백엔드 분리, 폐쇄망 공용 서버에서 팀 접속이다. 추가 답변에 따라 서버 로컬 SQLite·동시 사용자 10명 이하·관리자 발급 계정을 개발 기준으로 채택했다. SSO는 회사의 통합 로그인 방식이며 사용 여부는 미확정이다. 서버 OS·아키텍처·웹서버·HTTPS 주소·실제 DB 경로도 배포 전에 확인해야 한다.

## 구현한 범위

- backend: Python 3.9 FastAPI API, SQLite 마이그레이션, 관리자 CLI 계정 생성, 세션 로그인·로그아웃, CSRF, 역할·계약별 읽기/편집 권한, 공개 체크리스트 조회.
- 저장: 원문 그대로의 본문 초안, 사용자별 의견 초안, revision 충돌 검사, 감사 이벤트. 재시작 후 저장 내용을 읽는다. 다른 사용자와 운영자에게 계약을 자동 공개하지 않는다.
- SQLite: 서버 로컬 파일, WAL, 짧은 트랜잭션, 쓰기 잠금 시 재시도 가능한 503, 오래된 편집 시 409. 팀원은 API를 통해 접속하며 DB 파일을 공유폴더에서 직접 열지 않는다.
- frontend: 독립 HTML·CSS·JS 소스와 정적 빌드, 기존 정적 컨트롤 ID 237개와 탭 구성 유지. 실제 로그인·본문 초안 저장/목록/불러오기·로그아웃을 API에 연결했다. 개인 의견 초안은 현재 API까지만 구현했다.
- API 계약: OpenAPI와 엄격한 입력 모델, 원문 해시·UTF-16 위치 호환 함수, 통일된 오류 응답. 전체 분석 결과 모델과 작업 상태 모델은 후속 구현을 위한 초안이다.
- 패키징: Python 3.9 잠금 파일, 해시를 포함한 런타임·시험 의존성 목록, 백엔드 wheel. 코드·DB·개발 환경·정적 빌드 출력 경로를 분리했다.

미이전 기능은 capabilities에서 false로 표시한다. 분석 요청은 501을 반환하며, 화면의 미연결 기능은 비활성 상태다. 기존 JavaScript 분석 엔진을 Python 서비스에서 실행하는 대체 경로는 없다.

## 비교 기준

[계약·비교 자료](../contracts/README.md)에 기존 소스 92개 해시, 정적 저장소 참조 90개, 핵심 함수의 이전 경계, 원문 해시 합성 사례 6개를 기록했다. 약정 존재 합성 사례 61개와 실제 기존 Worker의 합성 문서 3종·선택 체크 8개 결과는 각 두 번 실행해 일치함을 확인했다.

기존 화면은 1440·1100·800px와 인쇄 조건에서 22개 이미지를 확보했다. 공개 내장 지식과 합성 계약만 사용했다. 이는 전체 골드셋·모든 UI 생명주기·동적 저장소 이관 명세를 완성한 것이 아니며, Python 분석 결과의 동등성 검증도 아직 아니다.

## 검증 결과

개발 장비는 macOS ARM64이며 백엔드는 실제 Python 3.9.25, FastAPI 0.128.8, SQLite 3.50.4에서 실행했다. 한글 소스·JSON·SQL 읽기/쓰기는 UTF-8을 명시한다.

| 검증 | 결과와 범위 |
| --- | --- |
| Python 신규 시험 | 34개 통과. 인증·권한·CSRF·세션 만료·본문/의견 복원·마이그레이션 변조·쓰기 충돌·DB 잠금·원문 위치 등을 확인 |
| SQLite 동시 쓰기 | 같은 revision에 10개 요청 시 1개 성공·9개 충돌, 서로 다른 사용자 10명의 초안 저장 성공 |
| 프론트 API 클라이언트 | Node 시험 3개 통과 |

| 기존 배포물 | v1.90.8 HTML·ZIP 무결성 검사 통과 |

오프라인 설치 시험은 현재 macOS ARM64 장비 기준이다. 공용 서버용 wheelhouse와 폐쇄망에서의 서비스 실행·백업 복원은 아직 검증하지 않았다. 브라우저 시험은 별도 합성 DB와 시험용 프로세스를 사용하며 종료 시 해당 서버 프로세스를 정리한다.

검증한 contract_review_api-0.1.0-py3-none-any.whl의 SHA-256은 b8b3781e8783f8d708969a48d5d8c066cb527c1a2cb0bf5af8da4b0c38ec169c이다. wheel 내부 Python·JSON·SQL 파일이 현재 백엔드 소스와 일치하는 것도 확인했다. wheel과 가상환경은 Git에 포함하지 않는다.

재현 명령은 프로젝트 루트에서 실행한다.

    backend/.venv/bin/python -m pytest backend/tests -q
    node --test frontend/tests/*.test.mjs
    backend/.venv/bin/python tools/migration/verify_foundation.py --chrome-path /설치된/Chrome/실행파일

## 남은 작업

다음 구현은 기존 화면 이벤트와 상태를 API 호출로 분리하고, 전체 검토 저장 모델·구버전 자료 이관을 확장하는 작업이다. 이후 문서 추출·구조·태그·매칭·자동판정·수기 보존·완료 조건을 Python으로 이전하고 고정한 기존 결과와 비교한다.

현재 미구현 범위에는 파일 추출, 계약 분석, 최종 판정과 완료, 표준·코퍼스·평가·설정의 전체 저장, 구형 자료 이관, 백업/복구, 계정관리 화면, CPU 작업 프로세스가 포함된다. 따라서 S0~S8 체크리스트 전체를 완료 처리하지 않았다. [실행계획](superpowers/plans/2026-09-21-python39-fastapi-migration.md).

개발 환경 변경 기록: SQLite 답변 전에 시작했던 PostgreSQL 설치는 중단했다. PostgreSQL 본체 설치·서비스 시작은 하지 않았으나 Homebrew 의존성 icu4c@78·ca-certificates·openssl@3은 설치되었다. 다른 도구가 함께 사용할 수 있는 의존성이므로 자동 제거하지 않았다.
