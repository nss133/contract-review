# v1.90.4 변경 안내

## 검토 화면

- ‘본문·부속서류 근거의 검토항목’ 별도 영역을 없애고 기존 조항별 검토 삼단 화면에 배치합니다. 항목 자체를 삭제하지 않습니다.
- 본문에 연결된 항목은 해당 조항, 별첨에서 확인한 항목은 실제 별첨 원문 행에 표시합니다. 근거가 아직 연결되지 않은 항목도 일반 미연결 항목으로 남깁니다.
- 자동 이상없음은 ② 확인 완료, 검토할 항목·의견은 ③에 표시합니다. 수기 의견과 리포트의 미완료 집계를 유지합니다.
- 흔한 구절만 겹친 과거 자료를 카드의 근거처럼 표시하던 ‘표현 검색 참고’를 제거합니다. 내부 매핑 자료와 관리용 검색은 유지합니다.

## 보안관리약정서 활용

- 본건에서 적용·별첨한다고 정한 등록 표준은 명칭의 공백·괄호 및 일반형 명칭 차이를 정규화하여 연결합니다. 후보가 하나이면 개정판을 다시 입력하도록 요구하지 않습니다.
- 서로 다른 후보·명시된 판본 불일치·참고용·적용 제외 문구는 자동 선택하지 않습니다. 본건에 실제 올린 별첨 원문이 있으면 등록 표준으로 덮어쓰지 않습니다.
- 개인정보 관리·감독 및 신용정보 재위탁 제한은 본문과 적용된 별첨의 내용으로 판정합니다. 실제 점검·승인 이행을 확인하는 기능은 아닙니다.
- 재위탁 금지 원칙과 같은 조의 서면승낙·법령상 금지업무 제외 조건을 함께 읽습니다. 단순 승낙만으로 무제한 재위탁을 허용하는 예외는 자동 통과하지 않으며 예외 범위의 확인이 필요하다고 표시합니다.
- 기존 자동 등록 표준의 연결은 업데이트 후 갱신됩니다. 수동 연결과 사용 중지 상태는 보존합니다. 다시 업로드하거나 승인할 필요는 없습니다.

## 업데이트

기존에 사용하던 실행기를 열어 같은 ZIP 안의 contract-review-v1.90.4.crupdate를 선택한 뒤 계약을 다시 분석합니다. 새 실행기 파일로 시작하거나 브라우저 데이터를 삭제하지 마십시오.

실제 폐쇄망의 자료·장비는 직접 시험할 수 없으므로, 로컬 검증 범위와 결과는 함께 제공하는 검증 기록을 확인하십시오. 자동 이상없음은 해당 질문의 약정 확인이며 계약 전체의 법적 적정성을 보장하지 않습니다.
