## 자동판정·표준·누적 결과의 연결

- 여러 요건이 있는 질문은 각 요건을 모두 확인합니다. 예를 들어 라이선스는 목록 고지·준수·위반 책임을 각각 확인하고, 하나가 빠지면 해당 항목은 자동완료하지 않습니다. 요건이 여러 문장이나 조항에 나뉜 경우도 처리합니다.
- 문장에서 읽은 주체·행위·대상·조건·방법을 직접 판정, 표준 자동등록, 과거 판단 재사용에 함께 사용합니다. 태그는 후보 검색과 근거 설명에도 사용하지만 태그가 비슷하다는 이유만으로 이상없음을 만들지 않습니다.
- 서로 다른 조건을 같은 정형 이력으로 묶던 범위를 좁혔습니다. 신원조회와 신원보증, 위탁회사와 원수탁업자 공동 지시와 선택적 지시, 평가 횟수 등이 다른 경우 서로 다른 근거로 남깁니다. 같은 근거에 대한 최신 보완 의견은 계속 자동판정을 차단합니다.
- 당사자 역할 어휘와 단순 줄바꿈 복구를 확대했습니다. 원수탁자·주식회사 등의 일부 글자를 수탁자·회사 별칭으로 잘못 읽지 않도록 했습니다. 모호한 정의는 추측하지 않습니다.
- 기존 자동등록 표준은 연결 규칙 10으로 자동 갱신합니다. 새 승인 작업은 없으며 수동 설정과 사용 중지 상태를 보존합니다. 표준 또는 과거 판단과 비교할 때도 관련 조건과 참조 문맥을 함께 확인합니다.

## ② 확인 완료 표시 수정

자동판정은 완료됐지만 어휘 매핑 점수가 낮아 ②열에서 빠지는 경우를 수정했습니다. 본문에 고유하게 확인되는 실제 인용 근거가 있으면 그 조항에 완료 카드를 표시합니다. 원래 매핑 점수·검토자 지정·학습 기록은 바꾸지 않습니다.

별첨에만 근거가 있거나 본문 위치를 하나로 특정할 수 없는 완료 항목은 기존 본문·부속서류 검토 영역의 삼단 화면에 근거와 함께 표시합니다. 완료 항목을 미완료 목록에 다시 넣지 않습니다. 근거 자료 삭제·요건 누락·관련 제한 또는 최신 사용자 정정이 생기면 자동판정을 철회하고, 직접 입력한 판정은 덮어쓰지 않습니다.
