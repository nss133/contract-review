# v1.69 통합 쟁점 검토 배포

v1.68을 먼저 설치할 필요 없이 동봉된 .crupdate를 기존 실행기에 적용합니다. 기존 자료는 업데이트 전에 내부 백업하세요. 코퍼스나 원문을 외부로 반출할 필요는 없습니다.

## 이번에 구현한 내용

- 106개 세부 항목을 30개 상위 쟁점으로 연결했습니다. 계약 유형·적용 모듈에 따라 활성화된 항목만 해당 카드에 들어갑니다. 전체 238개 원항목의 질문·근거·적용조건·ID는 유지합니다.
- 손해배상과 비밀유지를 비롯한 통합 카드는 ‘조항별 검토’ 위쪽 ‘통합 쟁점 검토’에 모았습니다. 서로 다른 조항과 별첨의 근거도 한 카드에서 확인할 수 있습니다. 같은 항목의 개별 카드를 조항마다 다시 표시하지 않습니다.
- ‘이상없음 / 검토의견 / 해당사항 없음’ 중 한 번 판정하면 통합 쟁점 한 건으로 완료됩니다. 세부 체크박스를 전부 클릭할 필요가 없습니다. 메모를 작성한 뒤 판정 버튼을 누르면 함께 저장됩니다.
- ‘세부 요건·근거’를 펼치면 기존 개별 판정·보완 의견·원문 후보·별첨 근거를 볼 수 있습니다. 필요한 경우에만 세부 판정이나 근거 조항을 조정합니다. 관련 문구 발견만으로 요건 충족으로 표시하지 않습니다.
- 완료 건수·잔여 목록·리포트·검토 마치기는 통합 단위로 연결했습니다. 저장 후 재분석·로컬 재로드 시 동일 문서·조건의 통합 판정을 유지합니다. 문서·별첨·적용조건·개별 수동판정이 바뀌면 재확인으로 표시하며, 리포트에서 해당 통합 카드로 이동할 수 있습니다.
- 부가세는 분석 시 확정적인 포함/제외/별도/미포함 문구를 자동확인합니다. 별도 ‘자동판정 시작’ 클릭은 필요하지 않습니다. 부정·미정·예시·상충은 확인 대상으로 남깁니다. 수동판정은 덮어쓰지 않으며 명시적 자동판정 중지 설정은 존중합니다. 그 밖의 정형 자동판정은 기존 원문·범위 확인 절차를 유지합니다.
- 지체상금/지연이자 오매핑 교정은 v1.68 변경을 포함합니다.

## 기존 자료와 평가셋 보호

- 기존 개별 판정은 그대로 보존합니다. 일부 세부 항목만 ‘이상없음’이면 전체를 완료로 승격하지 않습니다. 모든 활성 세부 항목이 이미 완료된 경우에만 종합 결과를 표시합니다.
- 기존 보완·위험수용 의견과 다르게 통합 ‘이상없음’을 선택하려면 이유를 입력해야 합니다. 원래 의견은 삭제하지 않습니다. 통합 판정 취소도 개별 판정은 삭제하지 않습니다.
- 통합 판정은 별도 group_reviews 필드 및 계약별 로컬 저장소에 저장합니다. 검토 내보내기/불러오기, 검토 아카이브, 코퍼스 원장, 선택적으로 켠 내부 평가자료에 보존합니다. 개별 verdicts 정답으로 복제하지 않습니다. 구버전 앱은 통합 판정을 처리하지 못하므로 새 판정 파일은 v1.69 이상에서 사용하세요.
- 통합 결론에는 쟁점 ID·결론·통합 범위 태그를 저장합니다. 누적 코퍼스의 동일 쟁점 검토는 카드에서 참고할 수 있습니다. 과거 횟수나 통합 결론 하나를 근거로 현재 개별 요건을 자동통과시키지는 않습니다.
- 내부 일괄 평가에는 ‘통합 쟁점’ 분모·후보·보완과 충돌 수를 별도로 표시합니다. 현재 규칙으로 모든 활성 세부요건이 충족되는 경우만 통합 자동 후보로 셉니다. 항목/정의가 달라졌거나 재확인이 필요한 과거 통합 판정은 채점에서 제외합니다. 자기 정답을 자동판정 입력으로 넣지 않습니다.

## 폐쇄망에서 확인할 순서

1. 계약을 열어 재분석합니다. 조항별 검토 위쪽에 손해배상·비밀유지 카드가 각각 하나로 나타나는지 확인합니다.
2. 기존 검토가 있으면 세부 요건을 펼쳐 판정·메모가 남아 있는지 확인합니다. 통합 카드에서 판정하고 다른 탭에 갔다 돌아와도 유지되는지 확인합니다.
3. 리포트의 미완료 목록과 카드가 일치하는지, 통합 판정 후 검토 마치기를 막는 숨은 세부 항목이 없는지 확인합니다.
4. 부가세 포함 문구가 자동확인되는지, 별첨과 포함/제외가 충돌하면 자동확정하지 않는지 확인합니다.

실제 폐쇄망 자료의 자동판정률·오판률은 이번 개발시험으로 확정할 수 없습니다. 통합은 질문·조작 부담을 줄이는 변경이며 법적 판단 범위를 무조건 확대하는 기능이 아닙니다. 선택특약 부재를 자동으로 위험으로 단정하지 않지만, 현재 코드가 모든 선택특약의 적용 여부를 자동 판별하는 것은 아닙니다.

AI·외부 API는 필요하지 않습니다. 배포 ZIP에는 개인 코퍼스 원문을 내장하지 않았습니다.
