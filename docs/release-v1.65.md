# v1.65 누적판정 자동태깅 및 간편 비교 사용안내

## 업데이트 전에

기존 실행기를 그대로 사용합니다. 기존 코퍼스 JSON, 계약검토 이력팩, 법률검토 지식팩과 중요한 판정파일을 폐쇄망 내부에 백업한 다음 새 .crupdate를 설치하세요. 새 실행기를 다른 위치에서 열면 기존 자료가 보이지 않을 수 있습니다.

이 배포본에는 사용자가 제공한 코퍼스·계약 원문을 내장하지 않았습니다. 이미 적재한 태깅자료는 다시 넣을 필요가 없습니다. 구 버전 ZIP은 복구용으로 보관하세요. 새 판정 이력은 구 버전이 완전히 해석하지 못하므로 업데이트 전 백업도 따로 유지하세요.

## 일상 검토

1. 계약 본문과 실제 별첨을 열고 분석합니다. 유형·우리 회사 역할·업무 범위를 확인합니다.
2. 평소처럼 이상없음 또는 검토의견을 선택하고 필요한 의견을 남깁니다. 결과·사유·주제 태그가 로컬에 자동 저장됩니다.
3. 누적저장 또는 검토완료 경로로 코퍼스에 반영합니다. 신규 개별 기록은 같은 계약의 수정·삭제도 반영하며 이전 이력을 보존합니다.
4. 다른 계약 검토 시 확정 의견을 해당 체크의 검색·매핑 보조로 활용합니다. 태그가 같거나 과거 이상없음이 많다는 이유만으로 새 계약을 자동 통과시키지는 않습니다.

구 집계에 이미 들어 있는 계약은 계약별 기여분을 알 수 없어 새 개별 기록을 별도 보존합니다. 기존 통계를 임의로 빼거나 중복 합산하지 않으므로 옛 집계 분포와 새 개별 판정이 다를 수 있습니다.

## 간편 점검

평가 탭 첫 화면에서 다음 두 버튼을 사용합니다. 복잡한 독립 검수·승인 시험은 고급 평가에 접혀 있습니다.

- 누적 판정 점검: 시스템이 근거를 충분히 찾지 못했는데 사람이 이상없음으로 판단했던 항목과 과거 보완 의견을 모아 보여줍니다. 개선 우선순위 점검이며 원문 재채점은 아닙니다.
- 현재 계약을 과거 판정과 비교: 원문·별첨·역할·체크 기준이 일치하는 저장 기록에 한해 과거 자료 참고 전후의 매핑을 다시 실행합니다. 기존 판정은 바꾸지 않습니다. 사람이 근거 조항을 명시적으로 확인한 경우에만 조항 일치도를 계산합니다.

동일 계약을 다시 열었는데도 비교가 안 되면 당시 별첨·문서 버전·유형·역할이 같은지 확인하세요. 원문 지문이 없는 옛 집계만으로는 비교할 수 없습니다.

## 예전 개별 판정파일이 있는 경우

1. 당시 검토한 본문·별첨을 입력 화면에서 분석합니다.
2. 평가 화면의 예전 개별 판정파일 연결을 열어 해당 계약의 판정 JSON을 선택합니다. 29건 집계 백업을 선택하는 기능이 아닙니다.
3. 확인자를 입력하고 동일 문서 버전 및 사람 확정판정의 재사용 가능성을 확인한 뒤 현재 문서와 연결을 누릅니다.
4. 현재 계약을 과거 판정과 비교를 실행합니다.

시스템 자동판정을 사람 정답으로 바꾸지 않습니다. 구 조항 번호도 현재 정답 조항 번호로 자동 승계하지 않습니다. 집계자료밖에 남아 있지 않다면 없는 개별 판정을 복원하지 않습니다.

## 자동판정 보류 개선 범위

- 다른 곳에 사용되지 않는 무관한 독립 정의문은 승인형 자동판정의 전역 보류에서 제외합니다.
- 바로 이어지는 명시적 지시어 문장에 나뉜 요건을 함께 확인합니다. 다른 조항·문서의 단어를 임의로 합치지 않습니다.
- 본문 매핑이 확인 필요나 검토 후보여도, 실제 문서 묶음에서 승인 규칙의 모든 요건을 확인하면 매핑 상태만으로 다시 보류하지 않습니다. 미선정·비적용, 사람 재지정, 실제 단서·충돌은 계속 차단합니다.
- 본문과 별첨에서 서로 다른 필수 요건을 각각 확인할 수 있지만, 별첨 이름이나 사용 체크박스만으로 충족 처리하지 않습니다.

자동판정은 해당 규칙의 검증·승인·활성화와 본건 입력 확인이 있는 경우에만 작동합니다. 이 ZIP은 새 규칙을 자동 승인하지 않습니다. 승인 규칙이 없는 환경에서는 자동판정률이 즉시 높아지지 않을 수 있습니다. 코드·코퍼스가 달라지면 기존 승인은 재평가가 필요합니다.

관련 없는 모든 예외문을 자동으로 구분하는 범위 해석은 아직 완성되지 않았습니다. 현재 계약 비교는 매핑 비교이며 독립 시험 성적이나 실제 자동판정률이 아닙니다.

## 폐쇄망에서 확인할 사항

- 기존 태깅자료·코퍼스·판정이 남아 있는지 확인합니다.
- 판정 수정 후 누적저장하고 다시 열어 최신 결과와 리포트·검토완료 상태가 일치하는지 확인합니다.
- 본문·별첨이 같은 계약은 비교되고, 별첨을 변경하면 비교가 차단되는지 확인합니다.
- HWP·HWPX·DOCX·PDF에서 실제 추출 내용과 별첨 구역이 맞는지 확인합니다.
- 검색·판정 저장·평가 실행 시간을 기존 버전과 같은 자료·장비에서 비교합니다. 로컬 합성자료 시험은 폐쇄망 실측을 대신하지 않습니다.

## 설치 파일

기존 실행기를 열고 contract-review-v1.65.0.crupdate를 선택합니다. 처음 사용하는 PC만 최초설치 실행기를 새로 사용합니다. Word 안내 대신 이 문서와 설치 TXT를 제공합니다.
