등록 표준 전체가 본건 본문·별첨과 일치하는 경우에 적용할 수 있는 존재 질문 6종을 연결했습니다. 저장된 보안관리약정서 3종의 동일 원문 등록 시험에서는 연결·판정이 기존 0개에서 GA 5개·일반 6개·재위탁 6개가 됐습니다. 실제 앱의 일반 약정서 시험에서는 적용 범위에 들어온 5개 항목이 자동판정되어 ②열로 이동했습니다. 최신 사용자 정정과 충돌 특약에 따른 철회, 기존 자동 등록 자료의 무승인 갱신도 확인했습니다.

Node 720개·Python 106개, 격리 브라우저 8개 흐름을 통과했습니다. 공개 자료 5종의 직접 자동충족은 여전히 0개입니다. 위 등록 시험은 새로운 계약에 대한 독립 정확도나 실업무 자동판정률이 아닙니다. 임의 문구의 일반적 의미 해석과 복잡한 참조 해소까지 완료한 것은 아닙니다. 적용 방법과 한계는 [v1.79 변경안내](release-v1.79.md)에 기록했습니다.

## v1.78 추가 구현

정형 의무 5종의 요소 비교를 직접 판정·표준 비교·과거 조항 비교에 연결했습니다. 원문 평가자료와 코퍼스의 문서·맥락·질문 지문이 일치하는 사용자 판정을 자동 복원하고, 태깅자료 ID를 출처 추적에 연결합니다. 전조·번호가 확인되는 전항·내부 명시 준용을 원문과 함께 비교합니다. 내부 평가의 판정 복원과 반복 자료 준비 비용도 개선했습니다.

Node 708개·Python 106개, 격리 브라우저 7개 흐름을 통과했습니다. 이번 배포와 남은 개발의 정확한 범위는 [v1.78 변경안내](release-v1.78.md)에 기록했습니다. 공개 표준자료 5개에서 직접 규칙 자동충족은 여전히 0개이며 실업무 자동판정률 향상을 실측한 것은 아닙니다. 아래 v1.67 내용은 과거 이력입니다.

v1.67: 원문 재매핑 평가, 추가 정형 패턴 및 신규 계약의 동일 패턴 이력 연결.

## 코드 변경

- ReviewReplay: 저장된 예전 coverage를 버리고 현재 ReviewCore로 조항 분할·매핑·별첨 검색을 실행. 원계약 역할을 확인하고 현행 체크가 같은 라벨만 비교. 명시적인 사람 매핑 정답은 근거 내용 지문으로 비교.
- StandardAuto v2: CMN-08/09/11/15 추가. CMN-08/11의 기존 자동금지 정책은 일반 경로에서 유지하고 해당 질문·판단 기준과 정확히 일치하는 상호 정형 패턴만 별도 검사. 임의 문구나 요건 누락은 불허.
- 본문·별첨 결합 및 부족한 별첨 매칭 후보 보강. 단어 점수가 아니라 정형 문구의 실제 존재로 후보만 보강하며 최종 통과는 전체 관련 문구 검사 후 결정.
- 원문 기반 사람 충족·보완·위험수용의 패턴 증거를 코퍼스에 보존. 같은 맥락의 다른 계약에서 이력을 연결. 보완·위험수용 이력은 통과를 차단. 빈도는 신뢰도나 독립 정답 표본으로 사용하지 않음.
- 독립 제목·괄호 없는 제목과 좁은 표기 변형 지원. 명시 참조와 전역 우선·배제 문구는 보수적 유지.

## 한계
