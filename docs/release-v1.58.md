# v1.58.0 — 검토 완료 집계·판정 유지 수정

## 수정

- 리포트는 조치 분류별 개수를, 조항 화면은 별도 판단 기준을 사용하던 불일치를 해소했습니다. 잔여 목록과 검토 마치기는 동일한 목록을 사용합니다.
- 미연결·quiet·원계약 커버 상태라도 필요한 판정은 조항 화면에 표시합니다. 판정을 마친 미연결 항목도 화면에서 사라지지 않습니다.
- 리포트에 남은 항목명, 확인 사유와 해당 판정으로 이동하는 버튼을 표시합니다. 문서 완결성 확인도 목록에 포함됩니다.
- 같은 이상없음 버튼을 다시 눌러도 취소되지 않습니다. 재확인이 필요한 경우 같은 버튼으로 확인을 갱신하고 메모를 유지합니다. 취소는 별도 버튼과 확인창을 사용합니다.
- 메모는 입력 즉시 저장하며 제거된 화면의 이전 입력이 뒤늦게 판정을 덮지 않도록 했습니다. 사유 변경 시 문서 지문과 재확인 상태를 보존합니다.
- 업로드한 부속서류 검색을 본문 부재 항목에서 전체 적용 항목으로 확장하고, 미연결 검토카드에 서류명·조항·관련 문구를 표시합니다.
- 이행 위치·문구 필요성의 내부 분류 배지를 기본 카드에서 제거했습니다.

## 안전 기준 및 범위

부속서류의 유사 문구를 찾았다는 사실만으로 이상없음을 자동 확정하지 않습니다. 표준서식 사용 표시나 파일명만으로 검토가 완료되지 않습니다. 검증·승인된 자동 규칙과 직접 판정이라는 기존 안전 기준을 유지합니다. 이번 변경은 표준약정의 모든 법적 요건을 자동 확정하는 기능을 새로 제공하는 것은 아닙니다.

폐쇄망 실자료를 반출하거나 열람하지 않았습니다. 합성 계약으로 숨은 항목 표시, 반복 클릭, 재확인, 메모·사유 보존, 재분석·저장 재로드 후 완료 유지와 기존 안전장치의 회귀 테스트를 수행합니다.

업데이트 전 검토의견을 백업하고 기존 영구 실행기의 업데이트 가져오기로 적용하세요. 부속서류 검색 확대를 적용하려면 본문과 부속서류를 불러온 상태에서 재분석하세요. 원문·역할 등 실제 입력 조건이 달라진 판정은 재확인이 필요할 수 있습니다.
