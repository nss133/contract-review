# v1.88.0 최종 검증기록

검증일: 2026-09-18. 승인된 6차 실행계획의 구현·로컬 검증 기록이다. 폐쇄망 실제 계약의 자동판정률을 측정한 자료는 아니다.

## 구현 범위

206개 ID를 전수 대조하고 활성 184개·비활성 22개로 정리했다. 활성 중 약정 확인 62개는 같은 판정 경로에 연결했고, 명확성 52개·적정성 및 유불리 70개와 구분했다. 22개는 범위 제외 9개·실제 이행 제외 9개·통합 4개이며 원 이력은 보존한다.

체크 ID와 판단 의미 버전으로 연결한다. 문구 표시가 바뀌거나 무관한 별첨·부서·태그 DB가 추가되었다는 이유만으로 현재 약정 확인을 보류하지 않는다. 표준 등록은 자동 연결하고, 자료실에만 있는 약정과 본건에 명확히 편입되거나 실제 반영된 약정은 구별한다. 수기 결론·코멘트의 내용 태그와 결과 태그를 분리하고 새 수기 저장에도 적용한다.

자동 완료는 기존 조항별 삼단 화면의 ② 확인 완료로 이어진다. 별도 승인 작업대나 통합 검토 공간을 추가하지 않았다. 최신 수기 결과, 명시적 자동판정 중지, 기존 태그·코퍼스·표준 자료를 보존한다.

## 판정·상태 검증

최종 브라우저에서는 다음을 검사했다.

- 별첨의 제1조 재시작, 숨은 미결, 완료 후 재출현, 최신 수기 수정 보호, 본문 변경 뒤 낡은 자동판정 해제.
- 페이지 재실행, 명시적 중지 설정 보존·무승인 재개, 표준 등록 후 실제 자동판정·재실행.

- 실행기에 합성 태그 1건·검토이력 2건을 넣고 재실행 및 다음 버전 모의 업데이트 후 유지.
- 전용 브라우저 컨텍스트와 합성 입력만 사용. 사용자 브라우저 저장소를 초기화하지 않았다. 실제 파일 입력·상태 시험 및 성능 시험에서 외부 요청 0건.

표준 등록 라이프사이클 시험의 일부 입력은 합성 추출 fixture를 사용한다. 이것을 실제 4형식 파일 시험의 성과로 중복 계산하지 않는다. 실행기 시험의 다음 버전은 실제 미래 배포가 아니라 저장소 보존을 확인하는 모의 업데이트다.

## 태그·표준·코퍼스 기여

합성 10사례를 7가지 소스 설정으로 비교했다. 직접 양성 2개는 모든 보조자료를 꺼도 유지된다. 명사형 태그 별칭과 명시적으로 편입된 표준은 각각 고정 사례의 자동 확인을 0→1로 늘렸다. 동등 문구가 본건에 있는 경우 자동 확인은 1→1이고 표준 연결이 0→1로 늘어난다.

코퍼스·법률검토 자료는 각각 현재 표현과 맞는 참고 연결 2개를 0→2로 늘렸고, 표현 차이가 있는 한 사례의 올바른 조항 매핑을 0→1로 보강했다. 과거 결론을 현재 이상없음으로 승격하지 않는다. 음성 4개는 모든 설정에서 오통과 0이며, 원문 인용 좌표 46/46·힌트 조항 16/16·대상 조항 매핑 5/5가 일치했다. 편입 표준의 인용 10회는 현재 제출 본문 인용과 분리한다. 실제 계약의 매핑 정확도로 일반화하지 않는다.

실행 스크립트는 build/audit_v188_sources.cjs이며, 상세 설정·집계는 v1.88-source-ablation.json과 평가자료 문서 8절에 있다. 태그의 부정·조건 표현을 삭제하여 반대 문구를 통과시키는 경로도 반례 시험으로 차단했다.

## 처리시간

최종 HTML을 합성 14조항·태깅 300문서·코퍼스 100건 및 수기 판정 400개로 비교했다. 같은 장비와 독립 컨텍스트를 사용했다. 반복 재분석·렌더링은 워밍업 2회 후 12회, P50/P95는 nearest-rank 방식이다. 최초 분석은 1회이므로 분위수로 부르지 않는다.

반복 재분석은 빨라졌지만 최초 분석과 렌더링은 조금 늘었다. 질문 통합 및 자동 완료의 수가 달라 같은 작업량의 미세 성능 비교는 아니며, 위 4→13을 폐쇄망 자동판정률로 환산하지 않는다. 최초 분석의 추가 비용은 새 의견·태그 색인과 현재 표현 검색을 포함한다. 별도 함수 계측에서 새 색인 생성 1회 35.4 ms·현재 표현 조회의 포함 시간 40.9 ms를 확인했다. 중첩 포함 시간은 합산하지 않는다. 발견한 동일 자료의 이중 색인은 제거했으며 매핑·자동판정·리포트가 자료 버전당 같은 색인 1회를 재사용하는 시험을 통과했다.

첫 기본 실행과 별도 계측 실행의 원시 측정값은 v1.88-runtime-benchmark.json에 구분하여 저장했다. Chrome 153 / macOS arm64 장비의 합성 입력 관측값이며 실제 파일 변환·자료 적재·브라우저 시작·비동기 평가자료 저장·GPU 페인트 완료는 이 표의 측정에서 제외한다. 더 큰 폐쇄망 DB와 실제 장비의 시간을 보장하지 않는다.

실제 4형식 입력부터 완료까지의 별도 종단 시험은 DOCX 1,931 ms, HWPX 1,910 ms, HWP 1,910 ms, PDF 1,926 ms였고 형식마다 핵심 6개가 자동 완료되었다. 파일별 한 번의 합성 시험값으로서 P50/P95가 아니다.
