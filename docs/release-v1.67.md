# v1.67 추가 개발 통합본

기존 실행기에 동봉된 .crupdate를 적용합니다. v1.66을 먼저 설치하거나 평가자료를 수집해 올 필요는 없습니다. AI·외부 API는 사용하지 않습니다.

## 추가 구현

- 기존 기간·부가세·지급·관할 외에 비밀정보 정의, 상호 중대한 위반에 대한 30일 서면 시정·서면 해지, 상호 귀책에 따른 통상손해 배상의 제한된 문구 패턴을 추가했습니다. 총 8개 체크의 정형 패턴입니다. 단순 조항 존재나 키워드만으로 해지·손해배상을 통과시키지 않습니다.
- 본문·별첨을 함께 검사합니다. 정형 근거가 실제 별첨에 있는데 유사도 문턱 때문에 검색되지 않는 경우 후보를 보강합니다. 파일명이나 참조만으로 충족시키지 않으며 전체 요건·충돌 검사와 본건 적용 확인은 별도입니다.
- 사람이 확정한 정형 근거의 패턴·범위·출처를 코퍼스에 저장합니다. 다른 계약에서도 같은 조건·같은 요건 패턴을 확인하면 과거 이력을 연결합니다. 과거 횟수로 통과시키지 않고 현재 문구를 다시 검사합니다. 같은 패턴의 보완·위험수용 이력은 자동통과를 막습니다.
- 내부 평가를 저장된 옛 매핑 상태가 아닌 원문 기반 조항 분할 → 현재 매핑 → 실제 별첨 검색 → 자동판정 순서로 변경했습니다. 사람이 명시적으로 확인한 근거 문구가 있으면 매핑 일치도도 집계합니다.
- 평가에 자기 정답·과거자료 검색을 투입하지 않습니다. 삭제된 유형·바뀐 체크·원계약 연결 불일치는 별도 제외/실패로 표시합니다. 취소 이후에는 패턴 중지 설정을 변경하지 않습니다.
- 괄호 없는 ‘제1조 해지’, 번호 없는 ‘손해배상’ 등 알려진 독립 제목을 구역으로 인식합니다. 명시적인 주체·조건을 보존하는 제한된 동의어·표기 변형을 지원합니다. 숫자·부정·예외를 지워 문구를 억지로 맞추지는 않습니다.

## 사용

계약 분석 후 조항별 검토의 ‘정형 문구 자동판정’에서 본문·별첨 적용과 유형·역할을 확인하고 실행하세요. 별도 규칙 ID 입력은 없습니다. 사람이 완료한 판정은 덮어쓰지 않습니다. 원문이 바뀌면 재확인하고, 무관한 코퍼스 추가만으로 원본 확인을 다시 요구하지 않습니다.

‘내부 평가자료 자동 저장’은 선택 사항입니다. 켜면 이후의 원문·판정을 내부 브라우저에 저장합니다. ‘저장된 검토로 일괄 점검’으로 재실행할 수 있습니다. 이 자료는 원문을 포함하므로 폐쇄망 밖으로 반출하지 마세요. 별도 내부 백업·복구 버튼을 사용합니다.

## 정확한 한계

- 보안관리약정 전체의 모든 보안 의무를 판단하는 기능은 아닙니다. 현재 추가한 정의 요건과 기존 별첨 결합·승인 규칙의 범위만 처리합니다.
- 새로운 해지·손해배상 패턴은 명시된 문구와 허용된 표기만 처리합니다. 임의해지·일방 면책·배상 상한·낯선 관련 문구는 보류합니다. 모든 법적 충분성 또는 모든 계약에 대한 공정성을 보증하지 않습니다.
- 다른 계약의 이력 연결은 이번 버전에서 사람의 원문 근거 패턴을 저장한 기록부터 가능합니다. 원문 없는 구 집계를 자동 복원하지 않습니다. 이력 연결만으로 인식하지 못하는 새 표현이 자동으로 학습되는 것은 아닙니다.
- 평가 시작점은 저장된 추출 텍스트입니다. HWP/HWPX/DOCX/PDF 바이너리 재추출과 계약 유형 자동선택 자체의 재평가는 포함하지 않습니다. 독립 실자료 정확도·폐쇄망 자동판정률은 미측정입니다.

이 안내는 v1.66에서 추가 개발이 남았던 영역 중 이번에 구현한 범위와 남아 있는 일반화 한계를 구분합니다. 1~3차의 모든 표현·모든 기능이 완료됐다는 의미로 읽지 마세요.
