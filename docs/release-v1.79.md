# v1.79 — 존재 질문 확대·등록 표준 전체 활용

## 바뀐 내용

- 직접 판정의 대상 질문을 13개에서 18개로 확대했습니다. 수탁자의 위탁 의무 위반 배상책임, 감독원 검사·자료제출 수인, 제3자 지식재산권 침해 주장에 대한 방어·면책, 복수 언어 불일치 시 우선 언어, 비밀정보 침해 배상책임의 존재 질문을 추가했습니다. 현재 질문과 일치하는 완전한 약정 문장에만 적용하며 종합적인 유불리 판단과 구별합니다.
- 접근제한 질문에 ‘업무상 최소권한’만을 유일한 통과 요건으로 추가하던 제약을 수정했습니다. 개인정보 접근 제한 의무가 명시된 정형 문장도 인식합니다. 접근 제한 면제·주체 변경은 통과하지 않습니다.
- 문장 중간의 단순 줄바꿈은 원문 위치를 보존하며 결합합니다. 조·항·호·새 주체 또는 표시용 입력란을 넘어 임의로 합치지 않습니다.
- 같은 문서의 문장 복구 결과를 재사용하고 문서 전체를 문장마다 반복 정규화하던 처리를 제거했습니다. 본문·파일명·문서 구성이 바뀌면 캐시를 갱신합니다.
- 특정 항의 위반에 따른 배상책임을 계약 전체의 모든 의무를 수정하는 문장으로 읽던 과잉 차단을 수정했습니다. 전역 면제·우선적용·배제 문장은 계속 검사합니다.
- 협의 불성립 시 법원을 지정하는 순차 분쟁해결 문장을 인식합니다. 중재·소송의 미선택 양식이나 관할 법원이 불명확한 자료를 임의로 완성하지 않습니다.
- 관련 조항 기반 과거 판단 재사용의 대상도 15개에서 20개 질문으로 확대했습니다. 원문·질문·적용 맥락 및 최신 사용자 정정 확인은 유지합니다.

## 등록 표준서식의 새 경로

기존 보안관리약정서는 나열식 보호조치, 조건, 참조조항 때문에 자동 연결이 0개였습니다. 이제 정의된 존재 질문 6종에 대해 등록 표준 전체가 본건 문서 또는 별첨과 일치하면 질문별 약정을 확인하여 자동판정합니다. 보호조치·접근제한·점검·배상책임·감독당국 협조·관할이 대상입니다. 모든 표준서식이나 모든 질문이 자동 연결되는 것은 아닙니다.

저장된 실제 약정서 3종의 등록 시험에서는 기존 0개에서 GA 5개, 일반 6개, 재위탁 6개로 연결·판정됐습니다. 이는 같은 등록 원문을 본건에 넣는 경로의 동작 확인입니다. 새로운 계약의 독립 정확도나 전체 업무 자동판정 비율을 뜻하지 않습니다.

표준 전체 일치는 띄어쓰기·줄바꿈과 기존에 식별한 독립 입력란을 제외한 내용을 보존합니다. 본문 숫자·기간·주체·조건을 마음대로 바꾸지 않습니다. 표준의 일부 문구만 있는 계약은 이 경로로 통과하지 않으며 기존 조항·의무 요소 비교 경로를 사용합니다. 자유롭게 채운 미식별 입력란도 전체 일치를 깨뜨릴 수 있습니다.

다른 본문·별첨에 관련된 추가 문구, 표준 배제·우선순위 변경이 있으면 보류합니다. 최신 사용자 보완·위험수용 판정과 충돌하면 표준 경로로 우회 승인하지 않습니다. 실제 이행 여부를 확인하는 기능은 추가하지 않았습니다.

## 적용 방법

기존 실행기에서 v1.79.0 업데이트 파일을 적용하고 계약을 재분석합니다. 기존 자동 등록 표준은 연결 규칙 7로 자동 갱신되므로 재승인할 필요가 없습니다. 수동 연결·사용 중지는 보존합니다.

표준서식을 등록만 했다고 본건에 적용되는 것은 아닙니다. 실제 검토 대상 본문 또는 별첨에 해당 내용이 있어야 합니다. 폐쇄망에서 쓰던 자료·브라우저 프로필을 그대로 사용하고 사용자 원문을 외부로 반출하지 않습니다.

## 검증과 남은 범위

Node 720개·Python 106개, 총 826개 회귀시험을 통과했습니다. 격리 브라우저에서 등록 표준, 의무 요소·출처 연결, 과거 판단 재사용, 자동판정 생명주기, 파일 등록, 표준 라이브러리, 표준 비교 확대, 체크리스트 내용의 8개 흐름을 검증했습니다.

일반 보안관리약정서의 실제 앱 시험에서는 적용 대상 5개 항목이 자동 ‘이상없음’으로 판정되고 ②열로 이동했습니다. 등록 연결 6개 중 감독당국 협조 항목은 그 시험 계약의 적용 범위에 없으므로 판정 수에 포함하지 않았습니다. 충돌 별첨·최신 사용자 정정 시 자동판정 철회와 기존 등록 자료의 무승인 자동 갱신도 확인했습니다. 등록 경로의 이 시험은 저장된 추출 텍스트를 사용하며, 바이너리 파일의 추출 정확도를 입증하는 시험은 아닙니다. 별도의 기존 PDF 등록 흐름도 통과했습니다.

브라우저 시험에서 외부 통신과 런타임 오류는 없었습니다. 배포 파일에는 사용자 검토 코퍼스와 시험용 표준약정서 원문을 넣지 않습니다.

공개 자료 5종에는 미입력 양식과 해설서가 포함돼 있습니다. 이 자료군의 직접 자동충족 수만을 올리기 위해 필수 요건을 없애지 않았습니다. 공개 자료와 업무용 보안관리약정서의 시험 결과는 구분합니다.

전 206개 질문의 일반적인 의미 해석, 복잡한 예외와 모든 별첨 참조의 해소, 등록 표준과 의미만 유사한 임의 문구의 자동 판정까지 완료한 것은 아닙니다. 이번 버전은 기존 질문의 존재 요건과 등록 자료 활용 범위를 확장한 배포입니다. 폐쇄망 실자료의 자동판정률·오판율은 별도 실측이 필요합니다.
