# v1.90.0 검증 기록 — 대량 과거자료 분석 중 화면 멈춤

상태: 구현·최종 로컬 브라우저 검증 완료. 실제 폐쇄망 장비 성능은 미확인이다. 배포 파일의 동일성은 아래 검증 명령과 SHA-256 목록으로 확인한다.

## 수정 범위

- 전체 과거 구절 검색기를 후보 선택 전에 만드는 경로를 제거했다. 체크·주제별 기존 후보 최대 200개를 먼저 고르고, 필요한 표현만 지연 생성·검색한다. 기존 후보 순서·최장 일치·동점·상위 5개 의미는 보존한다.
- 과거자료 준비, 매핑, 완결성, 참고 연결은 HTML에 내장된 별도 작업 스레드에서 실행한다. Worker의 참고 결과로 자동 허용 티켓을 생성하지 않는다. 기존 현재 원문 검사가 티켓을 발행한다.
- 실제 진행 단계, 계산 취소, 실패 후 버튼 복구를 연결했다. 작업 스레드가 차단되면 오류를 표시하며 무거운 동기 실행으로 되돌아가지 않는다.
- 본문·별첨·경계·표준·사용 설정·자료 변경을 검증하고, 저장 전 취소에는 결과·판정을 복원한다. 판정 반영 이후에는 취소 버튼을 숨긴다. 저장 실패는 완료로 표시하지 않는다.
- 조항 목록을 나누어 표시하고 전체 재지정 선택지는 해당 목록을 열 때 생성한다. 별첨 완료 카드도 원문 표시 최대 하나를 유지한다. 평가 스냅샷은 비동기 분석 완료를 기다린다.

## 최종 브라우저 수용시험

Chrome 153.0.8010.48 격리 프로필에서 최종 배포 HTML을 고정하고 v1.89 업데이트의 HTML과 비교했다. 10개 조건 모두 통과했다. 세부 합격 기준과 원시 값은 [수용시험 설명](v1.90-performance-acceptance.md) 및 [원시 결과](v1.90-performance-acceptance.json)를 따른다. 초안 측정값을 최종 결과로 사용하지 않는다.

CPU 4배 조건의 최장 화면 공백·LongTask 각각 1,000ms 미만 기준을 통과했다. Worker 자체의 CPU 지연 API는 지원되지 않아 페이지 설정의 Worker 상속 정도는 검증하지 못했다. 총시간의 전후 비율을 동일한 전체 CPU 지연 조건의 향상률로 제시하지 않는다.

수기 마지막 입력의 실제 새로고침·재분석 보존, 선택목록 해당 1개만 5→59 항목 확장, 별첨 근거 12개 내부 보존·버튼 1개·본문 인용 0개·팝업 좌표 일치도 통과했다. 외부 요청은 0건이다. CPU 4배의 자료 전달 복제는 29.3ms, 화면 렌더 구간은 68.6ms였다. Worker 왕복·렌더 등의 구간은 서로 겹칠 수 있어 단순 합산하지 않는다.

## 보존과 배포

사용자 첨삭 원본 SHA-256은 765546096ebc65fc3ed43e14ba152d3e465932f8a815d5930820da738196bcab로 작업 전후 동일하다. v1.89 ZIP 및 업데이트, v1.88 ZIP, 지식 기준표는 보존한다. 실제 계약·코퍼스·태깅 DB를 새 ZIP에 내장하지 않는다.

build/verify_offline_distribution.py는 최종 시험 HTML의 위 SHA-256을 고정해 ZIP·업데이트·직접 실행본의 바이트, 앱 소스·내장 Worker·지식·엔진 지문·최신 안내문을 대조한다. ZIP 자체와 업데이트 파일 지문은 dist/contract-review-v1.90.0.sha256.txt에 별도로 기록하여 ZIP에 자기 자신의 해시를 넣는 순환을 피한다.

## 해석의 한계

- 시험은 임시 브라우저와 합성 자료만 사용한다. 사용자 폐쇄망 저장소·실자료·프로파일을 읽거나 수정하지 않았다.
- 합성 태그 문서 500건×고유 근거 52문장은 52개 태그 칼럼 자체와 다르다. 이전 실패를 드러낸 문자열 다양성을 재현한 부하이며 실제 데이터 분포를 대표하지 않는다.
- 페이지 CPU 4배 설정의 Worker 직접 적용 가능 여부·상속 정도를 구분한다. 총시간 감소를 전체 계산이 동일하게 4배 지연된 성능 향상률로 일반화하지 않는다.
- 단회 측정은 평균·P95·실계약 자동판정률이 아니다. 브라우저 경고창의 발생 기준·실제 폐쇄망 기기와 보안정책·스캔 OCR·암호/손상 파일의 모든 경우를 보장하지 않는다.
- 기존 v1.89 로컬 통과 뒤 폐쇄망에서 재발한 사실을 보존한다. 이번 결론은 재현 조건의 응답성·기능 보존 시험에 한정한다.
