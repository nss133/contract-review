# v1.61.0 — 독립 검수·선정 쟁점 매핑 비교 연결

## 사용

‘검토 정확도 평가’에서 계약의 초안 확인을 마친 뒤 아래 ‘독립 정답 검수·매핑 비교’로 진행합니다.

1. ‘현재 자료로 정답 검수 시작 준비’를 누릅니다. 원문·별첨·문서 버전·질문·초안 버전이 고정됩니다. 별도의 ID 입력이나 파일 왕복은 필요 없습니다.
2. 과거 의견을 보지 않은 독립 검수자가 ‘독립 검수 화면 열기’를 누릅니다. 준비 화면과 예측·다른 검수 결과는 숨겨지고 중립 질문과 원문만 표시됩니다.
3. 질문별 판단, 직접 근거 조항, 원본 위치·이유를 입력합니다. 자료가 없으면 판단불가로 기록합니다. 중간 저장 후 닫고 이어서 작업할 수 있습니다. 제출 시 독립성·원본 대조를 확인합니다.
4. 다른 독립 검수자가 같은 절차로 제출합니다. 준비자와 동일 이름, 중복 검수자, 잘못된 조항 위치, 일부 질문 미검수는 제출하지 못합니다. 이름 입력은 조직 인증이 아니므로 실제 독립성은 내부 검수 절차로 관리해야 합니다.
5. ‘두 검수 결과로 매핑 비교 채점’을 누릅니다. 태그 제외·태그 보조의 최상위/상위 3개 근거 연결, 문제 항목 비노출과 오류 목록을 비교합니다. 저장된 평가 불러오기로 기록을 다시 볼 수 있습니다.

## 이번 평가의 정확한 범위

- 준비자가 확인한 활성 체크를 대상으로 한 **선정 쟁점 부분평가**입니다. 검토하지 않은 체크의 정답을 만들지 않습니다. 전체 계약의 누락률·정확도를 대표하지 않습니다.
- 두 검수자의 판단과 직접 근거 조항이 일치한 항목만 합의 정답으로 채점합니다. 이견·판단불가는 별도 표시하며 정확한 매핑 분모에서 제외합니다. 이견이 남은 전체 자료를 확정 골드셋이라고 표시하지 않습니다.
- 본문·별첨을 문서별로 분할한 뒤 고유 위치를 붙여 함께 조항검색합니다. 전체 체크 카탈로그를 대상으로 하는 검색 진단이며 실사용의 유형·역할·규제 적용범위 선택 성능과는 구분합니다.
- 과거 계약검토·법률검토 검색은 실행하지 않습니다. 두 모드 비교는 현재 계약 문장의 태그 매칭 보조 효과를 측정하며 적재 이력자료의 기여도 비교가 아닙니다.
- 자동판정은 실행하지 않으며 잘못된 이상없음 0건·자동판정 정확도 100%를 주장하지 않습니다. 기존 자동승인 설정과 검토 중인 계약 판정도 변경하지 않습니다.
- 원문·초안·체크 기준이 바뀌면 이전 기록으로 새 평가를 진행하지 못합니다. 과거 스냅샷·검수·채점 기록은 보존됩니다. 백업에 포함되며 복구된 초안은 재확인 대상이므로 이전 평가를 현재 유효한 결과로 자동 승계하지 않습니다.

## 다음 단계

계열·시점 분리된 다계약 시험셋, 실사용 적용범위와 매핑의 연결 평가, 계약·법률검토 검색 효과의 분리 비교, 검수 이견 조정, 검증 결과를 반영한 매핑 규칙 개선 및 자동판정 범위 확대가 남아 있습니다. 본 배포만으로 2차 전체나 최종 계획이 완료된 것은 아닙니다.
