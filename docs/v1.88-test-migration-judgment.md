## 변경한 기대값

- 과거 결론의 재사용 성공·불일치를 직접 자동판정의 필수 상태로 요구하던 시험은 현재 원문 독립 판정으로 변경했다. 과거 자료의 원문·맥락 대조 모듈 자체의 엄격한 시험은 보존한다.
- 관할·기간·배상 등 존재 질문에서 회사 지위 미입력, 무관한 별첨·제목·부서·문구 표시 변경으로 보류하는 기대를 제거했다. 명시적 의무주체 역전과 충돌은 필요한 질문에만 유지한다.
- 계약상 점검 협조에 모든 감독수단·특정 반복주기를 강제하지 않는다. 요청이 있을 때 협조한다는 약정도 존재한다. 점검을 거절하거나 협조를 명시적으로 면제하는 문구는 반례로 유지한다.
- 다른 쟁점의 보호조치 제한이 독립적인 암호화 약정을 자동 무효화하지 않는다. 같은 암호화 의무의 선택·면제·대체는 계속 반례다.
- 백업자료 보호와 백업설비 확보처럼 기준표에서 대체 가능하게 한 요소는 하나의 독립 근거로 확인한다. 모든 단어가 반복되어야 한다는 옛 문법 시험을 현행 최소요건과 분리한다.
- 일반적인 외부 규정 인용을 복원하지는 않지만, 그 사실만으로 이미 읽힌 본건의 보호조치를 무효화하지 않는다. 같은 약정을 배제·제한하는 명시 참조와 누락은 따로 검증한다.
- 제외·통합 ID의 옛 양성 자료는 삭제하지 않고 비활성 확인 시험으로 돌렸다. 개인정보·비밀유지 배상은 CNS-DAMAGE의 현재 질문으로 검증한다.
