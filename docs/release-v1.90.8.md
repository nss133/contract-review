# v1.90.8 — 절제된 브랜드 색감·그라데이션

- 리포트 헤더: 넓은 오렌지 띠를 없애고 짙은 네이비에서 블루로 이어지는 정적인 그라데이션을 적용했다. 작은 오렌지 표식으로 브랜드 포인트를 남겼다.
- 메뉴·본문: 짙은 관리 메뉴 띠와 오렌지 제목 면을 밝은 중립색으로 바꿨다. 긴 체크리스트 설명과 의견을 읽는 영역에는 강한 그라데이션을 넣지 않는다.
- 주요 버튼: 오렌지 계열의 미세한 명도 변화, 부드러운 모서리와 얕은 그림자를 적용했다. 차트의 범주별 색과 판정 상태 표시는 유지한다.
- 인쇄: 화면 장식용 그라데이션은 제거하고 밝은 바탕·짙은 글자로 출력한다. 차트와 숫자는 유지한다.
- CSS 표시 변경이며 기존 기능·문구·삼단 구성·자동판정 엔진·저장 형식은 그대로다. 움직이는 그라데이션·배경 블러·외부 라이브러리·폰트·통신은 추가하지 않는다.

기존 공식 CI 주색상은 유지하되 그라데이션의 네이비·중간색·명도 조정은 앱 디자인용 변형이다. 공식 CI 가이드의 별도 그라데이션 규격이라는 의미는 아니다.

## 업데이트

기존 실행기의 버전 설치·업데이트에서 ZIP 안의 contract-review-v1.90.8.crupdate를 불러온다. 실행기 위치·이름·브라우저 프로필은 유지한다. 기존 태깅자료를 다시 적재할 필요는 없다. 작성 중인 의견은 새로고침 전 저장한다.
