# v1.70 — 체크리스트 질문 자체 재작성

v1.69의 별도 ‘통합 쟁점 검토’ 영역과 하위 체크를 접어 보는 구성을 폐기했습니다. 기존 ① 원문 / ② 확인 완료 / ③ 검토할 항목·의견의 삼단 화면을 사용합니다.

## 내용 변경

44개 원질문을 실제 운영 체크리스트에서 제거하고, 12개 새 질문으로 대체했습니다. 전체 항목은 238개에서 206개로 변경되었습니다. 새 질문마다 하나의 ID·매핑·판정만 있으며, 하위 체크나 별도 통합 판정은 없습니다. 세부 관점은 질문 아래 설명 문장에 녹였습니다.

| 새 항목 | 대체한 원항목 |
|---|---|
| 손해배상·면책·지연책임의 합리성 | CMN-05-2, CMN-11, CMN-12, CMN-14, RISK-06, SP-DEL-02 |
| 비밀유지 약정의 적정성 | CMN-15, CMN-16, NDA-01~10, NDA-21 |
| 계약 해제·해지 사유와 절차 | CMN-08, CMN-09 |
| 대가 산정·지급·정산의 명확성 | CMN-03, CMN-04, CH-01 |
| 계약기간·갱신 조건 | CMN-06, CMN-07 |
| 산출물 권리 귀속·이용 범위 | CMN-17, ITDL-01 |
| 개인정보 위탁 범위·목적 제한 | PRIV-01, PRIV-02, PRIV-04, PRIV-14 |
| 개인정보 재위탁 통제 | PRIV-05, PRIV-15 |
| 개인정보 위탁 사실 공개 | PRIV-09, PRIV-10 |

| 핵심주주 경업·전업 의무 | SH-EXIT-01, SH-EXIT-02 |

이전에 제안한 모든 묶음을 기계적으로 하나의 질문으로 만들지는 않았습니다. 금융위탁·개인신용정보·하도급의 특별 기준, 소스 인도, 고객 이관 등 대상·효과가 다른 의무는 독립 질문으로 유지합니다.

## 판정·평가 보호

- 새 질문은 CNS-로 시작하는 새 ID를 사용합니다. 예전 개별 판정과 v1.69의 묶음 판정은 보존·내보내기하되 새 정답으로 복제하지 않습니다.
- 같은 계약의 예전 보완·위험수용 의견은 새 카드의 참고 문장에 노출하고 자동판정을 막습니다. 새 질문에서 사람이 다시 판정할 수 있습니다.
- 새 판정부터 일반 검토 코퍼스와 평가에 동일한 한 개의 질문으로 누적됩니다. 구 질문의 정답을 새 질문의 정확도 표본으로 자동 치환하지 않습니다. 원문 재평가에서 항목·기준이 달라진 구 항목은 비교 대상에서 제외합니다.
- 제한된 정형 자동판정은 새 질문의 요건을 다시 확인합니다. 대금은 금액·지급·정산이 모두 필요하며, 비밀정보 정의 하나만으로 넓어진 비밀유지 질문을 자동통과시키지 않습니다. 따라서 통합 전후 자동판정률의 분모는 직접 비교할 수 없습니다.
- 지체상금은 손해배상 질문에 포함되고 일반 지연이자 체크는 없어졌습니다. 특수한 대출·하도급 지연이자 규율은 별도 항목으로 유지합니다.
- 부가세는 기존 자동 사실확인 기능을 유지하되 별도 공간이 아닌 기존 조항별 검토 안에 표시합니다.

## 업데이트

내부 백업 후 동봉된 .crupdate를 기존 실행기에 적용하고 계약을 재분석하세요. v1.69를 거칠 필요는 없습니다. 같은 기존 문서에서 이전 기준의 판정이 보존되더라도, 질문이 바뀐 항목은 새 기준으로 한 번 검토해야 합니다. 이후 같은 문서·조건의 새 판정은 재분석·저장 재로드에서 유지합니다.

표준약정서의 반복 확인 표시 문제는 이 배포의 질문 통합과 별개로 원인·대안을 분석합니다. 이번 버전에 표준서식 원문 자동판정 기능까지 새로 구현했다고 해석해서는 안 됩니다.

개인 코퍼스는 배포본에 내장하지 않았으며 AI·외부 API는 필요하지 않습니다. 실자료 오판률·자동판정률은 폐쇄망 내부 평가로 확인해야 합니다.
