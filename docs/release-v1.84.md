# v1.84.0 — 번호 목록의 약정 인식·호 참조 비교

## 이번에 완료한 개발

‘수탁자는 다음 각 호의 사항을 이행하여야 한다’ 뒤에 번호 목록으로 작성된 약정을 인식하도록 보강했습니다. 항목마다 주체가 반복되지 않아도 앞 문장에 명시된 주체·의무를 연결합니다. 기존 문장형 약정과 같은 요소를 사용하여 직접 판정, 등록 표준 비교, 원문으로 확인된 사용자 판단 재사용에 반영합니다.

지원 범위는 같은 파일·명시 별첨 구역·조 안에서 이어지는 1. / 1) / (1) 방식의 단일 단계 목록입니다. ‘다음/아래 각 호의 사항·의무를 이행·준수한다’ 또는 명시적인 금지 도입문과, 지원하는 완전 문장·동작 명사·‘할 것’ 종결을 조합합니다. 예를 들어 신원조회와 인력 변경 시 인수인계를 번호 항목으로 기재해도 두 요건을 함께 확인합니다.

- 번호 항목만 검색되어도 도입문과 목록 전체를 함께 비교합니다. 단순 키워드를 모아 문장을 만들지 않고, 확장한 문장 전체가 기존의 유한한 요소 규칙에 맞는지 검사합니다.
- 의무의 주체, 횟수, 방법, 조건과 금지를 유지합니다. ‘가능한 경우에만’, ‘노력한다’, 선택적 이행, 번호 누락·중복·혼용, 미해석 항목이 있으면 그대로 자동완료하지 않습니다.
- 본문·별첨·다른 조의 도입문을 임의로 가져오지 않습니다. 같은 인용문이 서로 다른 주체나 조건 아래 반복되면 표준 근거를 임의 선택하지 않습니다.
- ‘제1조 제2호’처럼 해당 목록의 특정 호를 가리키는 참조를 비교합니다. 대상이 유일한 경우만 연결하고, 다른 조에서 그 호의 의무를 제한하는 문구도 포함합니다. 없는 호, 중복 목록, 항·호 중첩과 번호 범위 참조는 추정하지 않습니다.
- 판정 근거에는 합성한 문장이 아니라 원래 도입문과 번호 항목을 표시합니다. 목록형 표준과 문장형 본건, 문장형 표준과 목록형 본건을 양방향으로 비교합니다.

실제 교육·점검·신고 등의 이행 확인 기능은 아닙니다. 새 법적 기준이나 체크리스트 질문을 추가하지 않았으며 직접 규칙 64개·관련 조항 이력 재사용 66개의 질문 범위를 유지합니다. 태그만으로 적정성을 승인하지 않습니다.

## 저장자료·화면

기존 자동등록 표준은 연결 규칙 12로 자동 갱신합니다. v1.83의 등록 규칙 11에서 목록형 약정의 연결이 없던 경우에도 재승인 없이 다시 처리합니다. 수동 설정과 사용 중지 상태는 유지합니다.

자동 이상없음은 기존 조항별 검토의 ② 확인 완료에 반영합니다. 목록 번호·조건·주체·의무 또는 참조 근거가 바뀌면 자동판정을 다시 검사하고, 사용자가 직접 남긴 판정은 덮어쓰지 않습니다. 별도 승인 화면이나 검토 공간은 추가하지 않았습니다.

## 검증

Node 950개·Python 106개, 총 1,056개 회귀시험과 배포 HTML의 브라우저 14개 흐름을 통과했습니다. 신규 단위시험 34개에 목록형 문구, 표준 비교, 최신 사용자 정정, 원문 근거 보존과 오판 방지 사례를 포함했습니다.

배포 HTML에서 23종 질문의 합성 목록형 문구를 검사하고, 그중 인력관리·라이선스·개인정보 교육감독·질권 통지협력·기업결합 신고 협조 5종의 실제 분석 화면을 확인했습니다. 별첨 단독 근거의 ②열 완료 표시, 조건·번호·주체 변경 시 철회, 표준 자동등록과 등록 규칙 11→12 갱신, 호 참조를 포함한 사람 판정 재사용·참조 변경 시 철회를 검증했습니다. 기존 직접 판정·표준·코퍼스·새로고침·완료·실제 PDF 등록 흐름도 통과했습니다. 시험한 앱 흐름에 런타임 오류와 외부 통신은 없었습니다.

위 23종은 이번 합성 문구 시험의 범위이며 신규 질문 수나 실제 자동판정률이 아닙니다. 기존 보안관리약정서 3종에 무관한 조항을 더한 표준 비교 시험은 3·6·6개로 유지됐고, 공개 자료 5종의 직접 자동충족은 계속 0개였습니다. 폐쇄망 실자료의 자동판정률·오판율 상승 또는 감소를 실측한 것은 아닙니다.

## 적용과 남은 범위

기존 실행기의 ‘버전 설치·업데이트’에서 contract-review-v1.84.0.crupdate를 선택한 뒤 계약을 재분석하십시오. 실행기 위치·이름과 브라우저 프로필을 유지하고 내부 백업을 보관하면 됩니다. 외부 AI·원문 반출·별도 자료 승인은 필요하지 않습니다. 사용자 코퍼스나 내부 약정서 원문은 배포본에 내장하지 않았습니다.

이번 번호 목록·단일 호 참조 처리 개발은 완료했습니다. 임의의 의역, 중첩 목록, 표 셀 사이의 의무 추정, 번호가 사라진 추출물, 미정의 역할이나 유사 제목의 별첨 추정, 복잡한 조건의 법적 우선순위 판단은 포함하지 않습니다. 이 기능은 HWP·HWPX·DOCX·PDF에서 추출된 공통 텍스트에 적용되며 각 형식의 모든 변환 오류를 복원하는 기능은 아닙니다. 개발 시험 통과를 실업무 오판율 0으로 해석하지 않습니다.
