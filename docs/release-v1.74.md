# v1.74 — 자동판정 실행 경로 수정

## 변경

- 설정이 없는 환경에서도 계약 분석과 동시에 정형 자동판정을 실행합니다. 별도 본문 확인 체크박스와 시작 승인은 제거했습니다.
- 재실행·재분석 시 현재 본문·별첨으로 자동판정을 재계산합니다. 입력 중인 미분석 문서는 통과시키지 않습니다.
- 사용자가 직접 중지한 전역·항목별 설정, 수동 판정과 검토의견은 유지합니다. 전역 중지는 ‘정형 자동판정 재개·재실행’으로 해제할 수 있습니다.
- 표준서식 자동 연결에서 질문과 무관한 서식 전체를 일치 근거로 요구하던 문제를 수정했습니다. 전체 서식의 관련 충돌 검사는 유지하고 충족 근거 문장만 연결합니다.
- 복수의 정형 개인정보 보호 의무가 함께 있다는 이유로 점검·접근제한 연결이 막히던 문제와 본문에 붙은 조항 번호 처리를 개선했습니다.
- 기존 자동 등록 자료는 현행 연결 규칙으로 갱신합니다. 수동 연결과 사용 중지 자료는 자동 변경하지 않습니다.
- 분석 후 실제 자동판정 건수와 표준서식 판정 건수를 표시합니다. 등록됐지만 연결이 없는 자료는 ‘자동 충족 연결 없음’으로 구분합니다.

## 사용

기존 실행기의 업데이트 기능으로 적용한 후 계약을 분석합니다. 새 승인 작업은 없습니다. 자료와 수동 검토결과는 기존 저장소를 사용합니다.

## 한계

모든 정상 계약 문구를 인식하는 AI 기능은 아닙니다. 현재 규칙 밖의 문구, 관련 예외·충돌, 불완전 근거는 검토 대상으로 남습니다. 폐쇄망 실제 자료의 자동판정 비율은 아직 측정하지 않았습니다.

## 검증

합성 계약을 현행 체크리스트로 분석하여 기간·부가세·관할·해지·손해배상 5개 항목의 기본 자동판정, 재분석·재실행, 미완료 목록 제외를 확인했습니다. 표준서식 업로드 후 개인정보 점검 항목의 자동판정과 재실행도 확인했습니다. 면제 조항 추가 시 차단, 편집 중 기존 판정 회수, 사람 의견과 사용자 중지 설정 보존을 함께 시험했습니다. 실제 폐쇄망 자료의 정확도·자동판정 비율 측정을 대신하지는 않습니다.
