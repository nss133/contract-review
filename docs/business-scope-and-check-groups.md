# 업무·규제 해당성 및 유사 체크 정리 — v1.53.0

현행 안내: v1.56.0에서 별도 업무·규제 해당성 기능은 사용자 요청으로 제거했다. 아래는 v1.53 당시 구현 기록이며, 유사 체크 묶음은 유지한다.

## 구현 범위

업무·규제 해당성 탭은 기존 계약검토와 독립된 작업영역이다. 계약 유형, 모듈, 기존 이상없음 판정을 변경하지 않는다.
계약서 입력의 본문을 명시적으로 가져오거나 계약서·소개서·계획서 등 여러 자료를 직접 추가한다.
PDF·DOCX·DOC·HWP·HWPX·TXT 추출과 직접 붙여넣기를 지원한다. 스캔 OCR 및 그림의 의미 추출은 지원하지 않는다.
파일별 추출 본문을 확인·수정할 수 있으며, 실패한 파일은 보완하거나 명시적으로 제외하기 전에는 분석하지 않는다.

별도 축은 정보처리위탁, 금융업무위탁, 개인정보 처리위탁, 개인신용정보 처리 규율, 제3자 제공 구분의 5개다.
자료별 문장·추출 텍스트 행 위치를 보존한다. 행은 PDF 원본 페이지나 법적 조항 주소를 뜻하지 않는다.
문장 신호는 사실 후보이며, 결과는 해당 가능성·비해당 가능성·추가 확인으로 표현한다.
긍정·부정 기재가 공존하면 자료 충돌로 보류한다. 조건·예시·가능성 문언, 목적 외 처리 금지는 확정된 처리/미처리 사실로 쓰지 않는다.
부서와 과거자료는 참고사례 검색에만 사용한다. 과거 결론은 해당성 결과에 투입하지 않는다.

미확인 사실은 검토자가 예/아니오/보류로 보정할 수 있다. 확인 출처·사유를 반드시 남기며 원래 자동 후보와 충돌 근거도 보존한다.
원본 추가·수정·제거 시 기존 보정과 결과를 무효화한다. 사실 보정 시에도 재분석 전에는 결과 저장을 막는다.
서술 결과는 TXT로, 원본·보정·부서의 작업백업은 crscope 파일로 저장·복구한다. 본문이 포함되므로 폐쇄망 안에만 보관한다.
자동 저장하지 않는다. 새로고침·업데이트 전에 별도 자료백업이 필요하며 기존 계약검토 이력팩/지식팩과 서로 다르다.

## 규범 연결 및 검증 경계

정의요건을 사실 질문으로 연결한 규칙 기반 트리아지이다. 위탁 허용 여부, 필수 신고·보고와 기한, 동의 면제, 특별법의 모든 예외를 확정하는 법률 의견 엔진은 아니다.
전산 정보처리와 금융업무가 혼재하면 특별규정/일반규정 적용관계를 추가 확인으로 남긴다.
단순 연락처만으로 개인신용정보를 추정하지 않으며, 개인정보가 없다는 사정으로 정보처리위탁을 제외하지 않는다.
자연어의 생략 주체·복합 부정·복잡한 조건은 오류가 날 수 있다. 자동 후보와 인용문을 확인해야 하며 실자료 정확도는 미측정이다.

검색 대상: 각 위탁·정보처리 축의 기본 정의와 법률 연결 조문. 확인일 2026-09-09.

| 규범 | 확인 범위·핵심 | 검증 상태 |
|---|---|---|
| 금융회사의 정보처리 업무 위탁에 관한 규정 제2조 | 전산설비에 의한 정보처리, 자신의 업무를 제3자가 계속 수행하는 정의 | 로컬 전문 원문 확인 A. 공식 2021-9호 정본 링크·정의 검색 결과 교차확인. 전체 개정 연혁 검증은 별도 |
| 금융기관의 업무위탁 등에 관한 규정 제1·2조 | 금융업 목적의 계속적 외부 용역·시설 활용과 단순 후선업무 제외; 정보처리 별도 경로 | 로컬 제2조가 생략본이므로 공식 조문 검색문·정본 링크로 보완 B+. 전체 본문 추출 미완료 |

| 신용정보의 이용 및 보호에 관한 법률 제2·17조 | 개인신용정보와 처리 위탁 연결 | 제2조 로컬 원문 A(시점 한계 있음). 제17조 시행 2026-08-13 공식 원문 A |

## 유사 체크 표시 정리

조항별 검토의 동일 조항·동일 표시영역 안에서 아래 항목을 묶고, 각 항목의 반복 질문은 구분되는 검토요소로 짧게 표시한다.

| 묶음 | 보존하는 ID | 구분 |
|---|---|---|
| 해지·해제권 | CMN-08, SP-UNF-09 | 약정 사유·균형 / 약관상 법정권 제한 |
| 해지 절차 | CMN-09, SOL-02 | 최고·서면통지 / 모집위탁 설명·절차 마련 |
| 종료 후 정산·반환·이관 | CMN-10, NDA-12, CH-02 | 공통 정산 / 비밀정보 파기증빙 / 기존 고객보호 |
| 종료 후 비밀유지·의무 존속 | CMN-16, NDA-21 | 존속기간 / 관련 구제 등 잔존 범위 |

CMN-08 질문에서 CMN-09와 겹치는 절차·시정기회 표현을 제거했다. 사유·권리 배분에 집중한다.
하자 해제권(SP-DEL-07), 불가항력 후속처리, 위임형 불완전이행, 화해금 불이행은 고유 요건이므로 합치지 않는다.
기존 체크 240개와 저장된 개별 판정·근거·내보내기 ID를 삭제하지 않는다. 법적 요건이 다른 항목의 일괄 이상없음 승계도 하지 않는다.
이 기능은 의미를 확인한 4개 묶음의 표시·질문 정리이며, 임의의 유사 문장을 전부 자동 삭제하는 기능이 아니다.

## 회귀검증

단위: 개인정보 없는 전산처리, 미기재/조건문, 자료 충돌, 직원 연락처, 개인신용정보 신호, 사유 없는 보정 차단, 원본 불변, 체크 묶음 및 ID 보존.
브라우저: 독립 state, 5개 축, DOCX/TXT 복수자료, 실패파일 게이트, 보정 후 재분석, 원본 수정 시 보정 초기화, 체크 묶음과 개별 판정 보존.
추가 검증: 실제 폐쇄망 자료의 오탐·누락 및 혼합업무 분류, 추출완전성. 법률확정 자동화로 확대하기 전 필요하다.
