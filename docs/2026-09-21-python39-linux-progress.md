2026-09-21. feat/python39-fastapi, 기반 커밋 1ea8d29. 기존 앱 기준은 v1.90.8의 4a2e5f1이다. [이전 기반 구현 기록](2026-09-21-python39-foundation.md) 이후 작업이며, 전체 앱 전환이나 실사용 배포 완료 기록이 아니다.

사용자는 Linux 공용 서버라고 확인했고, 세부 배포판·CPU는 모른다고 답했다. 추가 조사를 사용자에게 반복 요구하지 않고 [서버 자동 점검 도구 및 설치 안내](../packaging/linux/README.md)로 확인한다. SQLite 서버 로컬 디스크·동시 사용자 10명 이하·관리자 발급 계정·Python 3.9·프론트/API 분리를 유지한다.

## 이번 구현

- 문서 분할·원문 구조·문장 조건·유사도·조항 역할·형식 검사·법률 및 금융위탁 범위·태그·전체 Matcher 함수·문언 요건·과거 의견 보조·현재 약정 근거 탐색을 Python 함수로 옮겼다. 존재 질문 프로필도 데이터와 유한 파서로 이전했다. 기존 법률 규칙을 새로 판단하거나 수정하지 않았다.
- Unicode 원문과 UTF-16 위치 호환을 유지하며, 과거 의견은 현재 문구가 있는 검색 후보에만 사용한다. Python 서비스에서 기존 JS를 실행하는 우회 경로는 없다.
- 개발 전용 capture_domain.cjs는 기준 소스 해시를 먼저 확인하고 기존 합성 시험에서 입력·결과를 수집한다. 실제 사용자 계약이나 브라우저 저장 자료를 수집하지 않는다. 정적 프로필에는 원본 해시가 포함된다.
- SQLite backup-db/restore-db CLI를 추가했다. WAL 포함 스냅샷, 무결성·해시·스키마·참조 관계 검사, 새 경로 복원, 기존 세션 폐기를 적용했다. 현재 DB 데이터만 포함하며 향후 첨부 파일 저장 단계에서 백업 형식도 확장해야 한다.
- Linux preflight, 설정 생성기, systemd API 서비스, Nginx 정적 프론트/역방향 프록시, 로컬 wheel 전용 설치기, 묶음 생성기를 추가했다. 서버 설정을 자동 적용하지 않으며 개발 묶음을 운영판으로 설치하지 않도록 구분한다.

## 남은 기능과 검증

API의 analyses 경로는 여전히 501이고 capabilities도 분석·문서 추출·검토 완료를 미구현으로 표시한다. 화면의 해당 컨트롤도 비활성 상태다. 함수 이전·비교 시험 통과를 사용자 분석 기능 연결 완료로 표시하지 않는다.

다음 엔진 이전 대상은 ClauseSemantics의 문맥·조건·목록·표 처리, AgreementJudgment, StandardAuto와 등록 표준 판단, ReviewCore, Verdict·수기 판단 의존성·완료 조건이다. 문서 추출, 전체 결과 저장/API 및 기존 화면 연결, 구형 자료 이관, 관리·평가·CPU 작업 분리도 남아 있다. [실행계획 S0~S8](superpowers/plans/2026-09-21-python39-fastapi-migration.md)의 미완료 항목을 그대로 유지했다.

Linux 서버나 VM에서 Python 설치·systemd·Nginx·사내 HTTPS·서비스 재시작을 실제 실행한 결과는 아직 없다. 로컬 macOS 시험과 교차 플랫폼 wheel 해석은 Linux 실행 검증을 대신하지 않는다. Python 실행파일·Nginx·systemd·사내 인증서는 앱 wheel 묶음에 포함되지 않는다.

작업 중 발견한 미추적 dist/contract-review-python39-dev-1ea8d29/ 디렉터리는 사용자 자료로 간주하여 수정·삭제·일괄 스테이징하지 않는다. 이전 메일용 개발 ZIP과 기존 v1.90.8 ZIP도 유지한다.
