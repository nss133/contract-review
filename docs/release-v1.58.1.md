# v1.58.1 — 완료 판정의 불필요한 재확인 방지

- 사람 판정의 지문을 본건 문서·적용 조건·해당 체크항목·해당 항목의 재지정으로 한정했습니다. 다른 항목의 연결 변경, 참고 DB·매칭 엔진 변경만으로 직접 판정을 회수하지 않습니다.
- 자동 승인 판정은 기존의 전체 환경 재검사·만료·중지 기준을 그대로 사용합니다.
- 검토 마치기 버튼은 항상 클릭할 수 있으며 클릭 시점의 저장 판정과 안전 상태를 재검사합니다. 실제 미판정·재확인·문서완결성 발견사항이 남아 있으면 해당 목록으로 안내하며 완료 저장을 하지 않습니다. 잔여 무시 또는 일괄 이상없음 기능이 아닙니다.
- 이전 버전에서 이미 재확인 상태가 된 기록은 변경 전 조건을 복원할 수 없어 임의로 완료 처리하지 않습니다. 해당 항목의 기존 메모를 확인하고 동일 판정을 다시 선택하면 새 지문으로 저장합니다.

실자료를 받지 않았으므로 사용자가 겪은 건의 단일 원인을 확정한 것은 아닙니다. 합성 계약으로 관련·무관 매칭 변경, 엔진 갱신, 재분석·재로드, 실제 검토 마치기 저장을 검증합니다.
