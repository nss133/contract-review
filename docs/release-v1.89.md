# v1.89.0 사용안내 — 근거 표시와 처리속도 개선

## 업데이트

기존에 쓰던 실행기를 같은 위치에서 열고 이번 ZIP의 contract-review-v1.89.0.crupdate를 적용한 뒤, 계약을 불러와 재분석한다. 자동판정은 기존 삼단 화면의 ② 확인 완료에 표시된다. 자료 재승인이나 평가셋 재설정은 필요하지 않다.

기존 태그·코퍼스·검토이력·수기 판정·등록 표준서식은 삭제하지 않는다. 명시적으로 중지한 자동판정 설정도 보존한다. 다른 실행기 위치나 브라우저 프로필을 사용하면 저장소가 달라 보일 수 있으므로 기존 실행 환경을 유지한다. 필요하면 폐쇄망 내부에 백업을 보관하되 외부로 반출할 필요는 없다.

## 변경 내용

- 자동판정 카드의 근거 원문은 길게 나열하지 않는다. 검증된 위치가 있으면 원문 보기 버튼 하나만 표시하고, 누르면 그 위치를 연다. 유효한 위치가 없으면 버튼을 표시하지 않는다.
- 자동 확인 메모에는 짧은 판정 설명만 남긴다. 전체 원문을 메모에 다시 복사하지 않으며 검증에 사용한 근거는 내부에 보존한다. 사람이 작성한 메모는 줄이거나 삭제하지 않는다.
- 과거 의견 표현 검색·조항 매핑·등록 표준 대조에서 반복 계산을 줄인다. 자료의 내용이 바뀌면 새로 검사한다.
- 한 번의 화면 생성에서 문서와 추출블록을 재사용한다. 메모는 즉시 현재 판정에 반영하고 짧은 입력들을 묶어 저장한다. 입력창에서 나가거나 페이지를 닫을 때 남은 저장을 처리한다.
- 내부 평가자료 한 건을 저장할 때 과거 원문 전체를 다시 읽는 경로를 변경했다. 본건 메모 저장만으로 현재 조항 화면을 반복 재생성하지 않는다.
- 태깅자료의 정본 별칭 사전이 실제 자동판정 경로에서 누락되던 연결을 복구했다. 부정·조건 의미를 삭제하는 별칭은 허용하지 않는다.

이번 수정은 기존 질문별 판정 기준을 완화하거나 자동판정 기능을 없애는 변경이 아니다. 과거 이상없음 결론은 현재 계약의 정답으로 복사하지 않는다. 관련 원문 변경·부정 및 충돌·표준 적용범위·사용자 수기 판단 보호는 유지한다.

## 검증 범위

검증기록과 성능 측정 JSON을 함께 제공한다. 긴 합성 계약, 추출블록, 태그·코퍼스, 다수 표준, 내부 평가자료 자동저장, 수기 입력 및 네 파일형식의 회귀시험을 구분한다. 합성 성능값은 폐쇄망 장비의 처리시간이나 실제 계약의 자동판정률을 보장하지 않는다.

HWP·HWPX·DOCX·텍스트 PDF 지원은 유지된다. 이미지뿐인 스캔이나 손상 파일의 읽히지 않는 내용을 임의로 채우지 않는다. LLM·외부 API·인터넷 연결은 필요하지 않으며 ZIP에는 사용자 코퍼스·등록 약정 원문이 포함되지 않는다.
