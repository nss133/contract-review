# v1.76 — 질문별 판정 기준·약정 요건·사용자 판단 재사용

## 반영

- 현행 206개 질문의 판정 수준을 질문 원문과 함께 명시했습니다: 약정 존재·반영 59개, 내용 명확성 63개, 적정성·유불리 77개, 실제 이행 확인 제외 7개. 분류만으로 자동 충족을 부여하지 않으며, 질문 변경 시 분류를 승계하지 않습니다.
- 재위탁 사전동의, 접근권한, 점검 협조, 기술적·관리적 보호조치, 개인신용정보 식별정보 암호화, 양도 제한, 완전합의·서면변경 7개 질문의 요건 인식 규칙을 추가했습니다. 각 질문의 주체·행위·대상·필요 조건을 충족해야 합니다. 제목·태그 일치만으로 통과시키지 않습니다.
- 등록 표준서식도 같은 요건 엔진으로 연결합니다. 기존 자동 등록 자료는 새 규칙으로 재처리하며 수동 설정과 사용 중지는 보존합니다.
- 종합 판단 질문도 원문·별첨 전체, 역할·유형·검토 관점 등 적용범위, 현행 질문이 일치하고 사용자가 ‘반영되어 있음’으로 판단한 이력이 있으면 재사용합니다. 현재 코퍼스의 수정의견·위험수용·재확인 대기·보류 기록은 종전 정답의 사용을 차단합니다.
- 원문 저장본은 표시 공백 차이를 정규화하여 비교합니다. 문구·책임 방향·수치·조건을 유사도 점수로 대체하지 않습니다. 같은 문구라도 회사 역할·질문·별첨이 달라지면 재사용하지 않습니다.
- 자동 재판정이 원문 평가자료의 사용자 정답을 덮어쓰지 않도록 했습니다. 사용자 수정·삭제는 반영합니다. 내용이 같은 반복 저장은 변경 알림을 발생시키지 않습니다.
- 기존 태깅 엔진은 조항 매핑과 표준서식 연결의 태그 생성에 계속 사용됩니다. 법률검토 태그나 단순 결론만으로 새로운 계약에 ‘이상없음’을 부여하지 않습니다.

## 사용

기존 실행기에서 업데이트 후 분석합니다. 자료별 승인이나 코퍼스 반출은 필요하지 않습니다. 기존 내부 원문 평가자료가 있으면 읽어 재사용합니다. 앞으로의 원문 보존은 기존 ‘원문·판정 내부 평가자료 자동 저장’ 선택을 존중합니다.

## 한계와 검증 해석

206개 전 항목의 임의 문구를 자동 이해하는 AI 엔진이 아닙니다. 독립적인 내용 인식 규칙은 현행 13개 질문에 적용됩니다. 나머지는 검증 가능한 사용자 판단 재사용·등록 표준기준 경로가 있거나 사람이 검토해야 합니다. 원문·질문·범위가 연결되지 않은 구 코퍼스의 결론은 임의로 정답 규칙으로 승격하지 않습니다.

서로 다른 계약의 유사 문구에 대한 포괄적인 적정성 판단까지 완료했다고 주장하지 않습니다. 폐쇄망 실제 자료의 자동판정 비율과 정확도는 별도 측정 대상입니다. 자체 회귀시험과 전체 문서 일치의 재사용 시험을 독립 정확도 수치로 제시하지 않습니다.

## 검증

Node 회귀시험 679개와 Python 시험 106개를 통과했습니다. 실제 앱 화면에서 완전합의·서면변경의 직접 판정, 종합 판단 항목의 사용자 정답 재사용, 정답 원자료 정정 시 자동판정 철회, 미완료 목록 반영, 사용자 정답 보존 및 저장 이벤트 반복 방지를 확인했습니다. 브라우저 시험은 합성 입력이며 폐쇄망 실제 계약의 검증을 대신하지 않습니다.

보유 공개 표준자료 5개도 재검사했으며 최종 자동충족은 여전히 0개입니다. 이 자료군에서 실문서 자동판정 비중이 개선됐다고 주장하지 않습니다. 추가 규칙의 적용 범위와 조건부 이력 재사용 동작을 구현·검증한 배포입니다.
