# v1.66 정형 자동판정 사용안내

AI 설치나 외부 전송 없이 실행합니다. 기존 실행기에 동봉된 .crupdate를 적용하세요. 반입 전 기존 판정·코퍼스 백업을 보관하세요.

## 사용 순서

1. 본문과 적용할 별첨을 불러와 분석합니다.
2. 조항별 검토 위의 ‘정형 문구 자동판정’에서 원본·적용범위 확인을 체크합니다.
3. ‘확인한 자료로 자동판정’을 누릅니다. 별도의 규칙 ID·계열 ID 입력은 없습니다.
4. ‘보류 이유·과거 판정 비교’에서 항목별 원문과 이유를 확인합니다.
5. 필요하면 항목별 중지 또는 정형 자동판정 전체 중지를 사용합니다. 이는 고급 승인형 규칙의 중지와 별개입니다.

본문·별첨·유형·역할 변경 후에는 다시 확인해야 합니다. 무관한 코퍼스 추가만으로 정형 자동판정을 취소하지 않습니다. 사람이 확정한 의견은 자동판정으로 덮어쓰지 않습니다.

## 자동처리 범위

- CMN-04: 청구서 수령 기준 기한·지정 계좌 지급 및 실제 수행 내역의 월말 상호 정산이 모두 명시된 제한된 패턴.
- CMN-05: 부가세 포함 또는 별도·제외가 명시된 제한된 패턴.
- CMN-06: 유효한 시작·종료 날짜 또는 체결일부터 확정 기간이 명시된 제한된 패턴.
- CMN-19: 소송과 구체적인 관할 법원이 명시된 제한된 패턴.
- 동일 본문·별첨·맥락·체크 기준에 사람이 직접 ‘반영되어 있음’으로 확정한 개별 코퍼스는 재사용할 수 있습니다. 자동화 금지 체크, 위험수용, 보완 판정, 미해결 수입 충돌은 제외합니다.

위 항목의 모든 표현을 처리한다는 의미가 아닙니다. 낯선 관련 문구·참조·충돌은 해당 항목을 보류합니다. 표준 문구의 요건 확인이지 계약 전체가 법적으로 안전하다는 보증은 아닙니다. 원문 없는 구 집계 29건을 개별 정답으로 복원하거나 이를 근거로 모든 체크를 자동승인하지 않습니다.

## 예외·별첨 처리

명확하게 구분된 조항 중 해당 쟁점과 무관한 구역의 단서는 전역 차단에서 제외합니다. 구역 경계가 불명확하거나 참조 목적지가 불명확하면 제외하지 않습니다. 관련 단서, 정의, 전역 우선·배제 및 변환 오류는 계속 확인합니다. 본문과 별첨에서 조항 번호가 같아도 문서 구역은 분리합니다.

## 내부 평가 저장

‘앞으로 검토한 원문·판정을 내부 평가자료로 자동 저장’을 선택하면 별도 IndexedDB에 저장합니다. 이 저장은 선택 사항이며 기존 판정 저장과 분리됩니다. 원문을 포함하므로 폐쇄망 밖으로 반출하지 마세요. 기존 코퍼스 JSON 백업에는 이 별도 평가 저장소가 포함되지 않습니다.

브라우저 변경·재설치 전 ‘내부 평가자료 백업’을 별도로 보관하고 ‘내부 평가자료 복구’로 복원하세요. 같은 문서·맥락의 기존 로컬 자료는 덮어쓰지 않으며 자동판정 활성화 설정은 복원하지 않습니다.

‘저장된 검토로 일괄 점검’은 사람의 내용 충족·보완 판정과 정형 패턴을 비교합니다. 자기 정답을 재사용 경로에 입력하지 않습니다. 과거 보완 판정을 통과시킨 체크는 정형 자동판정을 중지합니다. 취소 버튼으로 중단할 수 있으며 저장자료는 지워지지 않습니다. 같은 양식의 반복은 독립 표본으로 주장하지 않습니다.

## 한계와 남은 범위

이 배포는 정형 패턴의 실제 실행 경로, 구역별 단서 처리, 간편 실행·중지, 향후 평가자료 자동축적·재실행을 제공합니다. 다양한 보안약정의 의미 동등성, 광범위한 해지·손해배상 패턴의 신규 계약 전이, 구 집계와 원문의 자동 복원은 완료되지 않았습니다. 실제 폐쇄망 자동판정률·오판율·장비 지연은 측정 전이며, 합성 회귀시험 통과와 구분합니다.
