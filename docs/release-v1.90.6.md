# v1.90.6 — 미래에셋 CI · 뉴스페이퍼형 검토 대시보드

## 화면 변경

- 미래에셋 오렌지 #F58220과 블루 #043B72를 주요 버튼·메뉴·리포트 제목 면·굵은 구분선에 적용함. 차트 보조색은 #00A9CE임.
- 큰 계약명, 선명한 제목 위계, 기사형 의견 본문과 우측 판단 목록으로 리포트의 읽는 순서를 정돈함. 종합의견과 작성한 의견은 축약하지 않음.
- 현재 활성 체크항목의 유효한 자동판정·검토자 판정과 남은 필수 미판정/재확인을 누적 막대 차트와 숫자로 표시함. 체크항목 중복은 제거하고, 재확인 대상은 완료로 세지 않음. 대상 0건은 ‘대상 없음’으로 표시함.
- 안전점수나 진행률 백분율을 만들지 않음. 검토의견을 남긴 항목과 선택 항목의 완료 판정은 포함하되, 미판정 선택 항목은 제외함. 차트의 미판정 수는 실제 검토 마치기의 잔여 수와 일치함. 계약의 법적 적정성·자동판정 정확도를 나타내는 지표가 아님.
- 입력 페이지의 종전 세로/전체 폭 배치, 삼단 검토, 체크리스트 문구·매핑·자동판정 기준·수기 의견·저장/내보내기 기능 유지.
- 차트는 로컬 SVG로 그리며 외부 라이브러리·온라인 폰트·네트워크 요청을 추가하지 않음. 색상 없이도 범례·숫자로 이해할 수 있고 인쇄에서도 유지함.
