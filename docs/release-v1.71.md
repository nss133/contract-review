# v1.71 — 표준서식 기반 계약내용 자동판정

## 검토 범위

계약의 약정 구조·내용만 검토한다. 실제 체결·교육·점검·신고·등록 이행 실적은 검사하지 않는다.
ITCL-04, SOL-01, PRIV-18, REL-02, REL-09, CORE-05, INV-FUND-03의 7개 순수 이행/사실확인 항목은 매핑·완료 대상에서 제외한다. 원래 ID와 과거 기록은 보존한다.
개인정보 제공, 담보 통지·승낙, 기업결합 신고 협조 등 혼합 질문은 실제 증빙 확보 대신 계약상 의무·협력·거래 조건을 검토하도록 수정했다. 계약상 교육·점검 협조, 분별관리·예탁 약정, 명의개서 협력 의무 등은 유지한다.
전체 지식 원본은 206개이며 위 7개는 현재 검토 대상에서 제외된다. 계약 유형별 실제 노출 수는 별도다.

## 최초 등록

1. 팀·지식관리의 ‘표준서식 등록 · 계약내용 자동판정’에서 파일을 넣는다. HWP/HWPX/DOC/DOCX/PDF는 기존 구조 추출기를 사용한다. 스캔·암호화·추출 실패는 원문 붙여넣기와 확인이 필요하다.
2. 이름·버전·적용 계약 유형(복수 가능)·회사 지위·검토 관점을 선택한다. 지위 무관은 양측에 동일하게 사용할 수 있는 기준에만 선택한다.
3. 추출 원문을 확인하고, 질문을 충족하는 조항을 모두 선택한 뒤 연결 질문을 선택한다. 키워드·기존 검수 태그로 후보를 정렬하고 원문 태그를 생성한다. 태그/ID를 직접 작성할 필요는 없다.
4. 여러 질문을 연결한 뒤 ‘각 질문 전체를 충족함’ 확인에 체크하고 등록한다. 연결은 등록 시 한 번 승인하며 계약마다 반복하지 않는다.
5. ‘표준서식 백업’을 폐쇄망 내부에 보관한다. 서식 원문·연결은 브라우저 저장소에 있으므로 저장소 초기화 전에 백업이 필요하다. 저장 용량 초과 시 성공으로 표시하지 않는다.

## 계약 검토

- 본문 또는 업로드한 별첨에서 등록 근거와 동일·지원되는 동등 문구가 발견되면 자동으로 이상없음 처리한다. 문서명 일치는 필요 없다.
- 등록된 서식을 본건에 적용하려면 ‘본건 별첨으로 사용’을 누른다. 실제 서명·체결 사실을 확인하는 버튼이 아니라 검토할 계약 문서의 구성에 추가하는 버튼이다. 다른 계약에 자동으로 약정서를 적용하지 않는다.
- 판정과 근거 문구·서식 버전은 기존 삼단 화면과 검토결과에 기록한다. 여러 체크를 펼치는 별도 통합 판정 영역은 없다.
- 기존 사람 판정은 덮어쓰지 않는다. 원문 변경, 관련 추가 예외, 유형·지위 불일치, 질문 변경, 기준 중지는 현재 근거로 재검사한다.
- 같은 이름의 새 버전을 등록하면 이전 버전은 보존하되 사용 중지한다. 기존 자료를 덮어쓰지 않는다.
- 복구 파일은 기존 서식을 보존하며 새 항목을 승인 대기로 가져온다. 확인 후 활성화한다.

## 자동판정의 범위와 한계

AI를 사용하지 않는다. 공백·일부 어미와 검증된 구조적 동의 표현을 정규화한다. 예를 들어 ‘사전 서면 동의 없이 재위탁할 수 없다’와 ‘재위탁하려면 서면 동의를 미리 받아야 한다’는 주체·대상을 보존하여 비교한다. 임의의 모든 유사 취지를 일반 추론하는 기능은 아니다. 사후 통지, 선택적 동의, 의무 주체 역전, 수치 변경은 같은 것으로 처리하지 않는다.
태그는 후보 검색과 근거 연결을 보조하며 태그 일치 점수만으로 이상없음을 확정하지 않는다. 관리자가 승인한 질문별 근거 전체를 본건에서 찾는 방식이다. 관련 미등록 문구·예외는 자동통과하지 않는다. 승인된 표준문 자체의 ‘다만’은 일괄 보류하지 않는다.
이름·날짜·금액을 무조건 삭제하는 정규화는 하지 않는다. 그런 값이 승인 근거에 포함되어 있으면 변경 시 일치하지 않을 수 있다. 필수 빈칸을 무시하거나 OCR 실패를 의미 일치로 간주하지 않는다.

## 이력 점검

‘저장된 검토이력으로 기준 점검’은 기존 내부 평가자료 저장본의 원문과 수동 판정을 사용한다. 원문 없는 태깅/코퍼스 기록만으로는 문장 대조 점수를 계산하지 않는다. 자동판정 자체를 정답으로 사용하지 않는다.
자동충족 수, 사람이 검토의견을 남긴 항목을 자동통과시킨 불일치, 이행확인 제외, 질문변경 제외를 구분한다. 등록·학습 자료와 겹칠 수 있으므로 독립 정확도 수치로 해석하지 않는다. 원문 반출 없이 폐쇄망에서 실행한다.

표준서식 원문·사용자 코퍼스는 배포 ZIP에 포함하지 않는다. 이 버전의 시험 통과는 폐쇄망 실제 계약에 대한 정확도 보장을 의미하지 않는다.
