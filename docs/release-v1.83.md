# v1.83.0 — 문구 변형·구역별 당사자 정의·제목으로 지목한 별첨 비교

## 이번 개발의 완료 범위

기존 자동판정 질문의 문구 인식과 근거 연결을 보강했습니다. 질문 수를 추가한 버전은 아닙니다. 직접 판정 규칙이 있는 질문 64개, 관련 조항 기반 사용자 판단 재사용 대상 66개를 유지합니다. 전체 206개 질문 중 약정 존재 질문 60개에는 모두 유한한 문구 규칙이 있습니다. 이 수치는 실계약 자동판정률이 아닙니다.

- ‘할 의무를 진다’, ‘하여야만 한다’, ‘하여서는 안 된다’, ‘배상할 책임을 진다’, ‘매년 ○회 이상’ 등 명시적인 종결·빈도 표현을 추가로 인식합니다. 지원하는 9종 조건절은 주체의 앞에 있어도 같은 조건으로 읽습니다. ‘경우에만’ 같은 제한, 횟수, 방법과 주체 차이는 없애지 않습니다.
- 갑·을의 명시적 정의를 파일별, 같은 파일의 명시적인 별첨 구역별로 구분합니다. 본문과 별첨이 갑·을을 반대로 정의해도 각 구역의 역할을 사용합니다. ‘을은 수탁자를 말한다’ 같은 정의형과 괄호 안 축약형도 처리합니다. 같은 구역의 정의 충돌은 자동으로 해결하지 않으며, 다른 구역의 정의를 추정하여 상속하지 않습니다.
- ‘보안관리약정서 제1조’처럼 제목으로 지목한 별첨을 실제 파일명·문서 첫 제목·명시 별첨 표제와 연결합니다. 제목은 공백·지원 확장자 등을 정리한 뒤 정확하게 비교하며 하나로 특정되어야 합니다. 동명 별첨, 누락된 참조, 번호와 제목의 불일치, 중복 조문 번호를 임의로 선택하지 않습니다. 파일명의 버전·연도 차이도 지우지 않습니다.
- 이렇게 읽은 문구와 역할·별첨 문맥을 직접 판정, 등록 표준 비교, 원문으로 확인된 사용자 판단 재사용에 함께 반영합니다. 제목 참조만으로 이상없음을 만들지는 않습니다. 별첨 내용·연결된 제한·우선순위 문구도 비교하며, 법적 우선순위를 새로 추론하는 기능은 아닙니다.
- 띄어쓰기가 사라진 미해석 문장에 남아 있는 갑·을도 해당 구역 정의를 비교 지문에 보존합니다. 상대방 정의가 바뀌었는데 같은 과거 판정으로 처리하는 경우를 방지합니다.

체크리스트 질문·법적 기준은 바꾸지 않았습니다. 실제 교육·점검·신고 등의 이행 여부가 아니라 약정 내용을 확인합니다. 태그는 후보·출처 연결에 계속 사용하고, 유사도나 태그만으로 적정성을 승인하지 않습니다.

## 기존 자료·화면 처리

기존 자동등록 표준은 연결 규칙 11로 자동 갱신합니다. 다시 승인할 필요가 없으며 수동 설정·사용 중지 상태는 보존합니다. 변경된 문구 해석과 별첨 비교를 기존 표준에도 적용하기 위한 갱신입니다.

자동 이상없음은 기존 조항별 검토의 ② 확인 완료에 표시하고 미완료 목록에서 제외합니다. 근거 삭제, 의무·조건 변경, 동일 제목 중복 또는 최신 사용자 정정에 따라 자동판정을 철회합니다. 사용자가 직접 남긴 판정은 덮어쓰지 않습니다. 별도 검토 공간이나 자료 승인 단계는 추가하지 않았습니다.
