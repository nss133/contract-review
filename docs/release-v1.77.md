# v1.77 — 태그 요건·조항 단위 판단 재사용

## 구현한 변경

- 재위탁·개인정보 보호조치 등 기존 존재 질문에 주체·행위·대상 태그와 의무·조건 결합 검사를 연결했습니다. 질문이 사전 동의만 요구하면 서면을 추가 요건으로 강제하지 않습니다. 태그 점수 자체를 충족 확률로 쓰지는 않습니다.
- 배상의무 종결 표현(배상하여야 한다 / 배상할 책임이 있다 / 배상책임을 부담한다)을 구분하던 불필요한 차이를 정규화합니다. 부정·주체·기간·수치는 삭제하지 않습니다.
- 원문 평가자료의 사용자 판단을 관련 조항 단위로 재사용합니다. 제목·무관한 조항·독립 별첨이 달라도 관련 내용과 적용범위가 같으면 사용할 수 있습니다. 출처·질문·사용자 사유를 남기고, 최신 사용자 보완·위험수용·재확인 대기·정정은 재사용을 차단합니다.
- 관련 조항의 명시 참조와 해당 조항을 변경하는 역방향 참조를 포함합니다. 원문에서 해결하지 못한 참조는 미확인으로 남깁니다. 중복 조문번호를 가진 문서에서 참조 대상을 하나로 확정하지 못하면 임의 연결하지 않습니다.
- 손해배상·해지·비밀유지 통합 질문은 등록 표준서식의 질문별 구성요소를 확인해 기존 내장 예문과 별도로 연결할 수 있습니다. 예컨대 14일 시정기간을 임의의 적정성 기준으로 승인하지 않고, 그 내용이 있는 등록 표준을 기준으로 비교합니다. 적용범위·조건이 달라지면 통과하지 않습니다.
- 기존 자동 등록 서식은 연결 규칙 5로 재처리합니다. 수동 설정과 사용 중지는 보존합니다.
- 사용자 코퍼스 의견을 저장할 때 주체·행위·대상·조건 등 구조화 태그도 생성합니다. 기존 의견은 검색 색인에서 다시 태깅하므로 자료를 재승인할 필요가 없습니다. 결론 태그와 근거 태그는 구별합니다.
- 계약검토·법률검토 태깅자료를 질문별로 검색하고, 태그 일치·문자열 유사도·질문 연결을 후보 순위에 사용합니다. 후보는 통과 근거와 구분해 표시합니다. 근거가 없는 결론을 정답으로 승격하지 않습니다.
- 카드의 일괄 ‘관찰만·최종 확인은 검토자’ 문구를 없애고 자동 완료 / 사용자 완료 / 실제 미판정 이유와 미확인 요소를 표시합니다. 자동 완료는 수동 편집 핀이 남아 있어도 ② 확인 완료로 이동합니다.
- ‘저장된 검토로 일괄 점검’은 자동 추정 계열과 날짜로 시험 자료를 분리하고 이전 다른 계열의 자료를 검색합니다. 계열 ID를 입력할 필요가 없습니다. 보류 원인·오판·조항 재사용 수를 함께 집계합니다. 자동 계열 비교는 400건까지 지원하며, 이 한도는 일반 검토의 제한이 아닙니다.

## 사용

기존 실행기에서 업데이트하고 계약을 재분석합니다. 등록 표준서식의 자동 연결은 갱신됩니다. 별도의 자료 승인이나 외부 전송은 필요하지 않습니다.

조항 단위 사용자 판단 재사용에는 본문·별첨·판정·범위가 연결된 내부 원문 평가자료가 필요합니다. 기존 ‘앞으로 검토한 원문·판정을 내부 평가자료로 자동 저장’ 선택을 유지합니다. 원문 없는 구 코퍼스와 법률검토 태깅자료는 후보 검색에 활용되지만 단독으로 이상없음을 만들지는 않습니다.

## 범위와 남은 한계

- 독립적인 직접 인식 대상은 여전히 현행 13개 질문이며 이번에는 그 표현·조건 인식 범위를 확장했습니다. 조항 단위 재사용의 관련 내용 선택은 15개 주요 질문에 정의돼 있습니다. 전 206개 질문의 임의 문구를 이해하는 엔진이 아닙니다.
- 표준서식의 독립 연결은 손해배상·해지·비밀유지 3개 통합 질문부터 적용합니다. 그 외 자동 연결은 기존 요건 규칙을 이용합니다. 표준서식에 있다고 모든 질문을 자동 통과시키지는 않습니다.
- 의무의 주체·방향·대상·조건은 여전히 비교합니다. 유사도만으로 다른 문구를 동등하다고 확정하지 않으며, 복잡한 예외·전항·전조·준용은 확인이 필요할 수 있습니다.
- 폐쇄망 태깅자료 전체의 양과 원문 연결률, 실제 업무 계약의 자동판정 비율은 이 개발 환경에서 측정하지 않았습니다. 자료를 직접 보지 않은 상태에서 향상 수치를 제시하지 않습니다.
- 자동 계열 분리는 평가 편의 기능이며 독립 표본 인증이 아닙니다. 같은 날짜·미래 자료는 재사용 시험에서 제외합니다. 파일 재추출과 계약 유형 자동선택은 이 점검에서 다시 실행하지 않습니다.

## 검증

Node 693개, Python 106개 회귀시험 통과. 같은 태그가 있어도 책임 부정·주체 변경·사후 통지·관련 예외 변경을 차단하는 시험을 포함합니다. 브라우저에서는 이력 재사용, 독립 표준 연결, 일괄 평가, 근거 정정 시 철회, 사용자 정답 보존, ② 이동과 상태 표시를 검사합니다.

공개 표준자료 5개에 대한 내장 규칙의 자동충족은 여전히 0개입니다. 이 자료군에서 직접 판정 비중이 개선됐다고 주장하지 않습니다. 합성 문구·등록 표준·사용자 판단 자료로 확인한 동작을 실제 계약의 독립 정확도로 제시하지 않습니다.
