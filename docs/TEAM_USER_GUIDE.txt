계약서 리뷰 가이드 v__APP_VERSION__ - 팀원용 사용안내
====================================================

1. 이 도구는 무엇인가요?
------------------------
계약서에서 검토할 항목과 관련 원문을 찾아 보여주는 보조 도구입니다.
도구가 최종 결론을 내리는 것은 아닙니다. 계약서 원문을 확인한 뒤 검토자가
직접 "이상없음" 또는 "검토의견"을 선택해야 합니다.

인터넷 연결 없이 사용할 수 있으며, 입력한 계약서는 외부로 전송되지 않습니다.

폐쇄망에서 결과가 갑자기 나타나면 Windows·Chrome의 '동작 줄이기' 설정이
감지된 경우가 많습니다. 계약서 입력 화면의 '화면 효과'에서 '효과 사용'을
선택하면 인터넷 연결이나 시스템 설정과 무관하게 분석 단계와 순차 표시 효과를
사용할 수 있습니다. '시스템 설정'은 PC의 접근성 설정을 그대로 따릅니다.


2. 시작하기
-----------
1) 압축 파일을 풉니다.
2) 최초설치_계약서검토_실행기.html을 Chrome 또는 Edge로 엽니다.
3) 실행기 상단의 [버전 설치·업데이트]에서 같은 압축 파일의 .crupdate 파일을 선택합니다.
4) 계약서 입력 화면에서 [파일 열기]를 누르거나 계약서 내용을 붙여넣습니다.
5) 당사 지위와 계약 유형이 맞는지 확인합니다.
6) 보안관리약정서를 실제 체결·사용하는 경우 해당 항목을 체크합니다.
7) 필요한 적용 모듈을 확인하고 [분석 시작]을 누릅니다.

계약서 본문에서 약정서 참조를 찾거나 비슷한 부속서류를 업로드하면 "자동 후보"가
표시됩니다. 후보 표시는 체결 확정이 아닙니다. 적용 대상과 체결 상태를 확인한 뒤
검토자가 체크해야 세부 보호항목이 묶음으로 반영됩니다.

새 버전이 오면 새 실행기 파일을 열지 말고 최초 설치 때 사용한 실행기를 계속 사용하세요.
그 실행기에서 새 .crupdate 파일만 선택해야 법률검토 태깅자료와 브라우저 저장자료가 유지됩니다.

지원 파일: PDF, DOCX, DOC, HWP, HWPX

스캔한 PDF나 암호가 설정된 문서는 글자를 읽지 못할 수 있습니다.
이 경우 문서의 텍스트를 복사해 입력 칸에 붙여넣으세요.


3. 검토 화면 읽는 법
-------------------
조항별 검토 화면은 계약서 원문 옆에 검토 항목을 보여줍니다.

- 관련 원문 찾음
  체크 항목과 관련된 계약서 위치를 찾았다는 뜻입니다.
  "문제없음"이 확정됐다는 뜻은 아니므로 필요한 경우 원문을 확인하세요.

- 원문 확인 필요
  관련 가능성이 있는 원문을 찾았지만 사람이 내용을 확인해야 한다는 뜻입니다.

- 적용·보완 판단 필요
  해당 항목이 이 계약에 적용되는지, 계약 내용을 보완해야 하는지 판단해야 합니다.
  실제로 빠진 항목이라고 자동 확정한 것은 아닙니다.

화면의 필수·권장·참고는 항목의 중요도입니다.

- 필수: 반드시 확인해야 할 항목
- 권장: 계약 조건상 확인하는 것이 좋은 항목
- 참고: 검토에 도움이 되는 참고 항목

중요도와 이번 계약에서 할 일은 다릅니다. 각 카드에는 필요한 경우 "권장 처리"가 함께 표시됩니다.

- 계약서 수정 검토: 계약 문구를 추가하거나 고칠 필요가 있는지 판단합니다.
- 문제 문구 삭제·수정 검토: 그대로 두기 어려운 문구를 삭제하거나 고칠지 판단합니다.
- 별도 자료에서 확인: 보안관리약정서, 동의서·고지자료, 승인·평가·점검자료에서 확인합니다.
- 회사 유불리 검토: 법령상 필수 문구는 아니며 회사에 유리하도록 협의할 필요가 있는지 살펴봅니다.
- 계약서 반영 여부 확인: 계약서에 넣어야 하는지 또는 현재 문구로 충분한지 확인합니다.


4. 판정 남기기
--------------
각 항목에는 다음 두 가지 중 하나를 선택합니다.

- 이상없음
  계약 내용을 확인한 결과 별도 보완이 필요하지 않은 경우입니다.
  필요하면 "반영되어 있음", "해당사항 없음", "회사에 유리·불리하지 않음",
  "수용 가능한 위험" 중 사유를 선택하고 메모를 남깁니다.

- 검토의견
  수정, 보완, 협의 또는 추가 확인이 필요한 경우입니다.
  상대방이나 담당자가 이해할 수 있도록 이유와 필요한 조치를 코멘트에 적습니다.

조항별 검토의 ③에서 "이상없음"을 선택해도 사유·메모를 쓰는 동안 카드는 이동하지
않습니다. 입력을 마친 뒤 [입력 완료 → ②로 이동]을 누르면 ② 확인 완료로 이동합니다.
② 확인 완료 목록은 기본으로 펼쳐져 있어 이동한 결과를 바로 확인할 수 있습니다.
코멘트는 입력 중 자동 저장되며, 길이 제한 없이 종합리포트에 표시됩니다.

판정 아래의 "정확도 개선용 피드백"을 펼치면 "실제 처리 결과"도 선택할 수 있습니다.
계약서 수정 요청, 문제 문구 삭제 요청, 현 문구 유지, 별도 자료·절차로 확인,
이 계약에는 해당 없음, 추가 확인 후 결정 중 하나를 선택합니다. 이는 향후 시스템 안내의
정확도를 측정하기 위한 선택 항목입니다. 선택하지 않아도 검토 완료와 리포트에는 영향을
주지 않으며, 이상없음·검토의견 판정도 바꾸지 않습니다. 이미 입력한 항목은 펼쳐서 표시됩니다.

일부 항목은 계약서에 관련 문구가 있는지만 묻지 않고, 그 문구가 우리 회사에 불리해
수정이 필요한지를 묻습니다. 예를 들어 상대방만 무기한 비밀유지의무를 부담하면 회사에
유리할 수 있으므로, 의무주체가 명확한 경우에는 수정 불필요 사유가 함께 표시됩니다.


5. 종합리포트 확인하기
---------------------
종합리포트는 다음 세 가지를 중심으로 보여줍니다.

- 검토 상태: 사람이 확인해야 할 항목이 남아 있는지
- 검토 결과: 이상없음과 검토의견을 몇 건 남겼는지
- 형식 점검: 상호, 대표자, 주소 표기에서 확인할 부분이 있는지

리포트는 계약서 수정 검토, 별도 자료 확인, 추가 확인 필요, 회사 유불리 검토를 구분합니다.
확인이 필요한 항목이 남아 있으면 [조항별 검토로 이동]을 눌러 판정합니다.
모든 필수 검토가 끝나면 [검토 마치기] 버튼이 활성화됩니다.

상단의 종합 검토의견은 자동으로 작성됩니다. [수정]을 누르면 문안을 직접 고칠 수
있으며, 긴 코멘트도 잘리지 않고 표시됩니다.

[팀·지식 관리]의 [정확도·검토효율 현황]에서는 조항 매칭과 계약서 반영 안내를 따로 봅니다.
계약 유형 분류도 최초 자동유형과 검토자가 최종 선택한 유형을 비교해 자동 일치율과
검토자 변경 건수를 누적합니다. 자동 미확정 상태에서 사람이 유형을 선택한 건도 별도로 셉니다.
안내 일치율은 계약서 수정 요청, 문제 문구 삭제 요청, 별도 자료 확인처럼 시스템 안내와
실제 처리 결과를 비교할 수 있는 표본만 계산합니다. 회사 유불리 검토와 추가 확인 후 결정은
정답률 분모에서 제외됩니다. 표본이 없으면 백분율 대신 0건으로 표시됩니다.


6. 결과 저장과 공유
-------------------
- 검토 마치기
  현재 검토 결과를 이 브라우저에 저장하고 다음 검토를 위한 지식에 반영합니다.

- 검토의견 파일로 내보내기
  팀원이나 담당자에게 전달할 검토 결과 파일을 만듭니다.

- 인쇄
  종합리포트를 인쇄하거나 PDF로 저장합니다.

중요한 검토 결과는 브라우저 저장에만 의존하지 말고 반드시 파일로 내보내 보관하세요.
다른 PC나 다른 브라우저에서는 기존 브라우저 저장 내용이 자동으로 보이지 않습니다.


7. 변경합의서 검토
------------------
변경합의서나 개정합의서를 검토할 때는 입력 화면의 [원계약 첨부]로 원계약도 함께
넣으세요. 그러면 원계약에 이미 있는 내용을 전제로 변경된 부분을 검토할 수 있습니다.


8. 법률검토 태깅자료 적재와 보존
-------------------------------
관리자가 legal-opinion-tagger로 만든 일괄 XLSX를 [지식 데이터] 탭에서 최초 1회 가져옵니다.
같은 자료를 다시 선택해도 중복 집계하지 않으며, 태깅 결과가 바뀐 문서는 과거본과 새 리비전을
함께 보존합니다. 새 앱 버전을 설치할 때 이 XLSX를 다시 넣을 필요는 없습니다.

[지식팩 백업]으로 만든 .crknowledge 파일은 폐쇄망 내부 승인 폴더에 보관하세요. 브라우저 데이터가
삭제되거나 다른 PC로 옮길 때 [지식팩 복구]로 되살릴 수 있습니다. 지식팩에는 법률검토의견의
근거 문장이 포함될 수 있으므로 외부로 반출하면 안 됩니다.


9. 사용 시 주의사항
-------------------
- 이 도구는 검토 보조 수단이며 법적 판단을 대신하지 않습니다.
- 자동으로 찾은 원문 위치가 정확한지 중요한 항목은 직접 확인하세요.
- 계약 유형, 당사 지위, 적용 모듈이 잘못 선택되면 검토 항목도 달라질 수 있습니다.
- 스캔 상태가 나쁘거나 표가 복잡한 문서는 원문 추출 결과를 먼저 확인하세요.
- 검토의견에는 결론뿐 아니라 수정 방향이나 추가 확인 사항도 함께 적는 것이 좋습니다.


빠른 순서
---------
파일 열기 -> 설정 확인 -> 분석 시작 -> 조항별 검토 -> 판정·코멘트 입력
-> 종합리포트 확인 -> 검토 마치기 -> 검토의견 파일로 내보내기
