# v1.87 통합 개발 범위

사용자가 승인한 네 항목을 아래 순서로 구현하고 하나의 폐쇄망 배포본으로 검증한다.

1. 표: DOCX·HWPX·HWP의 행·열·병합 출처, PDF의 명시 열 머리글과 좌표를 보존한다. 주체·대상·의무·조건 열이 명확하고 모든 셀이 해석되는 표를 약정으로 연결한다. 출처 불일치·빈칸·불명확한 병합을 추측하지 않는다. 본문·별첨·등록 표준·내부 평가자료에 같은 구조를 전달한다.
2. 표현: 완전한 문장으로 확인 가능한 동사·종결·어순 변형, 같은 구역의 명시적인 주체·대상 반복 생략을 지원한다. 태그는 검색에, 구조화한 사실은 직접 요건·표준·사람 판단 비교에 쓴다. 부정·재량·수치·조건은 보존한다.
3. 참조: 가지번호 포함 조 범위, 명시된 서로 다른 부모의 항·호·목 경로, 호→목→하위 번호 목록을 연결한다. 중간 번호 전체와 순서·유일성을 검사하고 역방향 제한도 유지한다.
4. 조건: 여러 문장과 별첨에 걸친 명시 조건·제한의 적용 대상을 연결한다. 완전히 해석된 다른 쟁점의 조건은 해당 체크를 막지 않게 분리하되, 같은 쟁점·불명확한 지시어·우선적용·상충 조건은 보존한다. 표준·확인된 사람 판단과 조건이 같은 경우에만 재사용한다.

각 단계는 양성 사례, 잘못된 이상없음을 막는 반례, 출처·수동판정 보존, 변경 시 철회를 검증한다. 네 단계 이후 전체 회귀시험·배포 HTML 브라우저 시험·패키지 무결성 검사로 완료한다. 원문 반출·외부 AI·새 승인 절차·별도 검토 화면은 추가하지 않는다. 실업무 자동판정률·오판율은 내부 실측 전에는 주장하지 않는다.

## 구현 기록

1~4 구현 완료. 변경 범위와 형식별 지원 한계는 [v1.87 변경안내](release-v1.87.md)에 기록했다. Node 1,045개·Python 106개와 최종 배포 HTML 브라우저 18개 흐름을 통과했다. 신규 지원 합성 사례 17개는 v1.86 대비 0→17개 자동판정, 각 반례 17개는 모두 보류였다. 최종 패키지는 브라우저에서 시험한 HTML의 SHA-256, 직접 실행본·업데이트·ZIP의 동일성, 소스·안내·정책 포함 여부와 사용자 코퍼스 미내장을 검사한 뒤 전달한다.
