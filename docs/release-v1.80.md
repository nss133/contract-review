# v1.80 — 관련 조항 기반 표준 활용·감독 협조 요건 확대

## 이번에 완료한 범위

- 직접 자동판정 대상 질문을 18개에서 24개로 확대했습니다. 위탁업무 법령 준수(CORE-06), 관리·감독권(CORE-10), 감독당국 조치 시 변경·시정 협조(CORE-13), 클라우드 중요도 평가 자료(ITCL-01), 클라우드 제공자 건전성·안전성 평가 자료(ITCL-02), 연 1회 이상 서비스 품질평가 협조(ITSEC-10)가 추가됐습니다. 실제 법령 준수·평가 실시 여부가 아니라 해당 약정의 존재를 확인합니다.
- 주체·대상·행위·조건·연간 횟수를 구조화하여 직접 판정과 등록 표준 비교, 과거 판단의 관련 조항 비교에 사용합니다. 과거 판단의 관련 내용 선택 대상은 20개에서 26개로 늘었습니다. 단순 태그·유사도·과거 통과 빈도를 정답으로 취급하지 않습니다.
- 제목의 ‘클라우드’ 같은 쟁점어 때문에 제목 자체를 미해석 조건으로 읽어 보류하던 문제를 수정했습니다. 문서 첫머리의 독립 제목이고 뒤에 실제 조항이 있는 경우에만 제외합니다. 면제·배제 등 위험 신호가 있는 제목이나 본문 속 문구는 버리지 않습니다. 표준 비교에서도 단순 줄바꿈을 복구하며, 자동판정 이유에 확인한 주체·대상·행위·평가 주기를 표시합니다.
- CORE-10의 현재 질문은 관리·감독 조항이 있는지를 묻는데 판정 수준이 명확성으로 분류돼 있었습니다. 존재 질문으로 바로잡고 점검·자료 요구·감사 주체 및 권리 또는 협조 의무를 모두 확인합니다. 전 항목 분류는 존재 60개·명확성 62개·적정성 77개·실제 이행 제외 7개이며 분류만으로 통과시키지 않습니다.
- 등록 표준 6종 질문의 전체 문서 일치 경로에 관련 조항 비교를 추가했습니다. 제목·무관한 조항이 달라도 관련 조 전체, 정의, 조건, 연결되는 참조 내용이 동등하면 사용할 수 있습니다. 본문과 실제 첨부된 별첨을 함께 검사합니다. 일부 핵심어만 남은 발췌본은 통과하지 않습니다.
- 전조·명시 조문 참조는 대상 문장뿐 아니라 어느 조항을 가리키는지까지 비교합니다. 같은 조항 집합이라도 참조 연결관계가 바뀌면 다른 약정으로 봅니다. 제N항의 누락·중복 번호도 확인합니다.
- 등록 표준에서 항 번호가 텍스트 추출 중 사라진 경우에는 번호를 임의 복원하지 않습니다. 앞선 문맥이 있고 해당 조 전체와 문장 순서가 그대로 보존된 비교에 한해 등록 기준을 재사용합니다. 외부 법령 참조 역시 등록 표준과 동일한 참조 문구·문맥을 보존하는 경로이며, 법령 내용을 새로 해석하거나 현행성을 인증하는 기능이 아닙니다. 일반 과거판정 재사용에는 이 등록 표준 전용 예외를 적용하지 않습니다.
- 자동판정 근거에 ‘문서 전체 일치’와 ‘관련 조항·조건·참조 문맥 일치’를 구분해 표시합니다. 사용자 작성 판정은 덮어쓰지 않으며, 최신 보완 의견이나 충돌 특약이 있으면 자동판정을 철회합니다.

## 비교 결과의 의미

보유 보안관리약정서 3종에 새 제목·무관한 운송 조항을 추가한 시험에서 v1.79는 표준 연결은 있어도 실제 판정이 0개였습니다. v1.80은 GA 3개·일반 6개·재위탁 6개를 판정했습니다. 원문 전체 그대로의 비교에서는 종전 전체 일치 경로도 유지합니다.

이는 개발용 원문에 통제된 변형을 넣어 등록 경로를 비교한 결과입니다. 새로운 계약의 독립 정확도·폐쇄망 전체 자동판정률을 뜻하지 않습니다. GA의 나머지 참조와 임의 표현까지 모두 처리했다고 주장하지 않습니다.

## 사용

기존 실행기에서 v1.80.0 업데이트 파일을 선택한 뒤 계약을 재분석합니다. 기존 자동 등록 표준은 연결 규칙 8로 자동 갱신됩니다. 사용 중지·수동 설정은 보존하며 재승인이나 자료 반출을 요구하지 않습니다.

기존 실행기 파일의 경로·이름과 브라우저 프로필을 유지하고 업데이트 전 내부 백업을 보관하십시오. 등록 표준 자체가 아니라 본건에 실제 포함된 내용을 비교합니다. 원문 없는 태깅자료·구 코퍼스 결론만으로 계약 내용을 생성하지 않습니다. 배포본에 사용자 코퍼스나 시험용 약정서 원문을 내장하지 않습니다.

## 검증

Node 742개·Python 106개, 총 848개 회귀시험을 통과했습니다. 격리 브라우저에서 신규 직접 판정·관련 조항 비교와 기존 등록 표준·의무 요소/출처 연결·과거 판단 재사용·판정 생명주기·파일 등록·표준 라이브러리·표준 비교 확대·체크리스트 내용의 9개 흐름을 검증했습니다.

실제 앱에서 신규 6개 질문의 자동판정과 ②열 이동, 평가 횟수 축소 시 철회, 일반 보안관리약정서의 관련 조항 경로 5개 판정, 충돌 특약·최신 사용자 정정 시 철회, 사람의 직접 입력 보존을 확인했습니다. 기존 자동 등록 자료의 무승인 규칙 갱신과 PDF 등록 회귀도 통과했습니다. 브라우저 시험에서 앱 외부 통신·런타임 오류는 없었습니다.

보안관리약정서 비교 시험은 저장된 추출 텍스트를 사용합니다. 이 결과로 HWP·HWPX·DOCX·PDF의 모든 파일에 대한 바이너리 추출 정확도를 인증하지 않습니다. 기존 공개 자료 5종의 직접 자동충족 수는 여전히 0개이며, 미입력 양식·해설서에서 수치를 높이기 위해 판정 조건을 없애지 않았습니다.

## 남은 개발·별도 검증

이번 범위는 완료하되 전 206개 질문의 임의 문구·모든 참조를 이해하는 일반 추론기를 구현한 것은 아닙니다. 아직 지원하지 않는 자동화 가능 질문의 요건, 표준과 자유롭게 바꿔 쓴 문장의 동등성, 복잡한 별첨 선택·예외 해소는 추가 개발 범위입니다. 이 범위와 폐쇄망 실제 자동판정률·오판율·장비 성능 측정은 구분합니다. 자체 시험의 오류 미발견을 실제 오판율 0으로 해석하지 않습니다.
