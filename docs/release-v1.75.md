# v1.75 — 자동판정 구조 개편의 첫 구현

## 반영

- 관련 조항 인식과 최종 충족 판정을 별도로 반환·표시합니다. 책임 면제도 관련 문구로 인식하며, 면제가 적절한지는 별도 판정으로 남깁니다.
- 현행 통합 질문의 제한된 판정 규칙은 관련 문구를 찾은 경우 낮은 매핑 등급만으로 중단하지 않고 내용 검사를 진행합니다. 당사자 역할·서비스·관계·수동 재지정 등 적용범위 게이트는 유지합니다.
- 무관한 연락처·다른 조항의 빈칸으로 문서 전체의 정형 판정을 차단하지 않습니다. 관련 근거의 빈칸, 해석할 수 없는 손상 문장과 전역 우선·면제 조건은 계속 검사합니다.
- 동일 구역의 두 문장에 나뉜 상호 귀책책임·통상손해 범위를 결합합니다. 다른 조항이나 다른 문서의 부분 요건을 임의 결합하지 않습니다.
- ‘계약기간: 유효 시작일 ~ 종료일’ 형식을 인식합니다. 날짜 오류·역전 및 미인식 갱신 조건은 통과하지 않습니다.
- 보류 표에 판정을 막은 원문, 인식한 관련 문구, 미확인 요건을 구분해 표시합니다.
- 판정 엔진 버전을 변경하여 이전 자동 근거를 현행 규칙으로 재검사합니다. 사람의 판정은 보존합니다.

## 범위·미완료

이번 배포는 전체 계획의 완료가 아닙니다. 206개 질문의 존재·명확성·적정성 기준 전수 정리, 범용 약정요소 추출, 표준서식·사용자 코퍼스의 적용조건 기반 판단 재사용 확대는 후속 구현 대상입니다. 태그는 기존 검색·매핑 경로를 유지했으며 이번 버전에서 새로운 태깅 데이터를 학습하지 않았습니다.

## 실문서 확인

저장된 공개 표준계약 텍스트 5개에 대해 v1.74와 동일 입력 비교를 수행합니다. 이들 자료에는 미기입 서식, 안내문, 현재 규칙 밖의 내용이 포함되어 있으며 정답지가 없습니다. 최종 자동충족은 변경 전후 모두 0개입니다. 이를 실무 자동판정 비율 개선의 증거로 주장하지 않습니다. 무관한 문서 전체 품질 차단이 관련 근거별 검사로 바뀐 점과 차단 원문의 추적 가능성을 검증합니다.
