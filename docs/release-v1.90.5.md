# v1.90.5 — 기능을 보존한 화면 개편

- 계약서 입력: 기존 세로 배치와 전체 폭 입력란 유지. 우측 설정 칸을 별도로 만들지 않음.
- 조항별 검토: 기존 삼단 구성, 체크리스트 제목·질문·설명·판정 근거 및 입력 기능 유지. 카드 간격과 글자 위계를 정돈함.
- 검토 단계와 자료·검토 관리 메뉴를 두 줄로 구분함. 자동판정 상태는 바로 표시하고, 재실행·평가·백업 도구는 펼쳐 사용함.
- 리포트: 계약명·검토 상태·저장/내보내기를 상단에 배치함. 종합의견 및 작성한 의견은 본문, 남은 판단과 항목 이동은 오른쪽에 배치함. 좁은 화면에서는 남은 판단을 먼저 표시함.
- 판정 정리와 저장 완료는 구분함. 남은 필수 판단이 없다는 표시는 계약에 위험이 없다는 뜻이 아님.
- 비교·형식 점검·완료 항목·팀 관리·코퍼스 및 평가 기능을 유지함.
- 분석·매핑·자동판정 엔진, 체크리스트 내용, 저장 키와 데이터 형식은 변경하지 않음. 화면 변경에 따른 재분석이나 전체 화면 관찰자를 추가하지 않음.

## 설치

기존 폐쇄망 실행기를 사용하는 경우 ZIP 안의 v1.90.5 업데이트 파일을 실행기의 업데이트 메뉴로 불러옵니다. 기존 저장소와 주소를 유지해야 누적 자료가 보존됩니다. 새 HTML을 다른 위치에서 바로 열면 브라우저 저장 영역이 달라질 수 있으므로 기존 실행기를 이용하세요.
