# v1.62.0 — 3차: 자동판정 후보 관찰·제한 승인·오판 중지

## 달라진 점

‘검토 정확도 평가’의 독립 검수 영역에 ‘자동 이상없음 후보 시험·운영 중지’를 추가했습니다. 파일을 다시 내보내지 않고 현재 평가의 독립 검수 2명 결과에 후보 규칙을 대조합니다.

1. 기존 절차로 원문·초안을 준비하고 독립 검수 2명의 결과를 저장합니다.
2. 새 영역을 열고 ‘현재 평가의 체크·저장 후보 불러오기’를 누릅니다.
3. 시험 체크, 계약 유형과 당사 역할, 의무 주체·행위·대상·조건·방향·시험 이유를 입력합니다. 부서는 계약 유형을 제한하는 기준으로 쓰지 않습니다.
4. 원문 변환·별첨 누락·유형·역할을 확인한 뒤 ‘독립 정답과 후보 대조’를 누릅니다. 입력만 중간 저장할 수도 있습니다.
5. 후보 충족, 잘못된 이상없음, 미확정 정답 통과 후보, 근거 오연결을 구분해 확인합니다. 본건 근거 문장과 미충족·충돌 건수를 표시하고 내부 평가 저장소에 이력을 보존합니다. 평가 준비 백업에도 포함됩니다.

이름 확인은 검수자 인증이 아닙니다. 실제 독립성은 조직의 검수 절차로 관리해야 합니다. 후보 입력자가 이미 정답을 보았으므로 이 결과는 개발 관찰이며 독립 시험 성공으로 세지 않습니다.

## 안전장치

- 원문·초안·체크 변경 또는 독립 검수 부족 시 시험을 차단합니다.
- 단서·부정·주체 혼동·필수 조건 누락, 원문 미확인, 매핑 미충족은 후보를 보류합니다. 문언 검사는 법적 충분성을 보장하는 추론기가 아닙니다.
- 간편 양식은 단일 요건 문언 관찰만 지원합니다. 복수 요건·수치 제한 등 복잡한 충분성은 관리모드의 정밀 규칙에서 다뤄야 합니다. 간편 후보는 운영 원장에 등록·승인되지 않습니다.
- 운영 승인 시 개발·시험·반례, 위험 상한 등 기존 요건에 더해 근거 오연결과 문제 항목 비노출을 차단합니다. 평가 후 승인할 유형·역할 조합을 명시 선택해야 합니다.
- 일반 평가 화면에서도 승인 원장 상태 확인과 전체 긴급 중지가 가능합니다. 오판 의심 신고는 신고자·사유·해당 규칙·시험셋 지문을 보존하고 해당 규칙을 중지합니다. 동일 규칙·동일 시험셋으로 재승인할 수 없습니다.
- 중지는 사람 판정을 지우지 않습니다. 기존 자동판정은 재확인으로 돌아가며, 다른 열린 창에도 원장 변경을 전파합니다. 백업 복구는 자동허용을 켜지 않습니다.

## 아직 완료하지 않은 범위

이번 후보 시험은 전체 체크 조항검색에서 선정 쟁점만 대조하는 개발 관찰입니다. UI에서 입력한 유형·역할은 후보 문언 규칙 범위에 사용하며, 실사용 유형·역할별 매핑 파이프라인 평가를 대신하지 않습니다. 태그 보조 모드로 검색하고 계약·법률검토 이력 검색은 사용하지 않습니다.

선정 쟁점 부분평가에서 운영 승인용 다계약 시험셋으로 이어지는 간편 연결, 계약 계열·시점 분리, 이력자료별 기여도 비교, 오판 신고 사례의 시험셋 자동 편입은 남아 있습니다. 기존 관리모드의 고정 시험셋 승인 절차는 유지합니다. 실제 폐쇄망 자료의 정확도·자동판정 범위 확대는 검증하지 않았고 새 승인 규칙을 배포하지 않습니다. 따라서 3차 전체 완료나 자동판정 정확도 보장을 의미하지 않습니다.

## 구동

ZIP을 풀고 포함된 기존 설치·업데이트 안내에 따라 실행합니다. ‘검토 정확도 평가’ → ‘독립 정답 검수·매핑 비교’ → ‘자동 이상없음 후보 시험·운영 중지’ 순서입니다. 승인 범위 선택은 관리모드의 ‘요건 규칙·위험 한도·승인’에서 고정 시험셋 평가 후 진행합니다.
