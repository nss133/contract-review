# v1.55 안전성 작업대 운영 안내

## 기본 상태

초기 규칙·승인은 비어 있고 자동판정은 관찰 모드다. 매핑 점수, 과거 이상없음, 태그 일치만으로 본건을 이상없음 처리하지 않는다. 승인된 좁은 규칙만 제한 적용한다. 개발 시험은 합성자료이며 실제 폐쇄망 자료의 정확도를 입증하지 않는다.

## 내부 운영 순서

1. 원본·별첨과 추출 본문을 대조한다. 본건 유형·당사자 역할·적용범위 및 문서 품질을 확인하고 기준일·계약 계열을 기록한다. 부서는 보조 신호이며 계약 유형을 고정하지 않는다.
2. 골드셋 탭에서 관찰 기록과 블라인드 정답 양식을 분리한다. 작업대 검수 편집기에서 두 사람이 예측을 보지 않고 원본 근거·조항 번호·정답을 각각 기록한다. 서로 다른 이름 입력은 실제 독립성을 보장하지 않으므로 조직에서 검수자를 배정해야 한다.
3. 두 검수의 차이는 미확정으로 남는다. 필요하면 제3의 검수자가 원래 두 기록을 보존하면서 근거와 사유를 남겨 조정한다.
4. 계약들을 개발·고정 시험·반례로 나눈다. 같은 계열의 분할 중복, 숫자만 바꾼 중복 본문, 미래 과거자료, 시험 계열의 검색 유입을 차단한다. 과거 DB의 계열·기준일 메타데이터가 없으면 엄격 평가 검색에서 제외된다. 메타데이터를 내부에서 보완하고 전체 계약 재실행 후 데이터셋을 고정한다.
5. 관리자가 체크별 선언형 요건 규칙을 작성한다. 주체·행위·대상·조건·의무/금지·수치를 지정한다. 실행 코드나 임의 정규식은 받지 않는다. 해당 규칙이 체크의 모든 중요한 요건을 충분히 표현하는지는 법무 담당자가 별도 검토해야 한다. 일반적인 법률 의미 이해를 대체하지 않는다.
6. 현재 엔진으로 고정 자료를 평가한다. 개발·시험·반례와 부정 사례가 필요하며, 시험·반례의 잘못된 자동 통과 및 정답 미확정은 승인을 막는다. 유형·당사자 역할별 독립 계열 수와 오류 상한을 확인한다. 매핑 Top1/Top3, 잘못된 직접 연결, 문제 항목 미노출, 부서·유형별 결과도 따로 확인한다.
7. 승인자·근거·대표성 확인·위험 한도·만료일을 기록한다. 한도는 최대 5%이며 기본 1%다. 이는 허용 가능한 실제 오류율을 보장하는 수치가 아니라 관측된 무오류 독립 계열 수의 95% 상한 기준이다. 복수 적용집단은 보정한다. 대표성·계열 독립성·미래 분포 변화는 별도 관리해야 한다. 승인 후에도 전역 활성화를 따로 해야 한다.
8. 운영 중 본건의 근거·품질 확인·적용집단·규칙·엔진·유효기간을 재검사한다. 원문 변경 시 기존 시스템 통과는 즉시 재확인으로 돌아간다. 만료는 주기적으로 재검사한다. 이번 버전에서 직접 판정한 기록도 입력 맥락이 바뀌면 재확인을 요구한다. 이전 수동 기록은 소급하여 지문을 만들지 않는다.
9. 오류를 발견하면 해당 규칙 또는 전체 자동판정을 즉시 중지하고 원인을 조사한다. 작업대 평가에서 오류가 확인된 기존 승인 규칙도 중지한다. 새로운 규칙·자료·엔진은 다시 시험·승인한다. 시험 결과를 보고 규칙을 반복 조정했다면 새 독립 시험자료를 확보한다.

## 증거 및 보수적 제한

과거자료는 같은 문장 안의 근거만 보강한다. 주체·부정·시점 차이가 있으면 보강을 취소한다. 본건 규칙도 여러 문장의 단어를 임의로 합쳐 충족시키지 않는다. 반대 의무, 의무 없음, 복수 주체, 수치 충돌, 인용·가정·노력 표현 등은 보류한다. 예외·단서가 있는 문서 묶음은 보수적으로 자동허용을 막으므로 정상 계약도 수동 확인으로 남을 수 있다. 이 제한이 모든 모호성이나 법적 위험을 탐지한다는 뜻은 아니다.

## 보관·복구와 보안 한계

모든 정답·원본·데이터셋·백업은 폐쇄망 내부에만 저장한다. 외부 AI나 개발 환경으로 옮기지 않는다. 파일에는 계약 원문이 포함될 수 있다. 다운로드도 내부 승인된 저장 위치를 사용한다.

승인 원장과 설정은 해당 브라우저 저장소에 보관된다. SHA-256 지문은 변경 검출용이며 인증·전자서명이 아니다. 파일이나 브라우저 저장소를 편집할 수 있는 사용자를 방어하는 보안 경계가 아니므로 내부 접근통제와 승인 문서를 병행한다. 백업 복구 시 규칙·이력은 보존하지만 전역 활성화와 승인 효력은 복원하지 않는다. 재검증·재승인 후 활성화한다.

조직 인증, 서버 중앙 승인·감사 저장, 실제 내부 데이터 검수, 규칙의 법적 충분성·운영 위험 한도 승인은 이 단일 HTML의 자동 완료 범위가 아니다. 현재 배포본은 이 업무를 수행할 수 있는 로컬 흐름을 제공한다.
