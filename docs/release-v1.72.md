# v1.72 — 표준조항 자동판정 확장

v1.71의 표준서식 등록과 계약내용 검토 범위는 유지한다. 폐쇄망 자료 반출이나 외부 AI 없이 동작한다. 기존 사람 판정은 덮어쓰지 않는다.

## 1. 등록 연결 초안 자동화

팀·지식관리 → 표준서식 등록에서 파일을 넣고 유형·지위를 선택한 다음 **연결 초안 자동으로 만들기**를 누른다.

- 원문의 조항별 핵심어, 태그 및 근거 게이트를 이용해 질문과 근거 조항 묶음을 제안한다.
- 적용 계약 유형의 질문과 공통 질문만 대상으로 한다. 실제 이행 확인·금지 문구의 부재 판정은 제외한다.
- 초안은 미승인 상태다. 근거와 질문 전체를 확인한 초안만 선택해 연결하고 최종 등록·활성화한다.
- 자동 연결 점수는 질문 전체가 충족됐다는 확률이 아니다. 누락된 근거는 기존 직접 연결 기능으로 보완할 수 있다.
- 원문·적용 범위가 바뀌면 오래된 초안을 그대로 채택할 수 없다.

## 2. 동등 표현 비교 확대

사전 서면 동의, 위탁 목적 제한, 비밀정보 공개 금지, 개인정보 처리 현황 점검 협조, 종료 시 반환, 종료 후 기한부 파기, 유출 인지 시 즉시 서면 통지, 최소 접근권한의 8개 제한된 문장 구조를 비교한다.

예: 수탁자가 위탁자의 사전 서면 동의 없이 재위탁할 수 없다는 문장과, 재위탁하려면 미리 위탁자의 서면 동의를 받아야 한다는 문장을 동일한 주체·조건 구조로 인식한다.

반면 주체 역전, 사후 통지, 의무를 선택권으로 바꾼 표현, 30일→90일, 서면 요건 삭제, 새로운 면제는 동등한 것으로 보지 않는다. 승인된 표준문에 포함된 예외는 그대로 비교하고, 무관한 별도 조항의 ‘다만’만으로 일괄 보류하지 않는다. 같은 근거에 이어지는 면제·단서는 검사한다.

모든 한국어 문구의 취지를 일반 추론하는 기능은 아니다. 지원되지 않는 표현은 기존 동일 문구 또는 아래의 승인 표현 변형으로 다룬다. 태그 점수만으로 이상없음을 확정하지 않는다.

## 3. 허용 입력란

추출 원문 아래에서 허용 입력란을 선택한다. 독립된 ‘수탁자 상호: …’, ‘대표자: …’, ‘주소: …’, ‘체결일: …’ 형태만 후보로 제공한다.

- 승인한 입력란 값의 변경만 허용한다. 역할 표제 자체는 유지한다.
- 본건 별첨으로 사용할 때 등록 목록에서 값을 입력하면 사본에 반영한다. 표준 원문은 변경하지 않는다.
- 빈칸·잘못된 날짜·서로 다른 입력값 충돌은 통과하지 않는다.
- 상호나 날짜 값이 의무 본문에도 사용되면 단순 입력란 변경으로 처리하지 않는다.
- 계약기간·대금·이자율·통지기한·책임 범위, 본문 중 임의 문자열은 입력란으로 지정할 수 없다.

임의 위치에 있는 모든 이름·날짜를 자동 마스킹하는 기능이 아니다. 위 독립 입력란 형식에 맞지 않는 서식은 원문 그대로 대조한다.

## 4. 코퍼스 표현 후보와 승인

표준서식에 질문을 연결한 후 **누적 검토에서 승인할 표현 변형 찾기 → 누적 검토에서 표현 후보 찾기**를 누른다.

후보 출처:

- 원문을 보존한 내부 평가자료 중, 수동 ‘이상없음/반영되어 있음’ 판정과 사람의 조항 연결이 있는 문구.
- 코퍼스의 수동 충족 판정 의견 속 따옴표 인용 문장. 이 경우 실제 원문인지 또는 수정 제안인지 직접 확인해야 한다.

시스템 판정, 위험수용, 검토의견, 충돌 대기, 이유 없는 결론, 실제 문구가 없는 메모는 자동판정 기준으로 복사하지 않는다. 집계 태깅자료만으로 원문을 만들어내지 않는다.

1. 출처·문구·질문을 확인한다.
2. 실제 원문이며 질문 전체를 충족한다는 확인 후 선택 표현을 승인 초안에 추가한다.
3. 기준을 등록·활성화한다.

이후 같은 적용 유형·지위에서 해당 표현도 자동판정에 사용한다. 출처의 판정이 바뀌거나 없어지고, 미해결 충돌이 생기거나, 질문이 바뀌면 그 출처를 이용한 판정을 회수한다. 출처 식별자와 근거는 판정·내보내기에 남는다. 외부로 전송하지 않는다.

## 5. 평가·성능·호환

- 기존 표준서식 백업 형식을 유지한다. v1.71 자료에는 새 기능을 선택적으로 추가할 수 있다.
- 복구 자료는 기존과 같이 승인 대기로 들어온다.
- 원문·표현 구조는 한 번의 판정 실행에서 재사용하며, 이력 원문 전체를 매 체크마다 읽지 않는다. 후보 수집은 버튼을 눌렀을 때 수행한다.
- 이력 평가에서 같은 계약에서 배운 표현을 자기 정답으로 재사용하지 않는다. 다만 계약 계열 완전 분리 시험은 아니므로 결과를 독립 정확도로 표시하지 않는다.
- 이행 확인 제외, 질문 변경 제외, 실제 자동충족, 사람의 검토의견을 통과시킨 불일치는 구분해 집계한다.

## 범위와 검증 한계

이번 버전은 폐쇄망 피드백 없이 개발할 수 있는 네 기능을 구현한 것이다. 폐쇄망의 실제 계약·표준서식에 대한 자동판정 비율과 오판율은 아직 측정하지 않았다. 지원 범위 밖의 문장, 실제 태그 분포에 맞춘 추가 사전·표현 정교화는 운영 자료를 보고 확장할 수 있다.
배포 ZIP에는 사용자 코퍼스와 등록 표준서식을 포함하지 않는다. 등록 후 폐쇄망 안에서 표준서식 백업을 보관한다.
