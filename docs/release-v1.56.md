# v1.56 변경 안내

## 제거한 기능

사용자 요청으로 별도 업무·규제 해당성 탭, 해당성 분석·사실 보정·독립 백업 UI와 실행 코드를 제거했다. 계약 검토의 개인정보·업무 적용범위 설정, 체크 묶음, 기존 판정·지식 DB는 유지한다. 이전에 저장한 자료백업 파일은 삭제하지 않았으며 필요하면 이전 v1.55 배포본에서 열 수 있다.

## 문서완결성 오탐 개선

기존에는 제한된 제N조 표제 인식에 실패하면 조항 주소록에 등록하지 않은 채 해당 조항이 없다고 경고했다. 이제 매핑용 문단 분할과 별도로 표제를 읽는다.

- 제1조(제목), 제1조[제목], 제1조 제목, 1조(제목), 공백·전각 숫자·전각 괄호를 인식한다.
- 숫자 점·닫는 괄호·괄호 숫자·Article 표제는 존재 후보로 읽되 조·항·호 층위를 확정하지 않는다.
- 번호 구조가 불확실하거나 본문 중복·번호 유실·깨진 문자 징후가 있으면 개별 조·항·호 누락 경고를 억제한다.
- 추출 불확실성은 '자동 점검 범위 제한' 안내 하나로 모은다. 오류 카드, 필수 처리 건수, 미완료 건수로 만들지 않는다. 리포트도 '확인 완료'라고 표시하지 않는다.
- 구조를 인식한 문서도 '존재하지 않는다'고 단정하지 않고 '인식된 표제에서 찾지 못했으므로 원문 확인'으로 안내한다.

이는 OCR이나 원본 복원 기능이 아니다. 추출 시 완전히 사라진 조문·표·그림은 복원할 수 없다. 제한 상태에서는 해당 부분을 원본으로 확인하는 것이 대안이다. 폐쇄망 실자료를 반출하지 않았으며 실제 오탐 감소율은 측정하지 않았다.

## 계약검토 태그·원본 참고

기존 자동 참고는 태깅 지식 저장소를 검색했으므로 계약검토 이력 DB에만 가져온 자료는 빠질 수 있었다. 두 저장소의 조회 어댑터를 연결했다. 같은 원본 ID로 명시 연결된 자료는 중복 후보로 세지 않는다.

- 계약검토 이력만 적재해도 계약명·요청내용·태그로 후보를 찾고, 부서는 약한 보조 신호로만 사용한다.
- 계약검토 가져오기에서도 태그 1~52, 표시용 해시태그, 엄격 태그 열의 원문과 태그를 보존한다. 미보존 과거 태그는 자동 복원하지 않는다. 기존 태깅 XLSX 재적재가 필요할 수 있다.
- 지식 데이터·리포트에 계약검토 전용 참고 패널을 추가했다. 자료·태그 보유 건수, 후보, 일치어, 출처 ID, 신청·결과 불일치를 표시한다.
- 기존 shadow 표시의 의미를 '법률·계약 공통 태깅자료의 단순 일치 표시'로 명확히 했다. 단순 용어 일치 표시는 점수를 가산하지 않는다.
- 이력의 요청내용이나 검토결과를 계약 원문 근거로 간주하지 않는다. 검증 가능한 근거 문장이 없는 이력은 조항 점수를 가산하지 않는다. 과거 이상없음은 본건 자동판정으로 복사하지 않는다.
- 계약검토 이력 변경도 안전성 평가의 환경 지문을 바꾼다. 엄격 평가에서는 본건·계열·시점 검증을 동일하게 적용한다.

모든 파일과 정답·원문·태그는 폐쇄망 내부에만 보관한다. 업데이트는 기존 실행기에서 진행하며 지식팩·이력팩 백업을 먼저 권장한다.
