# Python 파일 추출·분석·수기 검토 완료 연결

> 최신 진행: 현재 원문 자동판정을 Python 서버와 화면·완료 기록에 연결했다. [자동판정 검증 기록](2026-09-21-python39-automatic.md)을 우선 확인한다. 아래 이전 단계의 미연결·검사 수치는 당시 기록이다. 전체 운영 이전 완료 게이트는 유지한다.

2026-09-21. 기존 화면을 열었지만 파일 추출·계약 분석·최종 완료가 비활성인 문제를 수정했다. 이전 기반판의 501 응답을 실제 처리 경로로 바꿨다. Python 3.9.25·FastAPI 0.128.8·서버 로컬 SQLite를 사용하며 정적 프론트와 API는 별도로 실행된다.

## 실제로 연결한 기능

- TXT, DOCX, HWPX, PDF, DOC, HWP의 본문 추출. 원본 바이트·해시·추출 결과를 계약별 SQLite에 저장하고 권한을 확인한 후 원본을 내려준다. 본문·원계약·별첨 업로드를 구분한다.
- 기존 규칙에서 이전한 Python Matcher로 문서 분할, 계약 유형·모듈 추정, 체크리스트와 현재 조항 연결, 원계약·별첨 관련 문구를 분석한다. 제품 실행에 기존 Node·JavaScript 분석 엔진을 사용하지 않는다.
- 원문·확인사항·의견의 기존 3열 화면에서 항목별 이상없음/검토의견·사유·의견을 저장한다. 계약·항목 revision을 검사하여 동시 수정을 덮어쓰지 않는다.
- 원문이나 분석 조건이 바뀌면 기존 의견을 보존하고 재확인을 요구한다. 동일 입력·조건 재분석이면 기존 확인 의견을 유지한다.
- 모든 대상 항목 확인, 원본 대조 확인, 현재 분석과 각 의견의 최신 revision을 서버에서 검증하고 완료 스냅샷을 저장한다. 완료 후 의견이 변경되면 이전 완료를 현재 결과로 표시하지 않는다.
- 종합 의견 초안 저장, 완료 리포트 재조회, JSON 내보내기, 최신 저장본 조회와 작성 중 내용 백업을 연결했다. 수정하지 않은 완료 기록을 열 때 원본 확인을 다시 요구하지 않는다.
- SQLite 백업에는 첨부 원본·분석·의견·완료 스냅샷·권한이 함께 포함된다. 첨부 해제는 원본을 삭제하지 않아 이전 완료 기록의 원본을 계속 확인할 수 있다.

분석과 추출은 최대 2개의 별도 Python 프로세스에서 처리한다. 처리 제한은 45초이며 Linux에서는 CPU 40초·주소공간 1GiB 제한을 추가한다. API는 Uvicorn 1프로세스로 실행한다. 요청 8MiB, 파일 7MiB, 활성 첨부 20개, 분석 본문·첨부 총 50만 자 및 본문 300조항 제한을 둔다. 작업이 밀리면 재시도 안내를 반환한다.

1,222개 중 1,162건은 기존 264개 합성 Node 시험에서 관측한 함수 호출 비교다. 서로 독립적인 1,162개 계약 사례나 전체 자동판정 동등성 검증을 뜻하지 않는다. 화면 시험은 합성 문서와 별도 검증 DB를 사용했다. 실제 사용자 계약에 자동으로 최종 의견을 부여하지 않았다.

## 남은 전환 범위와 형식별 한계

이번 분석은 현재 원문 매칭과 검토사항 제시까지다. 기존 ClauseSemantics·AgreementJudgment·StandardAuto·ReviewCore의 전체 자동 최종판정은 아직 연결하지 않았고 automatic_verdicts=false로 공개한다. 현재 최종 완료는 사람이 항목별 의견을 확정하는 흐름이다. 기존 자동판정을 수기 확인으로 대체한 결과를 전체 동등성 통과로 표시하지 않는다.

구형 검토 JSON 자료 이관, 등록 표준·평가·관리·지식 검수·로컬 AI의 전체 화면 연결도 미완료다. 해당 컨트롤은 비활성 상태이며 [전체 이전계획](superpowers/plans/2026-09-21-python39-fastapi-migration.md)의 완료 게이트를 유지한다.

이미지 전용 PDF의 OCR은 지원하지 않는다. PDF의 읽기 순서·표 구조, 구형 DOC/HWP의 표·자동번호 등은 추출 경고를 표시하며 원본 확인을 요구한다. 암호화·손상 파일은 성공으로 표시하지 않는다. 모든 실제 사내 문서에 대한 추출 동등성을 검증했다는 뜻은 아니다.

Linux 배포판·CPU를 사용자에게 다시 묻지 않고 preflight 도구로 확인한다. 실제 Linux의 Python·Nginx·systemd·사내 HTTPS·재시작 인수검증은 아직 실행하지 못했다. 기존 개발 ZIP이나 이전 wheel은 이번 수정본이 아니며 전체 운영 완료 패키지로 사용할 수 없다.
