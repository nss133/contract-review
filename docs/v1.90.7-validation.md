## 재현 및 수정

v1.90.6 기준본에서 종합의견 편집 후 리포트를 다시 그리면 저장 전 입력이 자동 생성 의견으로 바뀌는 실패를 재현했다. 계약 해시별 메모리 초안 보존·편집 복원으로 수정하고 같은 시험을 통과했다. 검토 마치기·내보내기에 현재 편집 내용을 반영하며 의견 저장 실패, 아카이브 저장 실패·축약 저장, 코퍼스 저장 예외를 구분한다. 저장 전체의 원자성이나 실패 시 롤백을 보장하지 않는다.

리포트 상단 간격을 줄이고 CI·문구·컨트롤·매핑·판정 기준·기존 저장 형식은 유지했다.
