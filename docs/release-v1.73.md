# v1.73 — 표준서식 승인 없이 자동 등록

- 지식관리에서 표준서식 파일을 넣으면 추출·자동 연결·저장까지 처리합니다. 여러 파일을 한 번에 넣을 수 있습니다.
- 자료 승인, 계약 유형 선택, 조항 선택은 필수가 아닙니다. 수동 편집은 선택적인 상세 설정으로 이동했습니다.
- 백업 복구도 현행 규칙으로 다시 처리하여 등록합니다. 기존 로컬 자료와 사람의 검토 결과는 덮어쓰지 않습니다.
- 파일 등록 완료와 질문 충족 판정은 구분합니다. 전체 요건 인식 규칙이 확인한 질문만 자동판정에 연결합니다. 단순 키워드 후보는 자동 통과하지 않습니다.
- 기존 정형 판정 규칙과 개인정보 접근 제한·처리 현황 점검의 제한된 완전 문장 규칙을 사용합니다. 모든 표준 문구를 자동 이해하는 AI 기능은 아닙니다.
- 폐쇄망 실제 자료의 자동판정 비율은 아직 측정하지 않았습니다. 자료는 브라우저 내부에 저장하며 외부 전송하지 않습니다.

사용 방법: 지식관리 → 표준서식 파일 넣기 · 자동 등록 → 등록 완료 표시 확인. 승인 버튼을 누를 필요가 없습니다.
