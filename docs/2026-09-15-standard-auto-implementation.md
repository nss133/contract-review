# AI 없는 자동판정 개선 — v1.66 구현·검증 상태

## 구현 완료

- 명시적 조항 구역에 따라 관련 단서를 구분. 참조 목적지 불명·전역 효력·변환 오류는 보수적으로 유지.
- CMN-04/05/06/19의 좁은 정형 요건 판정과 일회용 내부 티켓을 통한 실제 자동확정.
- 본문·별첨·맥락·현행 체크가 정확히 같은 사람의 내용 충족 판정 재사용. 집계에서 정답 추정, 위험수용의 정상 패턴 승격은 하지 않음.
- 간편 실행·전체/항목 중지·구체적 보류 이유·근거 원문 표시. 기존 독립 검수형 승인과 새로운 정형 요건 확인을 구분하여 표시.
- 코퍼스 변화와 분리한 정형 판정의 입력 지문. 무관한 코퍼스 추가만으로 정형 판정 회수하지 않음. 기존 승인형 경로의 전체 엔진 지문은 변경하지 않음.
- 선택형 IndexedDB 원문·판정 자동저장, 저장된 검토 재실행, 진행·취소, 내부 백업·중복 덮어쓰기 없는 복구.
- 평가에서 자기 정답을 자동 재사용 경로에 투입하지 않음. 과거 보완 판정을 통과시키는 체크는 중지.
- 기존 사람 판정 보존, 문서 편집 후 자동판정 회수, 실제 완료목록·리포트 정합성 검증.

## 검증

- Node 576개, Python 103개 통과.
- 브라우저: 네 정형 항목 실제 자동확정·완료 분류, 무관 코퍼스 변화 유지, 사람 보완 판정 보존, 평가 충돌 1건 감지 및 해당 항목 중지, 전체 중지·재개, 본문 편집 후 회수, 평가 백업·중복복구.
- 기존 승인형 브라우저: 독립 검수·60개 합성 계열 승인 시험·실제 승인형 통과·원문 수정 회수·오판 중지·복구 비활성·외부 요청 0.
- 기존 검토완료 브라우저: 21개 체크, 잔여 0, 리포트 링크·재확인·판정 유지 검증, 외부 요청 0.
- 배포 ZIP 무결성, 버전, 업데이트 HTML과 SHA256 일치, 사용자 코퍼스 미내장 확인.
- 합성 자료는 실계약 정확도 표본으로 계산하지 않음. 충돌 시험의 1건은 의도적으로 넣은 사람 보완 라벨이며 오류 감지 동작 확인용.

## 전체 계획 중 미완료·검증 불가 범위

- 보안약정·해지·손해배상의 다양한 표현을 서로 다른 신규 계약에 일반화하는 자동판정 패턴은 아직 구현하지 않음. 본문·별첨의 동일 입력 재사용 및 기존 승인형 다중 요건 경로만 제공.
- 기존 원문 없는 29건 집계와 계약 원문의 자동 연결 복원은 하지 않음. 새 평가 저장은 선택 이후의 원문 있는 기록에 적용.
- 임의의 단서·정의·참조 의미를 완전 해석하지 않음. 명시 구역 밖의 영향이 불명확하면 보류.
- 간편 일괄 평가는 저장된 적용 체크·매핑 상태를 기준으로 정형 패턴을 재실행하며 전체 추출·매핑 파이프라인의 독립 재평가가 아님.
- 폐쇄망 실계약 자동판정률·오판율·대규모 실제 장비 지연은 미측정. 일반화 성과 또는 1~3차 계획 전체 완료로 표시하지 않음.
