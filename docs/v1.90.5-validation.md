# v1.90.5 UI 개편 검증

최종 HTML SHA-256: 49c5909abe66752fc93c83a5b28e39bd66f73e1f2d30e5c60440193ecceced8d.

## 범위

실제 앱에 기능 보존형 시안을 적용함. 계약서 입력은 기존 전체 폭·세로 배치를 유지하고, 리포트는 상태·저장·종합의견·작성한 의견·남은 판단 순으로 재구성함. 체크리스트 내용, 매핑과 자동판정 로직, 저장 키·포맷은 변경하지 않음. 별도 관찰자나 분석 재실행을 추가하지 않음.

## 검증 방법

- Node 전체 1,622개, Python 전체 107개 시험.
- v1.90.4와 격리 Chrome에서 같은 합성 계약으로 비교: 초기/분석 후 기존 컨트롤·문구, 전체 조항별 검토 텍스트, 매핑 및 자동판정 결과 동일.
- 신규 UI 시험 36개: 세로 입력, 삼단 유지, 7개 탭 이동, 관리 도구, 실제 수기 입력·저장, 종합의견 편집, 완료 차단·항목 이동, 실제 검토 마치기, 인쇄, 계약명 안전한 출력, 1440/1100/800px 가로 넘침 없음.
- 표준약정 회귀: PRIV-07·21 자동판정과 ②열 배치, 구 등록자료 자동 갱신, 새로고침, 수기 의견 보존, 수정된 별첨 및 미편입 표준의 자동판정 차단.
- 실행기: 합성 태깅 1건·검토이력 2건을 새로고침·시험용 업데이트 후 유지. 관할·부가세 자동판정 유지.
- 기존 대용량 성능 회귀시험: 합성 태깅 500건·고유 근거 26,000행·코퍼스 29건과 긴 계약·CPU 제한 조건에서 결과 동일성, 연결 편집 시 전체 매핑 재실행 없음 확인.
- 최종 HTML 단일 실행 측정: 최초 분석 1.369초, 동일 입력 재분석 0.373초, 자동판정 13건. 비교용 v1.90.2는 4.105초/2.028초/13건. 일반 연결 편집 22~39ms, 281조항·페이지 CPU4 조건 125ms 및 전체 매핑 재실행 0회. 반복 표본 통계나 폐쇄망 실장비 결과가 아님.
- 시험한 브라우저 경로에서 앱 예외 및 외부 요청 없음. 입력·미완료 리포트·완료 리포트의 합성 화면을 이미지로 확인함.

## 빌드 및 한계

- iCloud 법령 DB 접속이 대기하여 기존 v1.90.4 배포본에 이미 내장된 법령 원문만 임시 SQLite로 복원해 빌드함. 버전·코드 지문을 제외한 내장 지식 데이터 전체가 기존 배포본과 동일함을 대조함. 기존 원문 미확인 표시는 유지하며 신규 법령 검증을 주장하지 않음.
- 설치된 Playwright가 없어 기존 CDP 기반 격리 Chrome 시험 도구를 사용함. 사용자 작업 중인 시안 창과 저장소는 조작하지 않음.
- 실제 폐쇄망 장비·모든 파일 형식·모든 관리 기능의 종단 간 검증이나 일반 사용자 관찰시험을 완료했다는 의미는 아님. 파일 추출기는 변경하지 않음.
- 최초 광범위 UX 계획의 되돌리기·다음 항목 이동 등은 이번에 추가하지 않음. 사용자가 채택한 기능 보존형 시안과 입력/리포트 수정 요청을 구현한 범위임.
- 배포 ZIP에는 비공개 코퍼스·사용자 원문·임시 시험 자료를 넣지 않음. 기존 ZIP은 보존함.
