# v1.90.7 — 폐쇄망 반입 전 사전점검

아직 폐쇄망에 반입하지 않은 상태에서 합성 자료로 재현·점검한 개선이다. 폐쇄망 실사용 장애를 확인했다는 의미는 아니다.

## 반영 내용

- 리포트가 다시 그려질 때 작성 중인 종합의견이 초기 내용으로 바뀌는 문제를 수정했다. 계약별 초안과 편집 중 커서·선택 영역을 유지한다.
- 검토 마치기와 검토의견 내보내기는 현재 작성 중인 종합의견을 먼저 저장·반영한다. 취소는 초안을 버리고 마지막 저장 의견으로 돌아간다.
- 의견 저장 실패 시 편집 내용을 유지하고 다시 저장하도록 안내한다. 완료 과정의 저장 실패도 성공으로 표시하지 않는다. 일부 단계만 저장되었을 가능성을 명시하며 재시도·내보내기를 안내한다.
- 저장 공간 부족으로 아카이브 원문을 제외한 축약 저장이 발생하면 누락 사실을 별도로 안내한다. 기존 저장 형식·용량 부족 시 대체 저장 방식은 유지하고 그 결과를 명확히 알린다.
- 미래에셋 CI와 판정 구성 차트를 유지하면서 리포트 상단 여백을 줄여 종합의견을 더 위에 배치했다. 기존 기능·체크리스트 문구·삼단 검토·자동판정 기준은 유지한다.

## 사용상 주의

작성 중 초안 보존은 현재 탭 메모리 기준이다. 새로고침하거나 브라우저를 닫기 전에는 의견 저장을 눌러야 한다. 저장 실패 메시지가 나오면 먼저 의견을 별도로 복사해 보관한다. 전체 완료 저장은 단일 트랜잭션이 아니므로 실패 전 일부 단계는 저장될 수 있다.

## 업데이트

기존 실행기의 버전 설치·업데이트에서 ZIP 안의 contract-review-v1.90.7.crupdate를 불러온다. 기존 실행기의 위치·이름과 브라우저 프로필을 유지한다. 기존 태깅자료를 다시 적재할 필요는 없다. 중요한 자료의 내부 백업은 유지한다.
