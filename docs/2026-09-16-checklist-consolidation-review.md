# 체크리스트 통합·자동확인 개선 검토

작성일: 2026-09-16 / 대상: 현행 체크리스트 238개 / 성격: 제품·데이터 구조 점검

## 쟁점·진행경과

- 지연이자 항목(CMN-05-2)의 검색어와 자동충족 후보에 지체상금이 직접 포함되어 있었음. 해당 연결을 제거하고, 모호한 지연손해금은 대금 지급지연 문맥이 있어야 근거가 되도록 수정함.
- 기존 묶음은 같은 조항에 붙은 제목을 접어 보여주는 수준이며, 개별 판정·완료 건수는 그대로였음. 이 방식만으로는 검토 부담과 중복 판정 문제가 해결되지 않음.
- 부가세 자동확인은 이미 있었으나 제한된 완결 문장 위주였음. 금액 문장·괄호·표형 표시까지 인식 범위를 넓힘. 새 법률 기준의 적정성을 검증하는 작업이 아니라 현행 질문의 중복과 제품 동작을 점검한 결과임.

## 검토의견

‘화면상 한 쟁점·한 판정, 내부적으로는 세부 요건·근거 보존’을 권고함. 과거 ID를 삭제하는 단순 병합은 권고하지 않음.

| 대상 | 제안 질문/동작 | 장점·기회 | 손실 위험과 보완 |
|---|---|---|---|
| 손해배상 | 귀책사유·배상범위·면책 및 지연책임이 본 계약의 성격과 회사의 지위에 비추어 합리적인가? | 6개 원항목을 한 검토 카드로 정리; 지체상금은 이행지연 손해배상 쪽에 배치 | 상한·간접손해·이자·위약금의 개별 문제를 놓칠 수 있음. 적용되는 세부요건별 결과와 근거를 카드 안에 표시 |
| 비밀유지 | 비밀정보의 범위·보호의무·예외·존속기간이 적절한가? | 정의와 기간을 한 번에 확인; NDA 심화항목도 같은 카드에 조건부 표시 | 일반 비밀유지와 NDA 세부의무를 동일시할 위험. 유형별 요건을 활성화하고 정의 존재만으로 전체 통과 금지 |
| 기타 중복 | 종료, 대가, 수행범위, 개인정보 위탁 등 30개 후보 묶음 | 반복 질문 감소; 본문·별첨 근거를 쟁점별로 함께 제시; 코퍼스도 세부 쟁점으로 재사용 | 같은 단어라도 적용대상·효과가 다를 수 있음. ‘통합’과 ‘조건부 묶음’을 구분하고 독립 항목 유지 |
| 부가세 | 포함/제외/별도/미포함이 명시되면 표시 사실 자동확인 | 사람이 같은 사실을 반복 체크할 필요 감소 | 부정·예시·선택·상충 표시를 오해할 수 있음. 확정 표시만 통과하고 출처 저장; 세법상 적정성은 판정하지 않음 |

전수 대응표와 각 묶음의 손실 방지 기준은 [별첨](2026-09-16-checklist-consolidation-inventory.md)에 수록함. 전체 카탈로그에는 특정 유형에서만 활성화되는 항목이 많으므로 카탈로그 축소 수치를 실무 검토시간 절감률로 보아서는 안 됨.

## 대응방안·구현 순서

1. 이번 수정: 지체상금 단독 조항을 지연이자 근거에서 제외하고, 부가세 확정 문구 인식을 확장함. 회귀시험을 추가함. 기존 수동 판정은 덮어쓰지 않음.
2. 다음 구조 변경: 안정적인 상위 쟁점 ID와 기존 하위 요건 ID를 연결함. 같은 조항 안에서만 묶지 않고 본문·별첨 여러 조항의 근거를 한 카드에 모음. 상위 판정은 한 번만 요구하며 완료 건수도 상위 단위로 집계함.
3. 세부 체크박스: 모든 상자를 사람이 클릭하도록 강제하지 않음. 각 세부요건에 적용/비적용/불명확, 충족/보완, 원문 근거를 자동 채움. 사람은 미해결·상충 요건을 확인하거나 상위 판정을 내림. 보완·위험수용·비적용 사유는 기존처럼 남김.
4. 이관: 과거 하위 항목의 ‘이상없음’ 하나를 상위 전체 ‘이상없음’으로 승계하지 않음. 확인한 하위 범위만 재사용하고 기존 보완 결과는 반드시 노출함. 통합 버전·원 ID·원 질문·근거·판정 주체를 보존함. 부분 판정은 부분 판정으로 표시하며, 화면에서 사라진 숨은 미완료 항목으로 완료를 막지 않음.
5. 자동판정: 적용되는 하위 요건이 모두 충족되고 상충이 없을 때 상위 자동판정함. 선택적인 책임상한·지체상금 약정은 없다는 이유만으로 무조건 누락 처리하지 않음. 적용 여부를 판단할 근거가 부족하면 임의로 비적용 처리하지 않음. 기존 CMN-11 정형 문구는 배상 귀책·범위의 근거일 뿐 새 통합 질문 전체를 통과시키지 않음.
6. 평가·코퍼스: 하위 요건의 매핑 정답과 판정 정답을 유지하고 상위 평가를 추가함. 분모는 ‘기존 원항목’과 ‘새 쟁점 단위’를 따로 보고하여 단순 병합 때문에 자동판정률이 오른 것처럼 보이지 않게 함. 잘못된 이상없음 건수, 적용 하위요건 누락, 근거 오매핑, 수동 클릭 수, 처리시간을 함께 비교함. 개인정보·하도급·금융위탁 특수항목은 별도 평가 구간으로 유지함.

## 이번 변경과 미구현 범위

- 구현: CMN-05-2 매핑 교정, CMN-05 확정 문구 인식 확장, 전수 대응표 생성·누락/중복 검증 및 회귀시험.
- 아직 미구현: 상위 쟁점 카드, 공통 판정·완료 집계, 과거 판정 마이그레이션, 통합 기준의 코퍼스/평가 화면. 별첨은 이 변경의 설계안이며 실제 질문 238개를 삭제·재편한 상태가 아님.
- VAT는 기존 ‘정형 문구 자동판정’ 실행 흐름에서 작동함. 문서·적용 범위 확인은 여전히 필요하며 항목마다 VAT를 수동으로 확인할 필요는 없음. 자동실행 기본값 변경·VAT 독립 카드 제거는 이번 수정에 포함하지 않음.
- 개인정보 위탁 책임, 신용정보 재위탁, 하도급 지급기한, 금융업무 위탁, IP 라이선스, 진술·보장 등 고유 목적의 요건은 일반 손해배상 문구로 대체하지 않음. 기존에 제외한 이행보증보험 및 일반 구상/비용전가 체크를 복원하지 않음.
- 실제 폐쇄망 자료에서의 오판률·자동판정률·시간 절감은 이번 소스 점검만으로 확정할 수 없음. 원문을 반출할 필요는 없으며 내부 평가로 측정해야 함.
