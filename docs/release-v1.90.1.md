# v1.90.1 — 체크리스트 설명과 자동 확인 포인트

기존 실행기의 버전 설치·업데이트에서 contract-review-v1.90.1.crupdate를 선택합니다. 기존 태깅자료·검토자료를 삭제하거나 다시 적재할 필요는 없습니다.

- 통합 13개 항목의 제목·질문·설명을 실제 확인 범위에 맞게 정리했습니다.
- 일반 항목 8개의 설명에서 개발·통합 이력을 걷어냈습니다. 근거 법령이나 원래 검색·판정 데이터는 보존했습니다.
- 제목은 검토 주제, 질문은 판단 대상, ‘확인할 내용’은 읽어야 할 약정과 판정 범위를 설명합니다.
- 자동판정된 항목의 ‘자동 확인’은 실제 판정 근거의 확인 요소만 최대 3개 표시합니다. 근거가 많아도 원문 버튼은 기존처럼 최대 하나입니다.
- 수기 판정, 근거가 변경된 판정, 과거 판단 재사용에는 현재 약정의 직접 자동 확인 표시를 붙이지 않습니다.
- 개인정보 위탁 범위·인력 운영·매매 하자 구제·핵심주주 의무는 현재 사람 판단 대상임을 설명합니다. 매핑된 사실을 자동판정 완료로 표시하지 않습니다.
- 기존 삼단 조항별 검토 구조, 자동판정 조건, 체크 ID·의미 버전, 수기 결과를 유지합니다.

손해배상 예시: ‘손해배상·책임 범위’ → ‘손해가 발생했을 때 누가 어떤 책임을 지는지 정한 약정이 있는가?’ → ‘자동 확인: 책임 배분 약정’. 배상한도의 적정성까지 확인했다는 뜻은 아닙니다.

이번 변경은 표시 개선입니다. 사용자가 보고한 약 3분의 분석 시간은 별도 성능 문제로 남아 있으며 이 버전에서 해결했다고 주장하지 않습니다. 이전 v1.90.0의 성능 검증기록은 당시 합성자료 시험의 기록입니다.
