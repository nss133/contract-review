# v1.63.0 — 다계약 비교·원천별 기여도·검색 격리

## 이번에 이어서 구현한 내용

독립 검수 2명이 완료된 여러 계약을 하나의 평가묶음으로 고정하고, 같은 정답에 다섯 조건을 실행합니다.

- 기본: 본건 태그 보조 없음, 과거자료 검색 없음
- 태그 보조: 본건 문장 태그 기반 매칭만 사용
- 계약검토: 태그 보조 + 과거 계약검토 자료
- 법률검토: 태그 보조 + 과거 일반 법률검토 자료
- 통합: 태그 보조 + 두 종류의 과거자료

적재된 계약검토 원본의 검토의견도 검색·쟁점 연결 보조에 사용합니다. 명시적으로 같은 계약검토 ID에 연결된 태깅자료와 원본 의견은 함께 사용하되 동일 문장은 중복하지 않습니다. 과거 의견이라는 출처를 보존하고 본건 근거나 정답으로 복사하지 않습니다. 본건의 최소 근거 점수를 통과한 조항만 보강하며, 새 자동승인은 만들지 않습니다. 검색은 어휘 기반으로, 표현 차이를 모두 이해하는 의미 추론기는 아닙니다.

## 사용 순서

1. ‘검토 정확도 평가’에서 계약별 원문·초안 확인과 독립 검수 2명을 마칩니다.
2. ‘독립 정답 검수·매핑 비교’ 안의 ‘여러 계약으로 과거자료 기여도 비교’를 엽니다.
3. ‘저장된 검수 계약·참고자료 불러오기’를 누릅니다. 서로 다른 평가 대상 2건 이상을 선택합니다.
4. 계약 묶음, 실제 계약 기준일, 개발/분리 시험/반례를 지정합니다. 계약 묶음은 알아보기 쉬운 이름이면 됩니다. 수정·연장·파생본은 같은 이름으로 묶으세요. 고유 ID는 앱이 만듭니다.
5. ‘검색에 사용할 과거자료 확인’에서 실제 검토일과 계약 묶음을 확인한 자료만 선택합니다. 같은 평가 계약의 태깅자료는 위 표와 같은 묶음으로 지정합니다. 미상 자료는 선택하지 않습니다.
6. 담당자를 입력하고 평가묶음을 고정한 뒤 ‘5개 조건 비교 실행’을 누릅니다. 선택·분할 입력은 변경 시 저장하며 수동 저장 버튼도 제공합니다. 저장된 평가 열기로 기존 결과를 다시 확인할 수 있습니다.

폐쇄망 DB를 내부에서 읽으며 이력팩이나 원문 반출은 필요 없습니다. 다계약 평가와 참고자료 스냅샷은 기존 평가 준비 백업에 함께 들어가므로 백업도 폐쇄망 안에 보관하세요. 복구한 초안은 재확인이 필요하고 이전 평가가 자동으로 새 원문의 유효 결과가 되지는 않습니다.

## 누수 방지와 결과 읽기

‘검수 이견 조정’ 화면에서는 현재 평가의 이견을 불러와 제3자가 원문·별첨, 두 검수 근거를 대조하고 결론·직접 조항·이유를 기록합니다. 준비자·두 검수자와 같은 이름은 차단하고, 원래 검수는 보존합니다. 조정은 독립 검수가 아니라 이견 해소 절차입니다. 판단 지문이 변경되므로 이전 다계약 평가묶음은 다시 고정하고 채점해야 합니다. 실제 검수자 신원과 직무 분리는 내부 절차로 확인하세요.

- 같은 원천의 다른 버전, 동일하거나 숫자만 다른 본문을 다른 계약 묶음으로 계수하지 못합니다. 유사하지만 동일하지 않은 파생본은 사람이 같은 묶음으로 지정해야 합니다.
- 같은 계약 묶음의 개발/시험/반례 교차를 차단합니다. 개발 계약 기준일은 분리 시험보다 이전이어야 합니다.
- 자기 계약과 시험·반례 계열, 미래·당일 참고자료를 검색에서 제외합니다. 같은 날짜는 시간 순서를 알 수 없어 제외합니다. 원천 ID로 연결된 태깅자료도 같이 제외합니다.
- 계열·검토일이 미확인인 참고자료는 제외 건수를 표시합니다. 실제 계열 관계와 날짜의 진실성까지 앱이 인증하지는 않습니다.
- 개발/시험/반례별 계약 수·묶음 수, 최상위/상위 3개 근거 연결, 문제 비노출, 미확정·이견을 구분합니다. 분모 0은 100%가 아닙니다.
- 태그는 기본 조건과, 과거자료 조건은 태그만 사용한 조건과 비교합니다. 개선과 악화, 새로 생긴 문제 비노출을 따로 표시해 순증가 수치가 악화를 감추지 않게 합니다. 계약별 오류와 검색 출처를 열어 볼 수 있습니다.
- 원문·독립 검수·체크·참고 DB·엔진이 변경되면 새 평가묶음이 필요합니다. 이미 고정한 자료와 결과는 보존합니다.

## 전체 계획에서 남은 사항

이번에도 ‘선정 쟁점의 전체 체크 조항검색’ 평가입니다. 실사용의 유형·당사 역할·모듈·추가확인 처리까지 동일하게 재현한 종단간 평가는 아닙니다. 새 화면의 평가묶음은 운영 승인 시험셋으로 자동 변환되지 않습니다.

남은 개발은 실사용 파이프라인과 승인용 시험셋의 연결, 오판 신고 사례의 시험셋 편입입니다. 폐쇄망 실자료로 분리 시험을 실행한 뒤 오류 유형에 따른 매핑 규칙 정교화와 안전한 자동판정 범위 확정도 필요합니다. 실제 자료에 접근하지 못한 상태에서 정확도가 향상되었다거나 전체 계획이 완료되었다고 주장하지 않습니다.
