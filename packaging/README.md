# 서버 배포 연결 기준

사용자 조건: Python 3.9, FastAPI, 프론트/API 분리, 폐쇄망 공용 서버, 동시 사용자 10명 이하. SQLite는 서버 로컬 디스크에서만 관리한다. 실제 서버 OS·Python 패치·사내 웹서버·HTTPS 주소는 아직 미확정이다.

권장 초기 실행 단위는 정적 웹서버/역방향 프록시, Uvicorn API 1프로세스, 서버 로컬 SQLite이다. CPU 분석 작업 프로세스는 S7에서 추가한다. 현재 기반판에는 분석 작업 프로세스가 없다.

- 브라우저는 사내 HTTPS 주소의 정적 프론트와 /api/v1만 사용한다.
- 역방향 프록시는 /api/v1 경로를 보존하여 API로 전달하고, API 포트는 외부에 직접 공개하지 않는다.
- 프록시 전달 헤더는 신뢰하는 프록시 주소에서만 수용한다.
- 요청 크기 8MiB 제한을 프록시에도 적용하고, 연결·본문 수신 제한시간을 설정한다. 파일 업로드 단계에서 형식별 제한을 별도로 조정한다.
- DB·WAL·원문·백업 경로는 배포 코드와 분리하고 서비스 계정의 접근권한으로 보호한다.
- 인터넷을 차단한 대상 서버에서 해시가 고정된 의존성 설치·세션 쿠키·쓰기 충돌·서비스 재시작을 시험한다.
- DB와 원문을 함께 복원하는 백업 기능과 운영 계정 관리 절차가 준비되기 전에는 운영 배포 완료로 표시하지 않는다.

설치 도구는 아직 특정 서버 OS를 가정하여 생성하지 않았다. FastAPI를 단일 HTML로 묶거나 기존 .crupdate에 Python 실행파일을 넣는 방식을 사용하지 않는다.
