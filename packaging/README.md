# 서버 배포 연결 기준

사용자 조건: Python 3.9, FastAPI, 프론트/API 분리, 폐쇄망 Linux 공용 서버, 동시 사용자 10명 이하. SQLite는 서버 로컬 디스크에서만 관리한다. 2026-09-21 Linux임을 확인했다. 사용자는 세부 배포판·CPU를 모르므로 [Linux 자동 점검·설치 절차](linux/README.md)의 preflight.py로 확인한다. Python 패치·사내 웹서버·HTTPS 주소는 아직 미확정이다.

권장 초기 실행 단위는 정적 웹서버/역방향 프록시, Uvicorn API 1프로세스, 서버 로컬 SQLite이다. 분석·추출은 최대 2개의 별도 Python 프로세스로 실행하며 45초 제한을 둔다. Linux에서는 CPU 40초·주소공간 1GiB 제한을 추가한다. 지속 작업 큐·중간 취소는 아직 구현하지 않았다.

- 브라우저는 사내 HTTPS 주소의 정적 프론트와 /api/v1만 사용한다.
- 역방향 프록시는 /api/v1 경로를 보존하여 API로 전달하고, API 포트는 외부에 직접 공개하지 않는다.
- 프록시 전달 헤더는 신뢰하는 프록시 주소에서만 수용한다.
- 요청 크기 8MiB 제한을 프록시에도 적용하고, 연결·본문 수신 제한시간을 설정한다. 파일 업로드 단계에서 형식별 제한을 별도로 조정한다.
- DB·WAL·원문·백업 경로는 배포 코드와 분리하고 서비스 계정의 접근권한으로 보호한다.
- 인터넷을 차단한 대상 서버에서 해시가 고정된 의존성 설치·세션 쿠키·쓰기 충돌·서비스 재시작을 시험한다.
- DB와 첨부 원본을 함께 복원하는 CLI를 제공한다. 실제 Linux 서비스·사내 HTTPS·백업 복원 인수검증 전에는 운영 배포 완료로 표시하지 않는다.

Linux용 자동 점검, 독립 API의 systemd 설정, Nginx 정적 프론트/역방향 프록시 설정, 해시 검증 오프라인 설치 도구를 추가했다. 기본 설치 기준은 glibc 2.28 이상·CPython 3.9·x86_64 또는 aarch64이다. 실기 검증 전이며 개발 묶음을 운영판으로 설치하지 않도록 구분한다. FastAPI를 단일 HTML로 묶거나 기존 .crupdate에 Python 실행파일을 넣는 방식을 사용하지 않는다.
