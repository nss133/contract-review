# 기능 보존형 UI 시안

실행 파일: [review-preserved-v2.html](review-preserved-v2.html)

이 시안은 v1.90.4 배포 HTML 전체에 표시 전용 CSS와 작은 화면 배치 스크립트를 덧붙인 복사본입니다. 예전 5문항 시안과 달리 실제 앱 엔진과 체크리스트·설명·판단 포인트·기능을 포함합니다. 실제 파일 분석과 저장도 동작하므로 기존 검토자료가 없는 별도 시험 브라우저에서 확인하세요. 새 배포 버전이나 폐쇄망 배포 ZIP은 아닙니다.

## 체험

1. 상단 ‘합성 계약 채우기’를 누르고 ‘분석 시작’을 선택합니다. 합성 본문만 사용하며 원문에 연결된 체크리스트는 실제 앱이 생성합니다.
2. 제목·질문·확인할 내용·법적 근거·매핑 정보·연결 수정·판정·의견 입력을 확인합니다. 문구를 축약하거나 새 예시 설명으로 대체하지 않았습니다.
3. 상단 ‘기존 배치로 비교’로 같은 상태의 원래 화면과 새 화면을 전환합니다. 전환만으로 재분석하거나 판정·의견을 변경하지 않습니다.

## 기능 위치

| 기존 기능 | 시안 위치 | 보존 방식 |
|---|---|---|
| 계약서 입력·조항별 검토·리포트 | 주 메뉴 | 기존 버튼·화면 유지 |
| 전체 체크리스트·검토 정확도 평가·지식 데이터·지식 검수 | 주 메뉴 아래 자료·검토 관리 줄 | 기존 버튼 노드 이동, 이벤트 유지 |
| 골드셋 채점 | 기존 관리모드에서 표시 | 기존 표시 조건 유지 |
| 자동판정 재개·중지·보류 이유·내부 평가·백업/복구 | 조항별 검토의 자동판정·평가 도구 | 기존 패널을 펼침 영역으로 이동 |
| 자동판정 현황 | 검토 진행줄 아래 | 기존 상태 노드 그대로 이동 |
| 체크리스트 문구·설명·근거·의견·수동 연결 수정 | 기존 삼단 항목 | 렌더링 코드와 문구 그대로, 글자·간격·설명 배경만 변경 |
| 파일 입력·원계약·부속서류·이전 검토 비교·검토 설정 | 입력 화면 좌우 구분 | 기존 컨트롤과 설명 유지 |

## 검증 범위

원본에 추가된 두 디자인 블록을 제거하면 원본 HTML과 바이트 단위로 동일합니다. 원본 스크립트/데이터 블록 5개는 그대로입니다. 상세 해시는 preservation-manifest.json에 있습니다.

격리 Chrome에서 원본과 시안의 내장 데이터, 초기 컨트롤 226개, 분석 후 컨트롤, 검토영역 전체 텍스트 및 설명 블록 78개, 매핑 29건·자동판정 11건의 동일성을 확인했습니다. 실제 수기 의견 버튼·저장과 배치 전환 후 보존, 관리 패널 접근, 7개 탭 이동, 1440/1100/800px 가로 넘침 등 28개 점검을 통과했습니다. 결과는 preserved-verification.json에 있습니다.

이 시험은 모든 파일 형식·모든 관리 기능의 종단 간 검증이나 폐쇄망 실사용 검증은 아닙니다. 기존 기능의 코드는 포함·보존되었지만 실제 앱 반영 전에는 추가 회귀검증이 필요합니다. UI를 이유로 기존 판정 기준·경고·문구를 수정하지 않았으므로 기존의 어색하거나 상충하는 안내도 일부 그대로 보일 수 있습니다.

## 재생성

    node prototypes/build-preserved.mjs

원본 배포본은 수정하지 않고 시안 HTML과 보존 명세만 생성합니다. 외부 UI 라이브러리·폰트·CDN을 추가하지 않았습니다. 이전 개념 시안은 비교 자료로 그대로 남겼습니다.
